# Lottie-сцены

## Происхождение

Оба файла присланы владельцем проекта. Исходники лежат рядом с префиксом
`_src-` и **в сборку не попадают** — их читает только `scripts/simba/prepare-lottie.mjs`.

| Файл | Исходник | Где используется |
|---|---|---|
| `empty-catalog.json` | `_src-empty-catalog.json` (Cute_Doggie) | пустой каталог, `components/catalog/EmptyCatalog.tsx` |
| `quiz-loading.json` | `_src-quiz-loading.json` (Loader_cat) | загрузка подбора корма, `components/quiz/QuizLoading.tsx` |

Лицензия — на стороне владельца, он подтвердил право использования при передаче
файлов. Если понадобится ссылка на источник, спрашивать у него.

## Как пересобрать

```
node scripts/simba/prepare-lottie.mjs
```

Скрипт делает две вещи и обе — по явным числам в своей шапке:

1. **Подрезает холст.** Оба файла пришли с холстом вдвое больше рисунка
   (собака занимала 985×842 из 1920×1080, кот — 138×140 из 280×200 и стоял в
   правой половине). Границы замерены в браузере по фактическим контурам,
   объединённым по всем кадрам петли, — на глаз тут не угадать.
2. **Перекрашивает в палитру проекта** по карте `colors`. Карта покрывает и
   сплошные заливки, и градиентные стопы: у собаки семь градиентов по три стопа,
   и без них перекраска прошла бы мимо основного тона корпуса.

Любой цвет, которого нет в карте, скрипт печатает как `НЕ ЗАМЕНЁН` — молчаливых
пропусков не бывает. Править цвета надо в карте и прогонять скрипт заново, а не
руками по JSON.

## Почему готовые файлы не лежат просто в public

Они импортируются динамически (`import('../../lottie/empty-catalog.json')`),
поэтому Vite кладёт каждую сцену в отдельный чанк и грузит только на своём
экране. Плеер `lottie_light` уезжает третьим чанком. Основной бандл от этого
не растёт.
