# Куда класть картинки баннеров

Два файла на каждый баннер — отдельно для компьютера и телефона. Один и тот же
файл на обоих экранах не работает: широкая картинка на телефоне либо обрезается
по краям (текст уезжает за экран), либо мельчает до нечитаемости.

```
client/public/banners/
├── desktop/   ← широкие, для компьютера и планшета
└── mobile/    ← вертикальнее, для телефона
```

## Размеры

| Куда      | Размер файла   | Пропорции   |
|-----------|----------------|-------------|
| `desktop/`| 1800 × 880 px  | 2 : 1       |
| `mobile/` | 1520 × 1035 px | ≈ 1.47 : 1  |

Это пропорции первых четырёх баннеров — под них настроена карусель. Файл
другой формы будет обрезан по краям, и нарисованный на нём текст может
отрезаться. Если новая партия баннеров задумана в другой пропорции — скажите
разработчику, карусель перестроится под неё.

Формат — WebP или JPG, вес до 300 КБ на файл. PNG не подходит: первые четыре
баннера в PNG весили по 1,5–2 МБ каждый, в WebP те же картинки — по 80–100 КБ
без видимой разницы. Пришлите PNG — разработчик пережмёт, но лучше сразу WebP.

## Как назвать

Одинаково в обеих папках — так сразу видно, что это одна пара:

```
desktop/akciya-farmina.webp
mobile/akciya-farmina.webp
```

Только латиница, без пробелов и заглавных букв: пробел в адресе картинки
ломает ссылку.

## Как подключить в админке

Раздел «Баннеры» → создать или открыть баннер → в поля картинок вписать адреса:

```
Картинка (компьютер): /banners/desktop/akciya-farmina.webp
Картинка (телефон):   /banners/mobile/akciya-farmina.webp
```

Адрес начинается со слэша и **без** `client/public` — эта часть пути на сайте
не видна.

Если текст (заголовок, скидка, кнопка) уже нарисован на самой картинке —
снимите галочку «Показывать текст поверх картинки», иначе поверх ляжет второй
заголовок из админки.

## Второй способ — загрузить файлом

В той же форме есть кнопка загрузки: файл уходит в хранилище картинок, и адрес
подставляется сам. Тогда класть ничего в эти папки не нужно. Разница в том, что
файлы из папок лежат в репозитории и попадают на сайт при выкатке, а загруженные
живут в хранилище на сервере.
