# Декор секции «Подбор корма»

Слоистая сцена вокруг карточки «Не знаете, какой корм выбрать?» на главной.
Три плана: животные ЗА карточкой, сама карточка, лапа и нос ПЕРЕД ней.

| Файл                    | План     | Место                                   |
|-------------------------|----------|-----------------------------------------|
| `quiz-left-back.*`      | задний   | кот слева, выглядывает из-за карточки   |
| `quiz-right-back.*`     | задний   | пёс справа, выглядывает из-за карточки  |
| `paw-front.*`           | передний | лапа кота лежит на левом крае карточки  |
| `nose-front.*`          | передний | морда пса выходит на правый край        |

Каждый файл — парой `.webp` (основной) + `.png` (фолбэк), прозрачный фон.

## Что запечено в пиксели, а не в CSS

- **Зеркало кота** в `quiz-left-back` и **повороты** лапы (−12°) и носа (+6°).
  В CSS их держать нельзя: при `prefers-reduced-motion` глобальное правило
  ставит `transform: none !important`, и любая геометрия из трансформа
  разъехалась бы — декор лёг бы поверх текста.
- Базовая позиция задаётся только через `left`/`right`/`bottom`,
  в `transform` уходит исключительно дельта анимации появления.

## Заход за карточку

У пса он больше, чем у кота (120px против 88px) намеренно: так его
собственная морда уходит ЗА карточку и её продолжением становится передний
`nose-front`. Иначе на макете читались «две морды» у одной собаки.

## Замена ассетов

Если меняете картинки — пересоберите пары и проверьте рендером:
срез животного должен полностью прятаться за карточкой, а передние
лапа/нос не должны наезжать на текст (текстовая колонка `max-w-xl`
по центру карточки `max-w-4xl`).

Ниже 1280px декор не рендерится вовсе — по бокам нет места, и файлы
на телефоне даже не скачиваются. Изображения декоративные: скрыты от
скринридеров и не перехватывают клик по кнопке.
