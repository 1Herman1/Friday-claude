# Логотипы брендов для секции «Бренды, которым мы доверяем»

Логотип встаёт в карточку бренда на главной вместо текстового названия.

**Имя файла обязано совпадать со слагом бренда из базы** (`/brands/<slug>.png`).
Иначе картинка отдаст 404 и плитка покажет название текстом — так уже было
с `hills.png` при слаге `hill-s` и с `happycat.png` при слаге `happy-cat`.

Пропорция важна: логотипы разной формы нельзя ограничивать одинаково, иначе
квадратные знаки выглядят втрое мельче широких надписей. Размеры задаются в
`BrandsSection.tsx` по группам.

## Как добавить или заменить логотип

1. Имя файла — точный слаг бренда из базы, расширение `.png`.
2. Прогнать через нормализацию (см. ниже) — она обрежет поля и вычистит фон.
3. Добавить слаг в `LOGO_FILES` в `client/src/components/home/BrandsSection.tsx`
   и в таблицу выше.

## Требования к исходнику

- Логотип, а не баннер и не карточка товара: без фото на подложке, без рамок.
  Присланный `grandorf` был баннером с размытым фото — пришлось вырезать полосу
  с надписью и выбеливать фон.
- Фон прозрачный или ровный белый. Серый (`#F8F8F8` у AlphaPet) и кремовый
  проступают на белой плитке цветным прямоугольником.
- Без больших внутренних полей — они съедают видимый размер логотипа. Нормализация
  обрезает их автоматически, но чем чище исходник, тем лучше результат.

## Нормализация

Файлы приведены к единому виду скриптом: обрезка по контенту, фон в прозрачность
мягким порогом (сохраняет сглаживание краёв), 600px по длинной стороне,
оптимизация. Исходники владельца остаются в истории git.
