# Загрузка фото для секции категорий

Здесь хранятся фотографии для плиток категорий на главной странице.

## Текущие файлы

✅ Файлы уже загружены и размещены:

| Файл | Назначение |
|------|-----------|
| `dogs.png` | Вырезанный объект спаниеля для плитки "СОБАКИ" |
| `cats.png` | Вырезанный объект кота для плитки "КОТЫ И КОШКИ" |
| `vet.png` | Вырезанный объект (лапа/нос) для плитки "ВЕТАПТЕКА" |

Объекты расположены на **прозрачном фоне** и автоматически прижимаются к низу плитки, позволяя подписи читаться в центре.

## Замена файлов

Если нужно заменить какое-то изображение:

1. Подготовьте новый PNG или WebP с вырезанным объектом на прозрачном фоне
2. Сохраните как `dogs.png`, `cats.png` или `vet.png` (заменяет старый)
3. Рекомендуемые размеры: 900×1080 px или с пропорцией 4:5
4. Для оптимизации — конвертируйте PNG в WebP через `cwebp -q 82 input.png -o output.webp` и положите рядом (компонент автоматически использует WebP, если доступен, или PNG fallback)

## Поведение

- Если файл отсутствует или не загружается — плитка остаётся светло-голубой (`#D6EAFE`) с названием категории белым текстом
- Функциональность не нарушена — клик все равно ведёт в каталог
- Text-shadow автоматически добавляет читаемость подписи

## Ссылки

Плитки ведут на:
- **СОБАКИ** → `/catalog?species=dog`
- **КОТЫ И КОШКИ** → `/catalog?species=cat`
- **ВЕТАПТЕКА** → `/catalog?category=care`
