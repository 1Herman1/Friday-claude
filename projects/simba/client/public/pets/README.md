# Изображения питомцев для аккордеона категорий

Загрузите сюда 5 файлов PNG (лучше с прозрачным фоном) с ТОЧНЫМИ именами:

| Файл               | Категория        |
|--------------------|------------------|
| `cat.png`          | Корм для кошек   |
| `smiledog.png`     | Корм для собак   |
| `dogwithcat.png`   | Лакомства        |
| `dogwithball.png`  | Аксессуары       |
| `dogdoctor.png`    | Ветаптека        |

Пока файла нет — на месте питомца просто ничего не показывается (без битой иконки).
Код подключает их автоматически из `client/src/components/home/CategoryAccordion.tsx`.
