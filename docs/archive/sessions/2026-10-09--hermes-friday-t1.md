# Hermes · Friday - AI Agents sytem / Создание топиков в группе · 2026-10-09

## Фрагмент (00:53)

**Просил** 00:53:
  Как сделать топики группы ?

**Ответ** 00:53:
  Топики («Темы») включаются в настройках группы. Сделать это может только админ с правом изменять группу.
  
  **Включить**
  - **iPhone:** открой группу → нажми на название → «Изм.» → включи «Темы».
  - **Android:** название группы → карандаш ✏️ → «Темы».
  - **Telegram Desktop / macOS:** ⋮ или название группы → «Управление группой» → «Темы».
  
  Обычная группа при этом сама станет супергруппой. Если пункта «Темы» нет, обнови Telegram.
  
  **Создать тему**
  - В группе: ⋮ (или название) → «Создать тему». Задай название и иконку.
  - Тема «General» создаётся автоматически. Её можно скрыть, но нельзя удалить.
