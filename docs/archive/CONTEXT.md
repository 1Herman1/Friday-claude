## Решения, которые нельзя забыть
- **Автономия до развилки (08.10, CLAUDE.md).** Цепочку без выбора довожу сам: правка → тест → пуш → выкатка → ревью «глазами» → отчёт. Спрашиваю только на вкусе, тратах больше $1 и необратимом. Причина: целый день ушёл на подтверждения «запушь/выкати».
- **Одна ветка `claude/greeting-nnz368`**, новых не создаём, ветки удаляет только Гермес.
- **Никакой маскировки бота под человека на пропах.** Hash Hedge (п. 12.2) запрещает ботов; скрытая автоматизация при получении выплат — обман фирмы. Джарвис отказался, даже когда Герман взял риск на себя. Пути вместо этого: полуавтомат (сигнал в Telegram, кнопку жмёт Герман), письмо в Hash Hedge за разрешением, пропы, где автоматизация разрешена (Propr, HyroTrader, SizeProp).
- **Код ищет сетап и считает уровни и риск, LLM отвечает только ВЗЯТЬ/ПРОПУСТИТЬ с причиной.** В тесте 9 бесплатных моделей OpenRouter на одних свечах входы разошлись на 240 п., стопы на 900, одна модель дала невыгодный RR.
- **LLM:** Opus 5.5 принимает решения, Sonnet 5.5 закрывает массовые роли. На старте оркестратор — Hermes на подписке Max, без API, и LLM будится только по сигналу детектора. На API или сервер переходим, когда упрёмся в лимиты или понадобится 24/7. Таймфрейм 5m выбрал Герман.
- **Памп-дамп Германа на пропы не идёт:** стоп по ликвидации 10x не переносится, стиль не копируется. На пропах — MA, SMC, новости и сантимент.
- **Контекст переносят файлы, а не чат.** Каждый топик — отдельная сессия, поэтому решение из чата сразу записываем в ТЗ, STATUS или README и коммитим. Трейдинг вынесен в отдельную группу, чтобы не смешивался со студией.
- **PS, специалисты:** ИНН проверяем через DaData при отправке, дамп реестра ФНС не импортируем (Герман: памяти сервера не хватит). Реестр служит только подсказкой («зелёная полоса»), решение принимает человек в админке или в Telegram.
- **PS, политика ПД (30.09):** получатели — TimeWeb, СДЭК и ФНС. Telegram и DaData не указываем: туда мы данные не передаём, только запрашиваем.
- **PS, факты:** не выдумывать. Строку «СДЭК от 6 000 ₽» Герман запретил. В «О компании» оставлены «30+ лет исследований» и «9+ лет на рынке» со счётчиком.
- **Сцена бестселлеров:** один жест = один ролик, остановка только на товаре, этикетки точные (текст наугад не дорисовываем), видео не хуже стоп-кадров. 10.10 сцену пересобрали из лучших уже сгенерированных клипов Kling. Причина: Герман указал, что на ролики ушло ~$35. Правило: сначала переиспользуем то, что уже сгенерировано.
- **Nullume:** у рецептов есть имена, запускаются только по вызову владельца. Pinterest и X — только локально (ADR-007), Higgsfield — каталог-раздел библиотеки вкуса (ADR-008). MCP отдаёт пути к файлам, не base64. `estimate` всегда идёт до `create`.
- **Действуют и раньше принятые решения:** механика возражения (`challenger`, `/council`, порог 80% только для находок), РКН в два гейта, сторож `portability-check.sh`, моторика только через обёртку (без прямого `animejs`), дизайн оцениваем по скриншоту.

## Грабли
- **Проверка рапортует «успех», ничего не проверив** — уже семь случаев. У новой проверки сначала подтверждать, что она видит непустой список файлов и падает, когда должна.
- **Мутационный тест в общем дереве** утёк и выключил потолок цены у рецептов. Теперь мутации делаем только в копии worktree.
- **Облачная среда Claude Code:** прокси рвёт `api.nuget.org`, поэтому CLIP ставится только на Маке. Ещё там нет PIL, `sleep` заблокирован, логи job в GitHub MCP отдают 404, numeric-ID пути запрещены.
- **Текстовая часть CLIP не понимает кириллицу**, запросы `lib search` пишем только по-английски.
- **Telegram:** при включении тем у группы меняется ID на `-100…`. Закрытая General отвечает `Topic_closed`. Бот должен быть админом.
- **Hermes работает на Маке:** если Мак спит, бот и cron молчат. Edge TTS игнорирует указания по голосу.
- **Windows и Mac рендерят по-разному.** Правило reduced-motion сплющивало transforms в раскладке. Перед выкаткой видео проверяем вес webm и предзагрузку.
- **MEXC klines:** не больше 500 свечей за запрос, листаем по startTime+endTime и ставим ретраи. Обзорный 5m-график нечитаем, каждый сетап рисуем отдельной панелью.
- **Битый UTF-8 в архиве (починено 2026-10-10):** BSD `cut -c` на macOS резал кириллицу посреди байтов. В `archive-session.sh` обрезка теперь через `perl substr` (`ucut`), 41 старая запись очищена. `hermes-archive.py` режет по символам Python — не затронут.
- **Перед пушем всегда `fetch` и `rebase`:** параллельные сессии пушат в ту же ветку постоянно.
