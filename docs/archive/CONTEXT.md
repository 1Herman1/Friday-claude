## Решения, которые нельзя забыть
- **Обучение — проверяемая работа:** после каждой логической правки свежая проверка/артефакт/объяснение своими словами; пример → близкая самостоятельная задача → ответы в конце → приёмка. Это нужно новичку, которому прежний краткий учебник был непонятен. Бесплатный клиентский прототип ограничивать первым экраном/одним сценарием.
- **Изоляция — сервером, не замком UI:** read-only обезличенная база знаний, запись только в свой проект; выпуск не выдаёт Git/SSH/деплой. Пример книги не работа ученика, HTML/CSS preview не исполняет JS/React; localhost не удалённый доступ.
- **Экономика сотрудника — цель:** 3 рабочих дня/неделю, проекты 60–500 тыс. ₽, доля 30–35% с уточнением базы/расходов, цель 60–70 тыс. ₽ чистыми. Общий доступ к подписке не считать разрешённым; учебный provider выбирать отдельно, торговые ключи не переиспользовать без разрешения.
- **Трейдинг сначала read-only/бумага:** прибыльность не следует из монитора/gross. Арбитраж требует размещённой маржи, комиссий, глубины и двух ног, не последовательных переводов; Hummingbot reference-only, проверенный connector BingX spot не готовый futures-бот.
- **Не придумывать рынок:** missing=unknown, не 0; funding сравнивать по интервалам/времени, неизвестный интервал null, ставки Decimal. 1000PEPE не склеивать с PEPE без сертификации, тикер не доказывает идентичность, альткоин не означает низкую ликвидность.
- **SMC:** фитиль снимает, тело подтверждает шифт, TP1 2R/TP2 следующая ликвидность/имбаланс; старт $0 на бумаге, Sharpe ≥0,5 в обоих периодах. Preview не разрешает live. Ботов не маскировать под человека.
- **Дневник теперь Codex, не прежний Opus:** владелец явно сменил выбор 16.11, поскольку Claude Code возвращал запрет доступа организации. На платный API без согласия не переходить; починка обзора не доказывает починку биржевого импорта. Секреты только `.env`; для BingX чтение без торговли/вывода. Маржа $20, ×10, стоп около −10%; доливка до ликвидации — нарушение.
- **Клиентские медиа лицензировать:** по BMG была претензия, составы сверять с INCI; назначение генератора/доступ к ключам проверять по текущему проекту. **Процесс:** автономия до развилки, одна рабочая ветка `claude/greeting-nnz368`, fetch/анализ/rebase перед push, чужое не откатывать; РКН на архитектуре/сдаче. ## Грабли
- Raw считать только во фронтматтере: упоминания в теле дают ложную очередь. Hermes дописывает старое/возвращает raw; вложенные уведомления и handoff не новые решения. Маскировка экспортёра пропустила биржевые ключи 16.11: очистить архив до git, не воспроизводить значения.
- Сон Mac задерживает сигналы: 13.11 проверка 18:36 стартовала 18:57 после пробуждения; свечи догрузить можно, актуальный вход потерять. Для 24/7 нужен бодрствующий хост, переезда нет.
- HTTP 403/400 malformed и запрет Claude Code — разные авторизационные сбои; не повторять неизменно неисправный вызов. Старые отказы делегирования не доказывают текущий отказ: v2-ревью успешно. Частичные файлы не готовый результат.
- Смена профиля меняет epoch: ошибка могла скрыть login и workspace; исправлено явным recoverLogin, проверено 503/relogin. В ReportLab сбрасывать heading_number в beforeDocument, экранировать H&B; старые проверки 18 глав/26 источников нельзя применять к v2 без обновления.
- В `trades` нет `avg_entry_price`, цены из `executions`; свечи делистнутых MEXC не всегда доступны. Timestamp и Incorrect apiKey — разные проблемы. Метаданные видео не означают полный просмотр.
