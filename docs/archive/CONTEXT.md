## Решения, которые нельзя забыть
- **Дневник:** Hyperliquid, спот и Ф3 пока не делаем, решение Германа 21.10. История MEXC берётся из xlsx, API — только для свежих ~90 дней. Единица правды — исполнение. Импорт идемпотентный. Удаление только мягкое (`deleted_at`). Данные сделок в git не попадают.
- **ИИ дневника и сигналов — только Claude Opus 5.5** («Не дипсиик»). Код находит сетап, LLM решает «входить или нет». `tg_note.py` без LLM: смысл разбирает Opus, CLI только пишет в базу.
- **Ключ MEXC оставляем текущий**, ротацию не предлагать. Секреты — `[СКРЫТО]`, Герман сам кладёт их в `.env`. Логины, сиды и 2FA не запрашиваем.
- **Prop-agents:** старт с $0, сначала бумага или демо. Kill-switch работает без LLM. Лимиты риска меняет только Герман. Критерий «проходит»: Sharpe ≥0,5 в обоих периодах. Бота не маскируем под человека. Чужие сигналы только читаем.
- **Pinterest по cookies (вариант Б)** включён по прямому «да» Германа 21.10 и только локально, по ADR-007. Pinterest API v5 по всему сайту не ищет, только по своим доскам.
- **Поток (кейс лендинга): основа графитовая, мята — акцент.** Решение владельца, чтобы цвета не повторялись между кейсами.
- **Структура:** ни один проект не стоит выше других, Simba — обычный проект. Агенты разложены по департаментам (`.claude/agents/<отдел>/`).
- **PS:** тексты клиента берём дословно. INCI — только от производителя. Пишем «косметолог», не «врач».
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. РКН проверяем в два этапа.

## Грабли
- **Секреты в чате и архиве** перед коммитом заменять на `[СКРЫТО]`.
- **Hermes дописывает в старые записи** (10.10–14.10) и возвращает им статус `raw`. Это повторы и уведомления о старых фоновых прогонах, новыми событиями их не считать.
- **Новое сообщение в топик обрывает задачу** («Operation interrupted»). Пока идёт длинная задача, не писать. Удаление из БД и `next build` Hermes держит до подтверждения. Окно подтверждения живёт 5 минут; если пропущено, попросить «пришли снова окно подтверждения».
- **Мак спит — бот и cron молчат.** Однажды ответ Opus шёл 16 минут, поэтому тайм-аут подняли до 25.
- **На Маке нет `timeout`**, в zsh циклы `set -- $c` ломались. `~/.hermes/scripts` не принимает пути с `..`, нужна обёртка.
- **Выкатка:** логи job в GitHub иногда отдают 404. `sleep` в Claude Code блокируется, нужен Monitor или until-цикл.
- `hermes gateway restart` выполняется только в Терминале Мака. PyTorch по медленной сети ставится с `UV_HTTP_TIMEOUT=900`.
