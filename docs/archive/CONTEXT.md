## Решения, которые нельзя забыть
- **История MEXC берётся из xlsx-экспорта кабинета, API — только для свежих ~90 дней.** Единица правды — исполнение (fill), сделка — их склейка от нуля до нуля. Импорт обязан быть идемпотентным. Данные сделок не коммитим.
- **Prop-agents:** стартуем с $0, 2–3 месяца бумага/демо, при плюсе — челленджи $5–10k. Kill-switch `/kill` работает без LLM. Лимиты риска меняет только Герман. Критерий «проходит»: Sharpe ≥0,5 после издержек в обоих периодах; сделочные стратегии — R >0 и PF ≥1,2. Стратегия №21 исключена.
- **Ключ MEXC оставляем текущий** («Оставляем ключ, который есть») — ротацию больше не предлагать. Значения — `[СКРЫТО]`. Логины, сиды и 2FA не запрашиваем, секреты Герман сам кладёт в `.env`.
- **ИИ дневника и сигналов — только Claude Opus 5.5** («Не дипсиик»). Код находит сетап, LLM решает только «входить или нет». Невалидный ответ = HOLD.
- **Чужие сигналы только читаем.** Бот на пропах не маскируем под человека. X-агент работает только с подтверждением человека.
- **PS:** тексты клиента — дословно. INCI — только от производителя или клиента; актив, которого нет в INCI, убираем из текста. «Косметолог» вместо «врача», пока нет медлицензии.
- **Aequitas:** латинскому названию нужна русская опора («бюро», «группа»…) — решает владелец.
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. РКН — в два гейта.
