## Решения, которые нельзя забыть
- **Миграция Hermes не меняет всё разом:** отчётность проверена отдельно; `.codex` не подключать до исправления тестов, чтобы не объявить неисправную систему рабочей. Claude-разборы дневника и торговую логику не затрагивали.
- **SMC: работоспособность не прибыльность.** Продолжать демо-сигналы по просьбе Германа, но различать кандидатов, сохранённые разборы, фактическую доставку и бэктест; иначе статистика создаёт ложную уверенность. Запрос v0.3 не равен её выкатке.
- **Генерацию картинок делает Claude через GitHub-workflow; Hermes собирает референсы**, по указанию Германа и из-за отсутствия kie-ключа на Mac. Новые стадии сначала добавлять в `stage` workflow; для Aequitas добавлен workflow коротких image-to-video (`85830539`).
- **Клиентские картинки только с лицензией** (Pexels, Unsplash, генерация): по BMG уже была досудебная претензия. Составы товаров сверять с INCI клиента.
- **Aequitas — клиент выбирает из вариантов**, без наших сравнений и рекомендаций: «Просто презентация»; герои одним списком, палитра без превью. Название «бюро»; ИИ и цифровым спорам отдельная страница из-за ожидаемого роста отрасли (`585c921`).
