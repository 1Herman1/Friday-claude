## Решения, которые нельзя забыть
- **Prop-agents: автономная торговля ИИ-агентов на пропах.** Старт $0: 2–3 месяца бумага/демо, при плюсе челленджи $5–10k. Оставляем 3–4 стратегии. Kill-switch и лимиты остаются; `/kill` без LLM (`engine/KILL_SWITCH`). Лимиты риска меняет только Герман.
- **Критерий «проходит» в бэктестах:** Sharpe после издержек ≥0,5 в обоих периодах; для сделочных — средний R >0 и PF ≥1,2 в 2024–26. Отбор по матожиданию в R после комиссий, не по winrate; демо — по числу сделок (≥100).
- **№21 «BTC сменил режим → альты» исключена:** по первоисточнику −0,343%/сделку после издержек. Первоисточники сверяем сами.
- **Доступы к площадкам:** логины, сид-фразы, 2FA не нужны. MEXC — API-ключ только на чтение (торговля и вывод выключены, привязка к IP), Герман сам кладёт его в `.env`, не в чат. Hyperliquid — достаточно публичного адреса кошелька: данные полные, ключ чтения не добавляет; присылать все адреса субаккаунтов/вольтов; API отдаёт ~10 000 последних исполнений, старое — из CSV. Для торговли позже: ключ MEXC с торговлей без вывода, на Hyperliquid — API-кошелёк.
- **ИИ дневника и сигналов — только Claude Opus 5.5.** Для SaaS — отдельный ключ Anthropic API (подписку в продукте для других нельзя).
- **Код ищет сетап и считает уровни, LLM только решает «входить или нет».** Невалидный ответ = HOLD (9 моделей дали разброс входов 240 п.).
- **Чужие сигналы только читаем, не перепубликуем;** пост сохраняем в момент выхода.
- **Никакой маскировки бота под человека на пропах.** Памп-дамп на пропы не идёт.
- **Трейдинговая база:** одна PostgreSQL, Prisma, Python через SQLAlchemy Core; деньги Decimal(38,18); единица правды — fill.
- **PS:** тексты клиента дословно, правим только явные опечатки. Факты (в т.ч. INCI) не выдумываем — только дословно с сайта производителя, остальное на проверку клиенту. Ролик 3→4 на телефоне не переснимаем («не меняем!»).
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. challenger и /council, РКН в два гейта, моторика через обёртку.

## Грабли
- **Hermes занижает токены на русском ~вдвое** — длинные сессии Opus разрастаются незаметно; чистить/сжимать контекст раньше.
- **Уведомления о старых фоновых процессах** приходят после итогового результата (ошибка tz-naive/aware в S6 уже исправлена) — сверять, к какому прогону относятся.
- **В облачной сессии Claude Code нет агентов репо** — отдаём general-purpose с полным текстом агента; бывает «not in plan mode».
- **Агенты-исследователи пропускают выводы первоисточника** (№21): сверяем с самой работой (скилл `grounded-citations`).
- **Ложная очередь архива:** скрипт ищет `status: raw` по всему файлу, 10-10--hermes-friday снова в очереди (фронтматтер `digested`, raw — в цитате). Не исправлено.
- **Нет PIL;** ffmpeg на mjpeg падает молча. Установка в Hermes ждёт подтверждения 5 минут.
- **Секрет в чате:** ключ вставлять `pbpaste | tr -d '[:space:]' > файл`.
- **Telegram:** thread_id после первого сообщения; Мак спит — бот и cron молчат. MEXC klines ≤500 свечей.
- **Перед пушем `fetch` + `rebase`.**
