## Решения, которые нельзя забыть
- **Prop-agents: цель — автономная торговля ИИ-агентов на пропах.** Старт $0: 2–3 месяца бумага/демо, при плюсе челленджи $5–10k. Тестируем много стратегий, оставляем 3–4. Агент = кластер + версия стратегии + модель + площадка + счёт; изолированы, координирует риск-слой. Полная автономия, но kill-switch и лимиты остаются; `/kill` работает без LLM (файл `engine/KILL_SWITCH`). Лимиты риска на дашборде только показываются, меняет их только Герман.
- **Стратегия «BTC сменил режим → альты догоняют» исключена** (№21): по первоисточнику (Khan, SSRN 7485359) эффект есть, но торговля даёт −0,343% на сделку после комиссий и проскальзывания. Агент-сборщик каталога это пропустил — первоисточники сверяем сами. Её место заняла TSMOM.
- **Отбор по матожиданию в R после комиссий, не по winrate;** демо оцениваем по числу сделок (≥100), а не по календарю. На 5m taker-комиссия съедает 0,5–1R, поэтому SMC 5m входит лимиткой (maker).
- **ИИ дневника и сигналов — только Claude Opus 5.5.** DeepSeek и OpenRouter не используем. Для SaaS нужен отдельный ключ Anthropic API: подписку нельзя использовать в продукте для других.
- **Код ищет сетап и считает уровни, LLM только решает «входить или нет».** Невалидный ответ = HOLD. Причина: 9 моделей на одних свечах дали разброс входов 240 п.
- **Чужие сигналы только читаем, не перепубликуем.** Пост сохраняем в момент выхода — каналы удаляют убыточные.
- **Никакой маскировки бота под человека на пропах.** Hash Hedge запрещает ботов. Памп-дамп Германа на пропы не идёт.
- **Трейдинговая база:** одна PostgreSQL, схема у Prisma, Python через SQLAlchemy Core. Деньги Decimal(38,18), float запрещён. Единица правды — fill.
- **PS:** тексты клиента дословно, правим только явные опечатки и показываем список. Факты не выдумываем, медиа сначала переиспользуем. Ролик 3→4 на телефоне с «кашей» на банке **не переснимаем** — решение Германа («не меняем!»).
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. Контекст переносят файлы. Действуют прежние правила: challenger и /council, порог 80% только для находок, РКН в два гейта, моторика через обёртку, дизайн по снимку.

## Грабли
- **В облачной сессии Claude Code нет агентов репо** («Agent type 'coder' not found»): отдаём general-purpose с полным текстом агента. Там же бывает «not in plan mode» и обрыв MCP-прокси.
- **Агенты-исследователи пропускают выводы первоисточника** (случай №21). Цифры сверяем с самой работой, а у PDF — с заголовком полученной страницы (скилл `grounded-citations`).
- **Ложная очередь архива:** скрипт ищет `status: raw` по всему файлу, поэтому 10-10--hermes-friday снова в очереди (у неё фронтматтер `digested`, строка raw — в цитате). Grep надо привязать к фронтматтеру.
- **В среде нет PIL** (ModuleNotFoundError); ffmpeg падает на mjpeg с пустым выводом — проверять, что кадр записан.
- **Установка в Hermes ждёт подтверждения 5 минут,** потом срывается. Язык STT по умолчанию английский.
- **Секрет в чате:** `hermes-archive.py` вырезает сообщение целиком. Ключ вставлять `pbpaste | tr -d '[:space:]' > файл`.
- **Проверка рапортует «успех», ничего не проверив:** сначала подтверждаем непустой список файлов.
- **Telegram:** thread_id появляется после первого сообщения; Мак спит — бот и cron молчат. MEXC klines ≤ 500 свечей.
- **Перед пушем `fetch` + `rebase`.** Логи job GitHub иногда отдают 404.
