# Память проекта

Обновлено: 2026-09-13

## Где мы сейчас

Основное направление — **магазин Симба**: чёрно-белый рестайлинг клиента
закончен и выкачен, следом прошёл спринт админки (категории, пользователи,
дашборд, блог, тексты сайта, доставка). SEO-трек по ветклинике в фоне: отчёт и
КП сданы, ждём данные от клиента.

## Активные направления

- **Симба, клиент** — `client/`. Единый чёрный акцент `ink` `#232323`, золото
  только для бейджей и галочек, синего декора не осталось. Чекаут: золотая
  шкала шагов, чёрные плашки выбора, полный адрес курьера, подсказки DaData.
  Мобильная версия: нижняя навигация, шторки, нативный свайп баннеров.
- **Симба, админка** — `admin/` + `server/`. Спринт 13.09, см. решения ниже.
- **Ветклиника** (4-й Ростовский пер., 1с1) — `docs/projects/vet-clinic/`.
  193 среза выдачи по 117 запросам через XMLRiver. Отчёт, стратегия, план
  продвижения, дашборд и КП готовы и сданы.
- **Система агентов** — `.claude/agents/`, `.claude/scripts/`.

## Решения, которые нельзя забыть

### Общие

- **Ветка одна: `claude/greeting-nnz368`**, репозиторий `1Herman1/project_simba`,
  выкатка только через слияние в `deploy/simba`. Новых веток не заводить —
  в истории уже были случайные ветки от ревью.
- **Дизайн ревьюим по скриншоту, а не по коду** — `.claude/scripts/screenshot.mjs`.
  Дважды поймало то, что в исходнике не видно.
- **Секреты только в GitHub Secrets и `.env` на сервере.** Всё, что попало в
  чат, считается утёкшим и подлежит замене без обсуждения.

### Симба, админка (спринт 13.09)

- **Дерево категорий редактируется в админке** — название и структура; сайт
  берёт из него подменю шапки и подписи плиток.
- **Пользователи разделены** на зарегистрированных и гостей с действиями.
  Молчаливые гости в списке не показываются, только считаются как визиты.
- **Дашборд считает визиты и сводки** за неделю, месяц и год.
- **Сроки доставки и порог бесплатной доставки — единый источник в админке.**
  Корзина, карточка товара, промо-полоса, чекаут и страница «Доставка» берут
  числа оттуда. Раньше числа были разбросаны по компонентам, это и стало
  причиной переделки.
- **Блог: 100 статей в базе** (10 опубликованных, 90 черновиков), редактор с
  датой, обложкой, рубриками, SEO-полями и вставкой ссылок на товары.
- **`import-blog.ts` идемпотентен**: тексты существующих статей не трогает,
  обложку ставит только там, где её нет, чтобы не затирать правки владельца.
- **Тексты сайта** — 26 заголовков и подзаголовков правятся из админки без выкатки.
- **Обложки блога можно собирать из ассетов проекта** (вырезанные иллюстрации,
  следы лап, золотое пятно), когда генераторы медиа недоступны.

### Ветклиника, SEO

- **Ставка на симптомные запросы, а не районные.** Симптомные — 0% агрегаторов
  в топе; районные — 66–100% заняты справочниками при 17–36 показах.
- **Деньги ниши — в стерилизации и кастрации:** 1642 подтверждённых показа в
  месяц при низкой конкуренции.
- **КП по пунктам, не тарифы** — клиент хочет видеть цену каждой услуги.
  Старт 45 000 ₽/мес → 60 000 со второго → 80 000 с третьего месяца.
- **Ведение Директа (12 000 ₽) ≠ рекламный бюджет** — бюджет клиент платит
  Яндексу напрямую, ориентир от 60 000 ₽/мес. Разделять явно.
- **Накрутку ПФ не рекомендуем** — фильтр Яндекса на 6–12 месяцев убьёт молодой
  домен. Пункт в прайсе есть по требованию клиента, но предупреждение рядом
  убирать нельзя.
- **Лицензия seomeat.ru:** указание авторства обязательно на каждом
  GEO-результате. Не убирать и не переписывать даже по просьбе.

## Грабли

- **Пароли MinIO и Postgres дважды попадали в чат открытым текстом** и заменены
  на сервере. `MINIO_SECRET_KEY` не синхронизируется из GitHub Secrets, живёт
  только в `server/.env` — при пересоздании сервера заводить руками.
- **Ключи XMLRiver тоже присылались в чат** — перевыпустить, сбор данных гонять
  через GitHub Actions, чтобы ключ не попадал в контекст.
- **Агенты уходят в режим планирования и не делают работу** — присылают план
  вместо результата. Проверять каждый отчёт лично, при необходимости
  доделывать руками.
- **Параллельные агенты ошибаются путями**, если не дать точные — сначала
  Explore, потом готовые пути в задании.
- **Доступность MCP зависит от сессии, а не от аккаунта.** В одном чате
  `artlist` не отдал ни одного инструмента, в параллельном (`695164c6`)
  тем же вечером сгенерировал снимок (`docs/archive/media-tests/`). Список
  инструментов читается при старте: переподключать внутри идущего чата
  бесполезно, нужен новый. `21st` просит авторизации, `higgsfield` авторизован,
  но упирается в бесплатный тариф.
- **Тяжёлые картинки не класть в git.** Тестовый PNG на 7,2 МБ ушёл в историю
  репозитория навсегда. Для сайта класть сжатый WebP в `client/public/`.
- **Параллельные сессии заводят свои ветки** вопреки правилу одной ветки
  (так появилась `claude/funny-dijkstra-uf4fr0`). Проверять `git log` чужих
  веток перед работой.
- **MCP `icon-library` не стартовал**: `tools/icon-mcp-server` вне npm
  workspaces, зависимости не ставились. Установка добавлена в
  `.claude/hooks/session-start.sh`, коммит `7c43afa`.
- **Новый агент не виден в текущей сессии** — определение подхватывается только
  при старте.
- **`<span>` с CSS `width` не растягивается** — инлайновый элемент игнорирует ширину.
- **Без `<meta name="viewport">` вёрстка разъезжается на реальном телефоне**,
  хотя узкие скриншоты в headless выглядят нормально.
- **Python-heredoc внутри YAML `run:`** ломает workflow целиком, и
  `workflow_dispatch` молча исчезает. Выносить в отдельный скрипт.
- **Пуш отклоняется 403 + non-fast-forward** — на remote чужие коммиты.
  Лечится `git pull --rebase origin <ветка>`.
- **Внешние сайты недоступны через WebFetch** (egress proxy), но curl из Bash
  работает.
