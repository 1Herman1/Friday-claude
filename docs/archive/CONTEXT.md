## Решения, которые нельзя забыть
- **Генерацию картинок делает Claude** через GitHub-workflow медиа, **Hermes только собирает референсы**. Так сказал Герман («Он не должен генерировать изображение»), к тому же на Mac нет ключа kie. Новую стадию сначала добавить в список `stage` workflow.
- **Картинки для клиентов — только с лицензией** (Pexels, Unsplash или генерация): по BMG уже приходила досудебная претензия. Тексты о товарах сверяем с INCI, подтверждённым клиентом.
- **Деку Aequitas показываем клиенту без наших рекомендаций.** Остаются только варианты, выбирает он. Так попросил Герман: «Презентация для владельца. Убираем. Просто презентация».
- **Aequitas:** под ИИ и цифровые споры делаем отдельную страницу — ставка на рост отрасли (`585c921`). Название — «бюро».
- **BMG:** перед правкой снимаем копию, работаем через REST и пароль приложения, тему правим через Code Snippets. Правки делаем автономно.
- **При блокировке биржи порядок такой:** сначала бэкап API (только чтение, пока API ещё отвечает), потом дамп БД, CSV и скрины, и только потом новая биржа. Причина: доступ к API может пропасть в любой момент.
- **Ключи бирж Герман вписывает в `trade-performance/.env` сам**, в чат их не просим. Ключ BingX — только чтение и торговля, **без вывода**. Ключ MEXC не ротируем.
- **Правило риска в дневнике.** Маржа $20 при плече ×10, стоп около −10%. Ликвидация с доливкой маржи — нарушение. Сделки по ETH и быстрые сделки с мелким результатом считаются «случайными». ИИ в дневнике — только Opus 5.5 («Не дипсиик»).
- **Prop и SMC.** Начинаем с $0 на бумаге, порог — Sharpe ≥0,5 в обоих периодах. Снятие ликвидности считаем по фитилю, шифт — по телу свечи. TP1 = 2R, TP2 — у следующей ликвидности или имбаланса. Бота не маскируем под человека.
- **Видео разбираем так:** субтитры целиком плюс кадры по фразам-указателям (`yt_moments.py`), это ~95% результата.
- **Процесс:** автономия до развилки, одна ветка `claude/greeting-nnz368`, РКН в два этапа.

## Грабли
- **Секреты** перед коммитом заменять на `[СКРЫТО]`.
- **Hermes дописывает в старые записи и возвращает им `raw`.** Сводки сжатия и повторы событиями не считать. Статус смотреть во фронтматтере.
- **Сообщение, пришедшее во время задачи, может оборвать её** («Operation interrupted» / «request was not processed»), тогда нужно повторить. Две сессии Hermes могут взять одно задание, поэтому перед стартом сделать `git pull`.
- **Генерация на Mac не работает**: нет ключа kie, OpenRouter отвечает 402. В облаке у kie кончились кредиты, баланс надо пополнить.
- **Нарезка видео** длиннее 7 минут обрывается, резать кусками. Время в сигналах — UTC.
- **В `trades` нет `avg_entry_price`**, цены брать из `executions`. По 9 делистнутым контрактам MEXC свечей нет.
