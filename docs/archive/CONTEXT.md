## Решения, которые нельзя забыть
- **Prop-agents:** старт $0, 2–3 месяца бумага/демо, при плюсе челленджи $5–10k; 3–4 стратегии; kill-switch `/kill` без LLM (`engine/KILL_SWITCH`); лимиты риска меняет только Герман.
- **Критерий «проходит»:** Sharpe после издержек ≥0,5 в обоих периодах; для сделочных — средний R >0 и PF ≥1,2 в 2024–26. Отбор по матожиданию в R, не по winrate; демо — ≥100 сделок.
- **№21 «BTC сменил режим → альты» исключена** (−0,343%/сделку по первоисточнику). Первоисточники сверяем сами.
- **Ключ MEXC (16.10): Герман решил оставить текущий ключ**, хотя он был опубликован в групповом чате (сообщение удалено) и, по ответу MEXC, имеет права «торговля: да, вывод: да». Джарвис дважды рекомендовал отозвать и сделать новый только на чтение с IP-привязкой; Герман: «оставляем ключ, который есть». Повторно не спорим, но код использует ключ только на чтение. Значения в архиве — `[СКРЫТО]`.
- **Доступы:** логины, сид-фразы, 2FA не нужны. Hyperliquid — публичного адреса кошелька достаточно (все субаккаунты/вольты; API ~10 000 исполнений, старое — CSV). Секреты Герман кладёт в `.env` сам, не в чат.
- **ИИ дневника и сигналов — только Claude Opus 5.5;** для SaaS — отдельный ключ Anthropic API.
- **Код ищет сетап и считает уровни, LLM только решает «входить или нет»;** невалидный ответ = HOLD.
- **Чужие сигналы только читаем, не перепубликуем;** пост сохраняем в момент выхода.
- **Никакой маскировки бота под человека на пропах.** Памп-дамп на пропы не идёт. **X-агент — только с подтверждением человека** (правила X, быстрый бан).
- **Трейдинговая база:** одна PostgreSQL, Prisma, Python через SQLAlchemy Core; деньги Decimal(38,18); единица правды — fill.
- **PS:** тексты клиента дословно, правим только явные опечатки; INCI — только дословно с сайта производителя или от клиента. Ролик 3→4 на телефоне не переснимаем. Перехват скролла в сцене бестселлеров — осознанное исключение (записано в доках). Четыре товара сцены «вшиты» в ролики — замена товара = перегенерация роликов. Переименование товара не ломает старые ссылки, избранное и встраивания в блоге (алиасы).
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. challenger и /council, РКН в два гейта, моторика через обёртку.

## Грабли
- **Секреты в чате/архиве:** Герман прислал ключ MEXC открытым текстом в группу — сырая запись архива его содержала; перед коммитом архивов проверять на ключи и заменять на `[СКРЫТО]`. Ключ вставлять `pbpaste | tr -d '[:space:]' > файл`.
- **MEXC API — ~90 дней истории;** MEXC klines ≤500 свечей.
- **Hermes занижает токены на русском ~вдвое** — сжимать контекст раньше.
- **Медленная сеть ломала запасную схему стоп-кадров PS:** кадры и ролики делили канал → пустая сцена. Лечится очередью загрузки и заглушкой.
- **Миграция `previousSlugs`** по ревью должна трогать только живую строку товара — миграции PS проверять `migration-guard`.
- **Уведомления о старых фоновых процессах** приходят после итога — сверять прогон.
- **В облачной сессии Claude Code нет агентов репо** — general-purpose с текстом агента.
- **Ложная очередь архива:** скрипт ищет `status: raw` по всему файлу; 10-10--hermes-friday в очереди из-за цитаты. Не исправлено: искать только во фронтматтере.
- **Нет PIL;** ffmpeg на mjpeg падает молча. **Telegram:** Мак спит — бот и cron молчат. **Перед пушем `fetch` + `rebase`.**
