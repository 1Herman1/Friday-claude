# Память проекта

Обновлено: 2026-09-21

## Где мы сейчас

Два трека. Симба (магазин): рестайлинг клиента и спринт админки закончены и
выкачены; ветклиника ждёт данные клиента. Nullume (CLI + MCP-сервер + skill
для генерации медиа через kie.ai): спринт 3 закрыт 20.09 — пакет готов к
публикации в npm, спринт 2 (библиотека вкуса) отложен по решению Гермеса.
Активный проект (`docs/projects/.active`) сейчас — `nullume`.

## Активные направления

- **Nullume** — `tools/nullume/` (CLI+MCP+core), доки `docs/projects/nullume/`,
  ADR-006 (архитектура), ADR-007 (политика источников для библиотеки вкуса).
  Три поверхности: CLI (`bin/nullume.js`), MCP (`src/mcp/`, 11 инструментов
  kie.ai в `.mcp.json`), SKILL.md. Каталог моделей вендорится из docs.kie.ai
  в `data/models.json`/`data/prices.json`. Спринт 3: `nullume init` ставит
  инструмент в любой проект (`.mcp.json`, скилл, `.env.example`); пакет готов
  к npm (`private:false`, `files`, `prepublishOnly`, bin запускает dist без
  tsx — публикует Гермес: `npm login && npm publish --access public`); скилл
  живёт в `tools/nullume/skills/nullume/SKILL.md`, копия в
  `.claude/skills/nullume/` через `npm run sync:skill`; 9 пресетов задач
  (`generate presets/preset`), история и повтор (`generate list/rerun`, MCP
  `list_presets`/`rerun_job`); CI `nullume-ci.yml` и еженедельный
  `nullume-catalog-audit.yml` (issue при расхождении каталога); корневой
  README репозитория. Живая генерация ещё не проверена — баланс kie не
  пополнен.
- **Симба, клиент** — `client/`. Чёрно-белый рестайлинг выкачен, мобильная
  версия готова (нижняя навигация, шторки, свайп баннеров).
- **Симба, админка** — `admin/` + `server/`. Спринт 13.09 закрыт: категории,
  пользователи, дашборд, блог, тексты сайта, доставка из единого источника.
- **Ветклиника** — `docs/projects/vet-clinic/`. Отчёт, стратегия, КП сданы,
  ждём данные от клиента (прогноз бюджета Директа по 12 запросам).
- **Система агентов** — `.claude/agents/` (по департаментам), `.claude/scripts/`.
  Заведены механика возражения (`challenger`, `/council`, расщеплённый порог) и
  правовая обвязка (`rkn-compliance`, `rkn-lint.mjs`), см. решения ниже.

## Решения, которые нельзя забыть

### Общие
- **Репозиторий — `1Herman1/Friday-claude`** (переименован, не `project_simba`).
  Ветка одна на весь репозиторий — `claude/greeting-nnz368`, объявлена в
  `docs/projects/README.md`; в `project.md` каждого проекта ветка больше не
  дублируется. Ветки удаляет только Гермес в GitHub (хук старта печатает
  лишние).
- **Дизайн ревьюим по скриншоту, а не по коду** — `.claude/scripts/screenshot.mjs`.
- **Секреты только в GitHub Secrets и `.env`** — попавшее в чат считается
  утёкшим и подлежит замене без обсуждения.

### Nullume
- **kie.ai выбран поверх Artlist/Higgsfield** ради прозрачного прайсинга и
  моделей, которых там нет (nano-banana-2-lite $0.02, Seedance 2, Kling 2.5).
  Официального SDK нет — каркас свой, знания об API взяты из MIT-репозитория
  VelsVisual.
- **Каталог kie собирается парсингом ~180 markdown-страниц документации, не
  API** — риск тихой деградации (неверная цена вместо падения). Закрыто
  полем `schemaSource`/`source` у оценки стоимости, требованием подтверждения
  при `fuzzy`/`unknown`, обязательной живой генерацией на $0.02 перед сдачей.
- **MCP отдаёт пути к файлам, не base64** — иначе один результат съедает
  ~20k токенов контекста.
- **Pinterest в библиотеке вкуса — по настоянию Гермеса**, вопреки
  возражению Джарвиса о риске бана аккаунта. Работает только локально
  (собственная сессия/cookie), только в CLI, никогда в MCP, за тройным
  гейтом `assertLocalOnlyAllowed` (ADR-007). Решение владельца, риск на нём.

### Механика возражения (против подхалимства модели)
- **Порог уверенности 80% расщеплён на два случая.** Находка о коде — порог
  есть, сомневаешься молчи. **Возражение против принятого решения порога не
  имеет**: озвучивается всегда, с пометкой уверенности словом («уверен»,
  «похоже на», «догадка»). Повод: формулировка «сомневаешься — молчи» стояла в
  23 агентах и толкала всю систему к молчанию, то есть в ту же сторону, что и
  подхалимство. Мы не забыли включить возражение — мы его выключили правилом.
- **`challenger`** (`.claude/agents/meta/`) — один самый сильный довод против
  замысла и обязательный раздел «при каких условиях решение окажется
  неверным», заполняемый даже при вердикте «возражений нет». Автора решения
  ему не сообщают. Звать до реализации, а не после.
- **`/council`** — три агента на один вопрос с разными заданными позициями, не
  видят друг друга, авторство при сведении скрыто, кворум называется честно.
  Совпадение трёх экземпляров одной модели — слабое свидетельство, не
  доказательство.
- **Рубрика `ВОЗРАЖЕНИЕ`** в блоке формата ревьюеров: не более одного пункта,
  пометка уверенности, нет возражений — рубрика опускается.
- **Правило главного агента** — `CLAUDE.md`, раздел «Возражение по существу»:
  возражать до работы; запрещено открывать ответ похвалой без конкретной
  причины.
- Источник идеи — разбор `karpathy/llm-council`, ADR-005. Взято: независимость
  мнений до сравнения, скрытие авторства при оценке, принудительная
  двусторонность, жёсткий машиночитаемый хвост, кворум. Отброшено: вендорное
  разнообразие (недоступно — четыре экземпляра Claude ошибаются одинаково),
  ранжирование без эталона, де-анонимизация при синтезе.

### Правовая обвязка (РКН)
- **`rkn-compliance`** (`.claude/agents/legal/`), скрипт
  `.claude/scripts/rkn-lint.mjs`, чек-лист `docs/core/rkn-compliance.md`,
  ADR-004.
- **Два обязательных гейта.** Ранний — на этапе архитектуры: размещение БД и
  бэкапов, хостер в реестре, на кого домен, способ авторизации, трансграничная
  передача. Перед сдачей это уже не правка, а переезд. Финальный — перед
  сдачей: согласия, политика, cookie, реквизиты, удаление данных.
- Агент **находит и репортит**, но код не правит и юридических текстов не
  пишет: оператор ПД — клиент. Каждая находка помечена зоной `[студия]` или
  `[клиент]`.
- Раздел **«Правовой контур»** в `project.md` каждого проекта: незаполненное
  поле считается находкой уровня ВАЖНО, а не благополучием.

### Единый источник текста агентов
- `docs/core/agent-report-format.md` + `.claude/scripts/sync-agent-blocks.mjs`.
  Копии общего текста обязаны лежать в каждом файле агента (механизма включения
  файлов нет, агент следует своему файлу), но правятся скриптом, не руками.
  Повод: копии разошлись за сутки на одном слове, и никто не заметил.

### Симба, админка (спринт 13.09)
- Дерево категорий, пользователи (зарегистрированные/гости), дашборд,
  сроки/порог доставки — единый источник в админке вместо разброса по
  компонентам. Блог: 100 статей, `import-blog.ts` идемпотентен (не трогает

### Ветклиника, SEO
- Ставка на симптомные запросы (0% агрегаторов в топе), а не районные

  Яндекса 6–12 месяцев убьёт молодой домен.

## Грабли
- **Механизм отчитывается об успехе, ничего не проверив** — шесть случаев за
  три сессии, самый дорогой урок: (1) проверка `[3]` в `selftest` состояла из
  одних `continue`, а `ok()` печатался безусловно; (2) после переезда агентов
  по департаментам `selftest` читал их нерекурсивно, видел ноль агентов и
  продолжал печатать «валиден»; (3) ранний гейт РКН существовал только прозой —
  ни `architect`, ни скиллы старта о нём не знали; (4) проверка `[9]` искала
  подстроку где угодно в файле вместо канала в блоке формата; (5) она же
  отбирала агентов по наличию строки «80%» и молча пропускала двух обязательных
  перед деплоем ревьюеров; (6) `sync-agent-blocks` искал рубрику по первому
  вхождению слова и заменил бы абзац прозы, после чего сверка стала бы зелёной.
  **Правило: у каждой новой проверки первым делом подтверждать, что она видит
  непустой список файлов и падает, когда должна.**
- **Агент уходит в планирование и присылает план вместо работы** — случилось с
  `archivarius` на этой самой свёртке памяти. Проверять каждый отчёт лично и
  доделывать руками.
- **Два агента правили один SKILL.md в разных копиях** — правки одного
  затёрлись синком `sync:skill`; править только копию в пакете
  (`tools/nullume/skills/nullume/SKILL.md`), затем синковать.
- **Стоимостной шлюз в MCP стоял после платного вызова** — исправлено,
  правило: `estimate` до `create` везде.
- **В `bin/nullume.js` после правок исходников нужен `npm run build`**,
  иначе запускается старый `dist`. Пресет с несуществующими полями модели
  ловится тестом-стражем по каталогу.
- **`KIE_API_KEY` добавлен в среду 20.09, но виден только новому чату**;
  баланс kie ещё не пополнен — генерация не пройдёт, проверять только `balance`.
- **Параллельные сессии правят одни файлы** — перед пушем всегда `git fetch`
  и разбор `log HEAD..origin/<ветка>`.
- **Тяжёлые файлы не класть в git** (тестовый PNG 7,2 МБ навсегда осел в
  истории). **Пуш 403 + non-fast-forward** — лечится `git pull --rebase`.
- **Без `<meta name="viewport">` вёрстка разъезжается на телефоне**, хотя
  headless-скриншот выглядит нормально.
