## Решения, которые нельзя забыть
- **Источник истории MEXC — экспорт xlsx из кабинета, API — только для свежих ~90 дней.** API физически не хранит старше (декабрь–июль пусто при рабочем запросе).
- **Единица правды — fill (исполнение); сделка = склейка исполнений.** Импорт обязан быть идемпотентным — файлы будут грузиться повторно и внахлёст.
- **Данные сделок не коммитим** (gitignore) — личные финансовые данные.
- **Prop-agents:** старт $0, 2–3 месяца бумага/демо, при плюсе челленджи $5–10k; 3–4 стратегии; kill-switch `/kill` без LLM (`engine/KILL_SWITCH`); лимиты риска меняет только Герман.
- **Критерий «проходит»:** Sharpe после издержек ≥0,5 в обоих периодах; для сделочных — средний R >0 и PF ≥1,2 в 2024–26. Отбор по матожиданию в R, не по winrate; демо — ≥100 сделок. **№21 «BTC сменил режим → альты» исключена** (−0,343%/сделку). Первоисточники сверяем сами.
- **Ключ MEXC (16.10): Герман решил оставить текущий ключ** («оставляем ключ, который есть»), хотя он публиковался в чате и имеет права «торговля: да, вывод: да». Джарвис рекомендовал отозвать дважды — повторно не спорим, код использует ключ только на чтение. Значения — `[СКРЫТО]`.
- **Доступы:** логины, сид-фразы, 2FA не нужны; Hyperliquid — публичного адреса достаточно. Секреты Герман кладёт в `.env` сам.
- **ИИ дневника и сигналов — только Claude Opus 5.5;** для SaaS — отдельный ключ Anthropic API. **Код ищет сетап и считает уровни, LLM только «входить или нет»;** невалидный ответ = HOLD.
- **Чужие сигналы только читаем, не перепубликуем.** **Никакой маскировки бота под человека на пропах;** памп-дамп на пропы не идёт; X-агент — только с подтверждением человека.
- **Трейдинговая база:** одна PostgreSQL, Prisma, Python через SQLAlchemy Core; деньги Decimal(38,18).
- **PS:** тексты клиента дословно; INCI — только с сайта производителя или от клиента. Перехват скролла в сцене — осознанное исключение. Четыре товара «вшиты» в ролики — замена = перегенерация. Переименование товара не ломает старые ссылки.
- **Процесс:** автономия до развилки (вкус, траты > $1, необратимое). Одна ветка `claude/greeting-nnz368`. challenger и /council, РКН в два гейта, моторика через обёртку.

## Грабли
- **Секреты в чате/архиве:** ключ MEXC приходил открытым текстом; перед коммитом архива проверять на ключи → `[СКРЫТО]`. Ключ вставлять `pbpaste | tr -d '[:space:]' > файл`.
- **MEXC API — ~90 дней истории;** klines ≤500 свечей.
- **Hermes дублирует фрагменты в сырых записях** (одно сообщение 2–3 раза, ответы не по порядку) — при своде не считать повторы новыми событиями.
- **Ложная очередь архива:** скрипт ищет `status: raw` по всему файлу; 10-10--hermes-friday (фронтматтер `digested`) снова в очереди из-за цитаты. Не исправлено: искать только во фронтматтере.
- **Медленная сеть ломала сцену PS** — лечится очередью загрузки и заглушкой. **Миграции PS** — через `migration-guard`.
- **Уведомления о старых фоновых процессах** приходят после итога — сверять прогон. **В облачной сессии Claude Code нет агентов репо.**
- **Нет PIL;** ffmpeg на mjpeg падает молча. **Мак спит — бот и cron молчат.** **Перед пушем `fetch` + `rebase`.**
