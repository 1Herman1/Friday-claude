## Решения, которые нельзя забыть
- **Обучение — проверяемая работа:** после логической правки свежая проверка/артефакт/объяснение; пример → близкая задача → ответы в конце → приёмка, потому что краткий учебник новичку непонятен. Бесплатный клиентский прототип — первый экран/один сценарий.
- **Изоляция сервером:** обезличенная read-only база знаний, запись только в свой проект, выпуск не даёт Git/SSH/деплой. Пример книги не работа ученика; HTML/CSS preview не JS/React; localhost не удалённый доступ.
- **Экономика сотрудника — цель:** 3 дня/неделю, проекты 60–500 тыс. ₽, доля 30–35% с уточнением базы/расходов, 60–70 тыс. ₽ чистыми. Общая подписка не автоматически разрешена; учебный provider отдельно, торговые ключи не переиспользовать.
- **Трейдинг сначала read-only/бумага:** монитор не доказывает прибыльность; LLM не отменяет кодовый quant/risk reject, APPROVE не разрешение ордера. Hummingbot reference-only: проверенный BingX connector spot, не готовый futures-бот. Ботов не маскировать под человека.
- **Не придумывать рынок/работу:** missing=unknown, не 0; Decimal funding сравнивать по часовому горизонту только при известных интервалах. Тикер не identity, 1000PEPE не PEPE без сертификации, альткоин не обязательно неликвиден. LIVE-наблюдение не реальные ордера, HOLD не рекомендация входа; refresh UI не возраст биржевого снимка.
- **SMC:** фитиль снимает, тело подтверждает шифт, SL за sweep, TP1 2R/TP2 следующая ликвидность/имбаланс; старт $0 на бумаге, Sharpe ≥0,5 в обоих периодах. Preview не разрешает live, дефектный тест v02 не опровергает всю стратегию.
- **Дневник теперь Codex, не Opus:** владелец сменил выбор из-за запрета Claude Code организации; платный API без согласия нельзя. Починка обзора не чинит импорт. Секреты только `.env`; BingX read-only, маржа $20/×10/стоп около −10%, доливка до ликвидации — нарушение.
- **Клиентские медиа лицензировать:** по BMG была претензия, составы сверять с INCI, назначение генератора/ключей проверять по проекту. **Процесс:** автономия до развилки; одна ветка `claude/greeting-nnz368`, fetch/анализ/rebase перед push, чужое не откатывать; РКН на архитектуре/сдаче.
