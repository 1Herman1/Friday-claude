## Решения, которые нельзя забыть
- **Картинки для клиентов — только с лицензией.** Берём Pexels или Unsplash со ссылкой на снимок либо генерацию. Pinterest годится лишь как референс раскладки, без публикации: у пинов не установить автора, а по BMG уже была досудебка. Причина та же для любых чужих фото.
- **BMG:** перед правкой снимаем копию страницы. Доступ к WordPress — через REST и пароль приложения (HTTPS), SSH есть только с Mac. Классификатор не пускает через GitHub Actions. То, что недоступно через REST (шаблон темы), делаем через «Дополнительные стили».
- **Андрей:** без медицины, без открытых курсов и франшизы, Instagram без рекламы, потому что это люкс. Клиенту показываем несколько путей. Доход студии в клиентской версии не показываем, цены даём по услугам, чтобы сумма не пугала.
- **Дневник:** Hyperliquid, спот и Ф3 пока не делаем. Историю MEXC берём из xlsx: API отдаёт только ~90 дней. Удаление только мягкое, данные сделок в git не кладём.
- **ИИ — только Claude Opus 5.5** («Не дипсиик»). Код находит сетап, решает LLM. Тильт и kill-switch работают без LLM.
- **Ключ MEXC оставляем текущий.** Секреты — `[СКРЫТО]`, в `.env` их кладёт сам Герман.
- **Prop:** начинаем с $0, на бумаге или демо. Порог — Sharpe ≥0,5 в обоих периодах. Бота не маскируем под человека.
- **SMC v0.2:** шифт считаем по закрытию тела, снятие ликвидности — по фитилю. Перенос на BTC — наша гипотеза.
- **Процесс:** автономия до развилки (вкус, траты больше $1, необратимое). Одна ветка `claude/greeting-nnz368`. РКН проверяем в два этапа. Цены называем точно.

## Грабли
- **Секреты** перед коммитом заменять на `[СКРЫТО]`.
- **Hermes дописывает в старые записи и возвращает им `raw`.** Повторы, уведомления о фоновых процессах и сводки сжатия новыми событиями не считаются. Скрипт очереди ловит «status: raw» и в тексте записи (так было с записью от 10.10) — проверять фронтматтер.
- **Новое сообщение в топик обрывает задачу** («Operation interrupted»). Так 23.10 прервался hero Perfect Skin, его доделали 24.10.
- **Время в сигналах указано в UTC**, а живём по МСК (UTC+3). Прежде чем искать задержку, сверить пояс.
- **Неоднозначный бриф** («в основном Пинтерест можно — Unsplash или Pexels») Hermes понял по-своему. Источник в брифах писать однозначно.
- **Без ключа kie.ai на Mac** генерация у Hermes стоит.
- Облачная сессия не читает файлы вне разрешённых каталогов (`/root/.nullume`, `hb_landing`). Нет PIL. Мак спит — бот и cron молчат. Команды дольше 7 минут обрываются.
- В таблице `trades` нет `avg_entry_price`, цены брать из `executions`. Скрины Playwright ложатся в `$TMPDIR`.
