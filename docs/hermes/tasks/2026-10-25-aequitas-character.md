# Задание Hermes: персонаж-маскот для Aequitas по образцу pgplaw.ru

Дата: 25.10.2026 · Проект: Aequitas (`docs/projects/aequitas/`) · Исполнитель: Hermes (Mac, Pinterest, Dribbble, Behance, X через Nullume с `NULLUME_LOCAL_IMPORTERS=1`)
Продолжение задания `2026-10-25-aequitas-design-ideas.md` — та часть, где ты не нашёл анимационного персонажа.

## Что это за персонаж
Ссылка от владельца: https://www.pgplaw.ru/ (Пепеляев Групп). Скриншот главной —
`docs/projects/aequitas/references/competitors/pgplaw.png`, разбор — `competitors.md`.

В первом экране pgplaw стоит **иллюстрированный персонаж-юрист**:
- линейная графика (line art), без заливки, тонкий контур;
- карикатурный, но интеллигентный: очки, бабочка, фрак;
- **голова собрана из логотипа «π^g»** — персонаж и есть знак фирмы;
- стоит над силуэтом города, смотрит на него, рядом бумажный самолётик;
- живёт в hero рядом со слайдером новостей.

Их приём сильный: имя → знак → персонаж → девиз. Слабое — исполнение: плоская
векторная графика в духе 2015 года и фиолетово-синий градиент-фон.

Владелец хочет **похожую идею** для Aequitas — персонажа, собранного из знака
фирмы, — но в солидном исполнении. Возможно, это не человечек, а **объект,
который играет такую же роль** (весы-персонаж, литера «Æ»/«Э» с характером,
перо-персонаж).

## Что найти — по разным источникам
Pinterest + Dribbble + Behance + Awwwards/Godly (через поиск) + X. Запросы
по-английски. Примеры: `law firm mascot line art`, `logo character illustration
lawyer`, `brand character built from logotype`, `monoline character illustration
premium brand`, `editorial line illustration businessman`, `character made of
letters logo`, `animated brand mascot website hero minimal`, `lottie line
character corporate`, `scales character illustration`.

### 1. Персонажи, собранные из логотипа или буквы — 5–8 референсов
Как знак превращается в персонажа и остаётся знаком.

### 2. Линейная иллюстрация в премиальном исполнении — 5–8 референсов
Monoline, гравюра, офорт, тонкая латунная линия на тёмном. Чтобы персонаж
выглядел как в «Нью-Йоркере», а не как флэт-вектор 2015-го.

### 3. Как персонаж живёт на сайте — 4–6 референсов
Сайты и Lottie-анимации, где персонаж ведёт по странице: hero, разделы, пустые
состояния, реакция на действия (форма отправлена, расчёт готов). Особенно ценно:
тёмный фон, сдержанная анимация.

### 4. Персонаж-объект вместо человечка — 3–5 референсов
Предмет с характером без лица: весы, перо, печать, ключ ведут себя как персонаж
(жест, поза, реакция).

## Распаковка идей
Предложи **3 концепции персонажа Aequitas**, у каждой:
- из чего собран: литера «Æ» / «Э», весы, знак § и т.п.;
- стиль линии и цвет под наши макеты A «Вечерний кабинет» (графит + латунь) и E «Равновесие» (чернильный синий + платина) — `docs/projects/aequitas/concepts/`;
- 3–4 сцены: первый экран, «Как мы работаем», калькулятор, заявка отправлена;
- как анимировать: Lottie / SVG-обводка / видеопетля, примерная стоимость генерации через Nullume, если нужна.

## Ограничения
- Солидность — главное правило. Без мультяшности, гипертрофированных эмоций и «стартап-маскотов».
- Этика адвоката: персонаж не обещает результат, не «побеждает» оппонента, не изображает суд и задержание.
- Без фиолетово-синих градиентов, «молотка судьи» и Фемиды с повязкой.
- Картинки в git не класть (ADR-007), только ссылки. Лицензия неизвестна — только внутренний референс.
