# Общие блоки отчёта: единый источник

Два куска текста повторяются в определениях всех агентов-ревьюеров. Claude Code
читает каждый файл агента как самостоятельный промпт — механизма включения
файлов нет, поэтому копии на диске обязаны существовать: агент следует своему
файлу, а не ссылке на чужой.

Но править их руками нельзя. Копии расходятся сами: через сутки после заведения
блока «Порог уверенности» у двадцати трёх агентов было «Порог 80% **выше** — про
находки», а у двух — «Порог 80% — про находки». Никто этого не заметил.

**Правило: текст ниже правится только здесь.** Копии разносит
`.claude/scripts/sync-agent-blocks.mjs --apply`, расхождения ловит
`--check`, и он же входит в `/selftest`.

Кого касается: агенты департаментов `review`, `quality`, `design`, `security`,
`legal`, кроме изготовителей ассетов (`component-curator`, `icon-curator`,
`media-generator`, `motion-curator`) — те отчётов о находках не пишут.

---

## Блок 1: порог уверенности

Отдельный раздел в конце файла агента. Между заголовком и следующим `## ` —
дословно этот текст:

```markdown
## Порог уверенности: два разных случая

Порог 80% выше — про **находки**: есть баг, есть уязвимость, есть утечка.
Ложная находка дорого стоит доверию, поэтому сомнительное лучше не репортить.

**Возражение против решения порога не имеет.** Считаешь выбранный подход
неверным или знаешь вариант лучше — говори, даже будучи неуверенным. Помечай
уверенность словом: «уверен», «похоже на», «догадка». Молчать из-за
неуверенности здесь запрещено — цена молчания может быть выше цены ошибки.
```

## Блок 2: рубрика возражения

Последняя рубрика внутри примера в разделе «Формат вывода» (или «Формат
отчёта» / «Формат находки» — заголовок у агентов разный, важно, что это блок
формата). Дословно:

```
ВОЗРАЖЕНИЕ  (не более одного пункта; нет возражений — рубрику опустить)
Подход выбран неверно: <что именно и к какому последствию это ведёт>
Уверенность: уверен / похоже на / догадка
```

Ограничение в один пункт — не формальность. Рубрика с обязательным заголовком и
без ограничения заполняется ради заполнения, и возражение тонет в шуме ровно
так же, как тонуло в молчании.

---

## Почему копии, а не ссылка

Проверено на живом прогоне: `code-reviewer` не воспользовался рубрикой
`ВОЗРАЖЕНИЕ`, **имея её прямо в своём файле** — возражение по существу у него
было, но ушло в рубрику `ВАЖНО`. Если заменить текст ссылкой «см.
`docs/core/agent-report-format.md`», он не воспользуется ею тем более.

Дублирование здесь — осознанная плата за то, что модель читает один файл.
Скрипт делает эту плату разовой.
