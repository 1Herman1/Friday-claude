## Где пусто (библиотека не дала)

- **dom-keramiki:** нет карточки плитки и калькулятора метража; нужны фото текстур/интерьеров с Unsplash/Pexels (не импортировались).
- **sovetnik:** нет «сайт косметики + открытый виджет» целиком и клинично-белого скинкер-сайта.
- **prime-fitness:** нет push-уведомления на экране блокировки.
- **atlas:** нет швейцарской строгости и жёлтого — рефы дают только структуру.
- **smena:** нет кремового фона в рефах — палитра из брифа.
- **potok:** нет письма со сканом и линий «фрагмент ↔ поле» — приём собран из двух рефов.

Дублей между кейсами нет.
