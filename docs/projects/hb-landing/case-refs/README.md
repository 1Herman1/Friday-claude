## Где пусто (библиотека не дала)

- **dom-keramiki:** карточка плитки и калькулятор закрыты Pinterest (калькулятор из другой ниши); фото текстур для макета — Unsplash/Pexels, не импортировались.
- **sovetnik:** закрыто — клинично-белый сайт (The Ordinary) + «сайт с открытым виджетом» (не косметический) из Pinterest; вместе дают композицию.
- **prime-fitness:** закрыто — экран блокировки с уведомлениями (Pinterest).
- **atlas:** строгая сетка/1px/моно (ref-4) и жёлтый акцент (ref-5) есть по отдельности; «строгий + жёлтый» в одном рефе нет.
- **smena:** нет кремового фона в рефах — палитра из брифа.
- **potok:** сплит «документ → поля → ИИ» есть (ref-5); письма со сканом и линий «фрагмент ↔ поле» нет — дорисовать по брифу.
