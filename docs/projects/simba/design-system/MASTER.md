**Синий текст — только `primary-hover` `#2E5DC8`.** `primary` и `primary-soft`
как цвет текста не проходят AA ни на белом, ни на `blue-50`. `primary-soft`
живёт на иконках, рамках и фокус-ринге, где порог 3:1.

**Цифра в кружке шага и текст пилюли «БЕСПЛАТНО» — это текст:** такие подложки
красить в `primary`, не в `primary-soft`.

**Чёрный акцент везде:** `ink` `#232323` — единственный цвет для действия (CTA кнопки,
выбранные чипы и варианты, прогресс квиза и выбранные ответы, фокус-ринг). Синий остаётся
только для ссылок, чипов в покое, иконок, тех мест где текста нет или он невидим.

**Gold для бейджей и иконок:** amber-400 для бейджей скидок и рекомендаций, amber-600 для
иконок, звёзд рейтинга и галочек.

### Полная шкала navy (обязательно к объявлению)

В `client/tailwind.config.ts` объявлены только `300/500/700/900`, а код использует
также `100/200/400/600` — эти классы **не генерируются** и молча не применяются,
из-за чего вторичный текст наследует `navy-900` и иерархия рушится.

```ts
navy: {
  100: '#E4EBF7',  // границы, разделители (= line)
  200: '#C4D3E0',  // фон бейджей
  300: '#8FA8C0',  // декор, зачёркнутая цена — НЕ смысловой текст
  400: '#6B85A0',  // иконки, крупный текст (3.5:1) — НЕ body
  500: '#4A5C7A',  // вторичный текст (6.4:1) ✅
  600: '#3A4B66',
  700: '#2A3A56',
  800: '#1F2E48',
  900: '#000000',  // основной текст (решение владельца: чистый чёрный)
}
```

**Правило:** смысловой текст — только `navy-500` и темнее. `navy-300/400` —
декор, иконки, зачёркнутые старые цены. На подложке `primary-tint` `navy-300`
и `navy-400` запрещены даже как декор под текстом — только `navy-500` и темнее.

### Шкалы blue и amber (как в `client/tailwind.config.ts`)

```ts
blue:  { 50: '#F1F1F1', 100: '#D6EAFE', 200: '#A4D4FC',
         300: '#6BB8F5', 400: '#3A9AE8', 500: '#1A3A5C' }
amber: { 50: '#FFF8E8', 100: '#FFEDC4', 200: '#FFD9A0', 300: '#FFD580',
         400: '#FFB347', 500: '#E8921A', 600: '#A66200', 800: '#7A4700' }
```

`blue-200` — легаси-пастель: прогресс-бары и декор. **Как фон CTA запрещена** —
действие красится в `primary`. `blue-500` `#1A3A5C` — тёмный, это цвет текста,

**Правило: hex в компонентах запрещён** — использовать классы Tailwind
(`text-navy-500`), а не `style={{ color: '#4A6A8A' }}`. Хардкод приводит к
дрейфу палитры: в коде уже встречается `#4A6A8C` вместо `#4A6A8A` — отличие в
один символ, глазом незаметно, но это другой цвет вне системы.
`design-lint.mjs` помечает такие места как WARNING.

## Типографика

```ts
fontFamily: {
  sans: ['Montserrat', 'system-ui', 'sans-serif'],
  display: ['Montserrat', 'system-ui', 'sans-serif'],
}
```

- **Семейство:** Montserrat (кириллица ✅). Решение владельца: заголовки —
  semibold (600, утилита font-bold переопределена на 600), основной текст —
  light (300); мельче 14px — regular (400), чтобы держать читаемость.
- **Подключение:** только `<link>` в `index.html` с `display=swap` +
  `preconnect` к `fonts.googleapis.com` **и** `fonts.gstatic.com`.
  `@import` в CSS — запрещён (блокирует рендер).
- **Шкала:** 12 / 14 / 16 / 18 / 24 / 32 / 40
- **Body на мобиле:** ≥ 16px (иначе iOS авто-зумит поля)
- **Line-height:** 1.5–1.75 для текста
- **Длина строки:** `max-w-prose` для абзацев (65–75 символов)
- **Цены и таблицы:** `tabular-nums` — иначе цифры прыгают

## Motion

MOTION_INTENSITY=3 → только `:hover`/`:active`, без авто-анимаций. Исключения: свечение под курсором на кнопках (::before, blur 14px, только мышь) и радужный ободок нижнего меню (6s loop, только кромка, пауза при открытой шторке, статичен под reduced-motion).

| Что | Длительность | Easing |
|---|---|---|
| Hover карточки/кнопки | < 100мс | `ease` |
| Дропдауны, поповеры | 150–250мс | `ease-out` |
| Модалки, шторки | 200–500мс | `ease-out` |

Правила (полностью — `docs/core/motion.md`):
- Анимировать **только** `transform` / `opacity`. Не `width/height/top/left/flex-grow`.
- `transition-all` — запрещён, перечислять свойства явно.
- `ease-in` запрещён **везде** — и на входе, и на выходе (линтер даёт ERROR).
- **Выход = 65–75% длительности входа** (вошло за 300мс → ушло за 200мс).
- Уважать `prefers-reduced-motion` (глобально обработан в `index.css`).
- **Раскрытие на неизвестную высоту** (аккордеон) — единственное разрешённое
  исключение из «только transform/opacity»: `grid-template-rows` `0fr → 1fr`,
  200мс вход / 140мс выход. `max-height` с магическим потолком запрещён — он
  обрезает длинные ответы.
- Авто-карусели: пауза на hover/focus + отключение при reduced-motion.
- Карусель баннеров на главной — по референсу клиента, во всю ширину:
  сосед 11% + зазор 5.5% + слайд 67% + зазор + сосед (сумма 100), мобиль
  9% / 16px / 82%. Соседи не масштабируются, только `opacity .6`; стрелки —
  белые кружки 44px по центру зазора (`calc(13.75% − 22px)`); радиус 24px
  (`rounded-banner`), слайды 2:1.
- Lottie-сцены (`.lottie-host`) исключены из глобального сброса `transform`
  под reduced-motion: их конечности стоят на SVG-атрибуте, и CSS `none`
  разбирал персонажа на части. Плеер там просто стоит на первом кадре.

## Компоненты — ключевые инварианты

### Пилюли: шапка, нижнее меню (мобиль)

**Общие характеристики пилюль:**
- **Фон:** `bg-[rgb(119_119_119_/_0.5)]` + `backdrop-blur-[8px]` (серый #777 на 50% прозрачности с размытием)
- **Форма:** `rounded-full` (скруглены полностью)
- **Текст и иконки:** белые, `text-white`, с `filter: drop-shadow(0 1px 2px rgb(0 0 0 / 0.55))` для читаемости на полупрозрачном фоне
- **Тач-таргеты:** 44px (все нажимаемые элементы)
- **Состояния:** hover и active = `bg-white/28` (белый на 28% непрозрачности)

**Шапка (Header) — пилюля:**
- **Позиция:** `position: fixed; top-[10px]; left-0; right-0; z-50`
- **Размеры:** `max-w-7xl mx-auto`, `h-16` (64px десктоп), `h-14` (56px мобиль)
- **Padding:** `px-8` (десктоп), `px-4` (мобиль)
- **Состав:** слева навигация (Собаки / Коты и кошки / Ветаптека),
  по центру логотип, справа иконки (Telegram / Поиск / Профиль / Избранное / Корзина)
- **Логотип:** PNG обрезан по чернилам, центруется без сдвигов. Тень та же, что у иконок (`drop-shadow(0 1px 2px rgb(0 0 0 / 0.55))`), статичная; размытого ореола 3px нет. Hover — только scale.
  - Десктоп: 154px
  - Мобиль: 96px (в пилюле), 62px (в компактной пилюле)
- **Telegram:** оформлен как соседние иконки — 44px-обёртка, контурный `TelegramPlaneOutlineIcon` 22px, без залитого кружка
- **Корзина:** `CartBagIcon` (lucide `shopping-bag`)
- **Иконки-движение:** трансформ живёт на самом `<svg>` (классы `.header-ico-*`), не на 44px-обёртке,
  чтобы соседи не двигались. Поиск −12°/1.08, профиль −1px/1.06, сердце `icoPop` 200ms, корзина +2px/−6°, Telegram +2px/−1px/1.06.
  180ms `--ease-out`, только `(hover: hover)`
- **Мегаменю:** белая карточка `rounded-card` с тенью, привязана под пункт навигации
- **Отступ контента:** `main` класса `pt-[84px]` чтобы не уезжал под пилюлю

**Нижнее меню (мобиль):**
- **Позиция:** `position: fixed; bottom-[10px]; left-4; right-4; z-[70]`
- **Высота:** `h-14` (56px)
- **Padding:** `px-2`
- **Содержимое:** четыре кнопки с иконкой сверху и лейблом (Главная / Избранное / Корзина / Профиль)
- **Safe area:** учитывает `env(safe-area-inset-bottom)` для notch
- **Drawers (шторки):** останавливаются 64px выше bottom nav, чтобы не закрывали кнопки

- **Тач-таргеты:** ≥ 44×44px (`w-11 h-11`). Эталон — сердечко в `ProductCard`.
- **Иконочные кнопки:** обязателен `aria-label`.
- **Две карточки, два языка.** Контентная (шаг инструкции, FAQ, инфо-блок,
  колонка футера) — `bg-white border border-line rounded-card`, тени нет.
  Товарная — та же рамка в покое, но на hover получает глубину:
  `shadow-card` + `border-primary-soft` + `translateY(-2px)`. Требование
  глубины из e-commerce-профиля закрывается ховером, а не постоянной тенью.
- **Рамка ИЛИ подложка, не оба.** Блок на `primary-tint` рамки не получает.
- **Плитки категорий на главной** — исключение по референсу клиента: серая
  заливка `#D9D9D9`, радиус 32px (`CategoryTiles.tsx`).
- **Border-radius:** карточки `rounded-card` (14px), кнопки `rounded-xl`,
  пилюли `rounded-full`. Максимум 16px.
- **Вложенные карточки:** запрещены (карточка в карточке).
- **Цены:** только через `formatPrice` — в БД копейки (`249900` = 2499 ₽).
- **Пустые состояния:** заголовок + пояснение + кнопка next step.
- **Высота экрана:** `min-h-[100dvh]`, не `min-h-screen` (100vh прыгает на мобиле)

### Радиусы — исключения из шкалы

Стандартный максимум — 16px (`rounded-card` карточек). Исключения:

| Компонент | Радиус | Причина |
|-----------|--------|---------|
| CTA и outline кнопки | 30px | Решение владельца: мягкий, узнаваемый профиль |
| Quiz modal | 28px | Решение владельца: чуть мягче стандарта |
| Category tiles (плитки на главной) | 32px | Решение владельца: выразительный дизайн |
| Carousel slides & banners | 24px | Решение владельца: больше свежести чем 16px |
| Pills (шапка, нижнее меню) | 9999px (full-round) | Математическое скругление при `h-16`/`h-14` |.

### Кнопки и управление

- **Главные CTA** (`.btn-primary`): фон `ink` `#232323`, текст белый, радиус 30px,
  высота ≥44px, font-size 13px (12px на мобилях ≤ 767px), font-weight 600.
  На ховер (при наличии мыши) фон темнеет до `#000000` + подъём 1px + тень `0 4px 12px rgb(0 0 0 / .18)` + мягкое белое свечение под курсором (radial 5rem, blur 14px, 150ms вход / 105ms выход).
  На тач нажатие — scale 0.97 + затемнение, свечения нет. Фокус — outline 2px ink.
  Disabled = opacity 50%.
- **Вторичные/outline** (`.btn-outline`): белый фон, рамка `ink` `#232323`, текст `navy-900`, радиус 30px, высота ≥44px.
  На ховер фон инвертируется: фон `ink`, рамка `ink`, текст белый; на hover — чернильное свечение под курсором rgb(35 35 35 / .14).
- **Чипы и фасовки** (`.btn-press`): 
  - **Покой:** white bg + `line` border + `navy-700` текст
  - **Активный и hover:** `ink` bg + `ink` border + белый текст
  - **Без синих цветов** — весь выбор управляется чёрным и белым
  - Scale 0.94 на нажатие
- **Ссылки:** текст `primary-hover` `#2E5DC8`, никогда не синий текст на синем фоне.
  Стрелка в тексте сдвигается +3px на ховер.

## Решённые вопросы

- **Чёрный акцент везде** (12.09.2026). Все CTA, выбранные чипы, ответы в квизе и фокус-ринги
  используют единый чёрный `ink` `#232323` с белым текстом (контраст 15.2:1).
  Синий остаётся только для ссылок внутри текста, информационных подложек, иконок.
  
- **Gold для бейджей и иконок** (12.09.2026). Бейджи скидок и рекомендаций — `amber-400` `#FFB347`.
  Иконки, звёзды рейтинга, галочки — `amber-600` `#A66200`.
  
- **Мобильное нижнее меню в пилюле** (12.09.2026). Навигация по четырём пунктам в фиксированной
  пилюле с backdrop-blur, тач-таргеты 44px, разное состояние активного пункта через `bg-white/28`.
  Находится в `z-[70]`, drawers останавливаются 64px выше.

- **Блик вместо прожектора на CTA** (13.09.2026 — отменено 14.09.2026). Hover-эффект переделан с radial-gradient-пятна
  под курсором на однократную диагональную полосу света (блик) 520ms. Подъём 1px и внешняя тень остаются. На тач нажатие блика не происходит.
  Отменено: владелец попросил вернуть свечение, но сильно размытое и следующее за курсором.

- **Радужный ободок нижнего меню — исключение владельца** (13.09.2026). Единственная авто-анимация
  проекта (помимо idle-иконок). Тонкая кромка 2px пилюли переливается вбок по цветам палитры
  (blue-100, blue-200, amber-200) на низкой альфе: 6s loop бесконечный, пауза при открытой шторке.
  Только кромка — фон остаётся серым стеклом. Под reduced-motion показывается статичный градиент.

- **Логотип шапки — тень как у иконок, не ореол** (13.09.2026). Размытый `drop-shadow(0 1px 3px)` читался свечением при hover-scale; заменён на резкий `0 1px 2px / .55`, как у соседних иконок — без него голубой логотип на серой пилюле даёт контраст ~1.5:1.
  Hover-scale (1.05) оставлен.

- **Telegram в шапке — залитый самолётик** (14.09.2026). По просьбе владельца контур заменён на залитый (как в логотипе Telegram),
  обёртка и hover прежние: 44px, TelegramPlaneIcon 21×18px, hover +2px translateX, −1px translateY, scale(1.06).

- **Свечение вместо блика** (14.09.2026). Hover-эффект кнопок переделан: вместо однократного блика 520ms —
  мягкое размытое свечение, которое следует за курсором. Реализовано через ::before с radial-gradient 5rem + filter blur(14px).
  Белое свечение на CTA (.btn-primary), чернильное на outline (.btn-outline) и .btn-glow.
  Включается через lib/button-glow.ts, координаты --mx/--my пишутся при наведении мышью.
  Отключено при тач и reduced-motion.

- **Раскрытый FAQ — на primary-tint** (14.09.2026). Заливка #F2F6FE открытого вопроса возвращена по просьбе владельца
  (была снята в коммите 714d751 при унификации к white). Это подложка, не акцент, правило «синий только ссылки» не нарушает.
