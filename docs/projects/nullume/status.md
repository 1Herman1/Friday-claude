проект, 33 стиля, 6 рецептов. Проверено живьём, больше 15 генераций.

## Работает в облачной сессии

| Что | Как | Проверено |
|---|---|---|
| Генерация картинок, 60 моделей | `generate create`, MCP `generate` | да |
| Генерация видео, 78 моделей | то же, image-to-video / text-to-video | да, 01.10 (grok-imagine) |
| Смета и потолок | `generate cost`, `--max-credits` у рецептов | да |
| 9 пресетов | `generate preset` (без `--style`) | да |
| 6 рецептов: Витрина, Афиша, Триптих, Метаморфоза, Сцена, Оживление | `recipe run <имя>` — только по слову владельца | 5 из 6; Оживление не запускалось |
| 33 стиля из фильтров Higgsfield | `generate create … --style higgsfield-<имя>` | да (Noir, Sketch, Two color, Marble) |
| Стиль только на фон (карточки товара) | `--style-scope background` | да, 01.10 (Marble) |
| Каталог Higgsfield: 736 позиций | `lib import higgsfield --limit 1000` | да, 724 референса после дедупа |
| Разделы библиотеки по тегу | `lib family create/set-refs --tag` | да |
| Установка стилей одной командой | `lib style apply higgsfield-styles.json` | да, 33/33 |
| Поиск по имени и тегу | `lib search <текст>` | да |

**Запрос в `lib search` — только по-английски.** Текстовая часть CLIP
(`clip-vit-base-patch32`) кириллицу не различает: любой русский запрос даёт почти
один и тот же вектор (косинус 0,95–0,97 с бессмысленным набором кириллицы) и
возвращает шум — молча, без ошибки. Проверено живьём на Mac 03.10 (коммит `4d287a7`).

Библиотека в облаке живёт до перезапуска контейнера. Источник истины — файлы в
пакете; пересборка: `lib init --skip-models` → `lib import higgsfield --limit 1000`
→ четыре `family create --tag` → `lib style apply higgsfield-styles.json`.

## Не работает в облаке — нужен Mac

| Что | Почему | Что сделать |

| Поиск по смыслу, кластеризация (CLIP) | прокси среды рвёт туннель к `api.nuget.org`, движок не ставится | на Mac: `npm install` в `tools/nullume`, `nullume lib init` — работает, проверено 03.10 (40 референсов, 2 семейства) |

## Требует внимания

- **Расход kie вне этой сессии.** 30.09 вечером баланс 9951, 01.10 — 8619
  (−1332 кр). Через Nullume в этой сессии за это время — 0. Вероятный источник —
  параллельная сессия «UI perfect-skin/shop» (работает с карточками товара) или
  GitHub Actions с ключом в секретах. Проверить в кабинете kie историю задач.
- **Списание видео выше оценки.** Оценка grok-imagine 720p — 4,5 кр, баланс
  упал на 27. Возможно, совпало с чужим расходом (см. пункт выше); подтвердить
  по истории задач kie.
- **Полный облёт 360°** — нужна модель с длиной ≥ 9–10 с (kling 2.6, seedance)
  или две дуги со склейкой.
- **Оживление (видео-рецепт)** стоит на kling 2.6 — до 225,5 кр по смете.
  Решение владельца: переключить пресет на grok-imagine (≈ 13,5 кр за рецепт)?
