# Дизайн-система: Nullume

Не применимо. Nullume — это CLI-инструмент и MCP-сервер, не веб-приложение.
Дизайн-система нужна для веб-сайтов, мобильных приложений и дизайн-систем UI.

CLI использует текст и встроенные символы Unicode. SKILL.md в `.claude/skills/nullume/`
содержит правила использования инструмента, а не токены цвета/типографики.

Этот файл оставлен как заглушка из шаблона проекта.
