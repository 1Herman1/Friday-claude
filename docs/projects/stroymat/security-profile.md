# Профиль безопасности: Стройматериалы

Карта для агентов `security-*`. Универсальные классы уязвимостей —
`docs/core/anti-patterns/security.md`.

## Что есть

- Статический HTML (`projects/stroymat/obnovlenie-assortimenta.html`), собирается
  `build.py` из `index.html`, `assets/`, `fonts/`. Сервера, БД, API нет.
- Сборщик читает только файлы своего каталога; внешних запросов не делает.

## Секреты

Нет. Реквизиты поставщика в странице — публичные.

## Не применимо

Аутентификация, сессии, CORS, rate limit, загрузка файлов, вебхуки, SQL.
Единственная поверхность — контент страницы: при появлении форм или счётчиков
запускать `/rkn` и `security-infra-cloud` (внешние скрипты).
