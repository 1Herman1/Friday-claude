# Проект: Стройматериалы (обновление ассортимента)

Страница «что появилось в ассортименте» для оптового поставщика листовых
материалов и теплоизоляции. Бренд и тон — `brand.md`, токены —
`design-system/MASTER.md`. Универсальные правила — `CLAUDE.md`, `docs/core/`.

Восстановлен 20.09.2026 из ветки `claude/greeting-nz368-inventory-html-2hrmlh`
(единственная работа, которой не оказалось в основной ветке при сверке).

## Выкатка

Ветка выкатки: нет — клиент размещает HTML сам.
Сборка: `python3 projects/stroymat/build.py` собирает `obnovlenie-assortimenta.html`
со встроенными картинками (base64) и шрифтами из `assets/` и `fonts/`.
Что проверять после: страница открывается с телефона, есть `<meta name="viewport">`,
все карточки материалов показывают размер и толщину.

Рабочая ветка здесь НЕ указывается: она одна на весь репозиторий и объявлена
в `docs/projects/README.md`. Новых веток не заводить.

## Пользователь

Имя: Гермес. Клиент — поставщик стройматериалов (реквизиты — в самой странице).

## Технологический стек (реальный)

Статический HTML + CSS, без фреймворков. Сборщик — `build.py` на Python 3
(стандартная библиотека). Шрифты Golos Text и Manrope, кириллические сабсеты,
лежат в `fonts/`. Не применимо: Next.js, React, Tailwind, Prisma, Vercel, сервер.

## Правовой контур (для агента `rkn-compliance`)

- Форм сбора персональных данных нет: только телефон и почта поставщика для
  связи. Cookie и счётчиков нет. Уведомление в РКН не требуется — ПД не
  собираются. Дата проверки: не проводилась — при добавлении формы запустить `/rkn`.

## Домены проекта

- Карточка материала: наименование, формат листа (мм), толщины, наличие на складе.
- Главный вопрос снабженца — срок поставки на объект; он вынесен в первый экран.
