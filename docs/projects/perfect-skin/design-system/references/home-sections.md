## Откуда взяты референсы
- **Сбор.** Nullume, импорт из Pinterest (`pinterest-cookies`, только локально, по ADR-007): 8 запросов, 135 новых пинов.
- **Отбор.** CLIP-поиск по библиотеке (13 запросов, в том числе по Are.na), затем ручной просмотр оригиналов.
- **Исключены** источники higgsfield, civitai и shotcafe.
- **Картинки** в git не кладём. Лицензия у всех — «только внутренний референс».
- **Поле `author`** — это тот, кто сохранил пин, а не дизайнер.
- **refId** — по нему референс находится в библиотеке Nullume.
- **Ссылки.** Если ссылка на пин не открывается, используйте ссылку «оригинал» (`i.pinimg.com`).

**Новое семейство стилей не заводил.** Все три секции — служебные блоки внутри
утверждённого кита: камень #F4F2EC, Montserrat и Golos, скругления как у панелей
cosmomedica. Новое семейство раздробило бы главную.

**Рекомендация.** Схема 3.1: глубина через масштаб, наложение и мягкое
затемнение, без наклона. Наклон 3.2 и 3.3 эффектнее, но спорит с MOTION_INTENSITY=3
и с «аптечной точностью».

Предлагаемые параметры:
- **Десктоп.** Видимы 5 карточек. Центральная около 300 × 533 px, со звуком по клику.
  - Масштаб соседей: ±1 — 0.84, ±2 — 0.70.
  - Сдвиг: каждая следующая перекрыта предыдущей примерно на 35 %.
  - Затемнение: `brightness` 1 / 0.85 / 0.7, края ленты уходят в фон градиентом #F4F2EC.
  - Боковые ролики стоят на паузе, показан постер.
- **Подпись.** Имя, город и средство под центральной карточкой, текстом, а не поверх видео.
  Две круглые стрелки-пилюли по центру под подписью, как в 3.1.
- **Переход.** 260 мс, ease-out. Автопрокрутки нет. При `prefers-reduced-motion`
  карточки переключаются без анимации масштаба.
- **Телефон.** Центральная карточка на 72 % ширины экрана, соседи видны по 12 % с каждой
  стороны (масштаб 0.88), переключение свайпом. Стопка из 3.5 — запасной вариант,
  если боковые края мешают.

## Где пусто
- Нет готового примера coverflow именно с видеоотзывами на светлом бьюти-сайте.
  Механику берём из 3.1 и 3.4, оформление постеров — из 3.8.
- Блоков новостей в бьюти-нише мало, поэтому образцы взяты из корпоративных сайтов
  (2.1, 2.2). Приём переносится без изменений.
