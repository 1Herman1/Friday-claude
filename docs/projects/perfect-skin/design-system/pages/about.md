## Правила

- Заголовки блоков — в левой колонке (4/12), текст справа ≤65ch; ниже md — одна колонка.
- Между блоками 96px (lg+) / 64px (мобайл); между абзацами 32px.
- Без появления при скролле, без count-up, без sticky. Только hover/active кнопок (MASTER §6).
- Фото без рамок и наложений, rounded-media: m16 — «Почему важен экспертный подход», m5 — «Система заботы».
- Система заботы — нумерованные ряды 01–04 на линиях border; без карточек и иконок-плиток.
- Роли — список-спецификация (капс-подпись / факт). Реквизиты — 14px muted. Финальная фраза — по центру.
- Одна залитая кнопка на экран — «Пройти тест»; остальные обведённые.
