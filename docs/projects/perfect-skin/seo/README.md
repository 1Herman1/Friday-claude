## Сбор

Wordstat через XMLRiver, регионы 225 (Россия) и 213 (Москва), по 202 фразы, около **12 ₽ за оба прогона**.

Как читать частоты:

- **Широкое соответствие.** Wordstat отдаёт число показов по всем фразам, где есть эти слова. «Крем для лица» = 491 680
  включает и «ночной крем для лица», и «тональный крем для лица». Поэтому частоты внутри страницы не складываются
  напрямую: в листе «Страницы» фраза, у которой есть более короткий «родитель» с числом, не суммируется.
- **В столбцы частот записано только точное совпадение** текста запроса. Совпало у 117 из 202 исходных (РФ) и 116 (Москва);
  у всех 202 новых — по определению.
- **Не совпавшие отмечены в столбце «статус частоты»:**
  43 — Wordstat не вернул ни одной фразы (спрос ниже порога, ≈0) — это все брендовые и навигационные запросы;
  17 — та же фраза с другим порядком слов или в другой словоформе («лифтинг крем для лица» = «крем лифтинг для лица», 4 929) — число в статусе;
  21 — запрос входит в более длинную фразу («bha кислота» ≥ 896 по «bha кислота это») — в статусе нижняя граница;
  4 — совпадений нет вовсе.
- **Москва, «крем для век»** — сбой ответа XMLRiver, нужен перезапрос одной фразы.
- **Загрязнённые частоты** (число есть, но интент чужой) в приоритет не входят: «крем с озоном» (маркетплейс Ozon),
  «крем с пчелиным ядом» (кремы для суставов), «glacee» (духи Kenzo).

## Как считался приоритет

Спрос сам по себе ничего не решает: топ-1 по «крем для лица» магазину двух брендов недоступен — там маркетплейсы,
сети и массовые бренды. Поэтому индекс страницы = **достижимый спрос × k × f**:

- **достижимый спрос** — сумма частот без двойного счёта, **без голов** (запросы ≥ 15 000 показов, их 31) и без
  медицинских запросов (прыщи, купероз, постакне — там аптеки и клиники, а лечебные обещания косметике запрещены);
- **k — шанс попасть в топ-10**: ниша и бренд — 1,0; B2B «для косметологов» — 0,6; статьи — 0,5; подборки по задаче
  и активу — 0,4; главная — 0,3; категории — 0,25; общий каталог — 0,15;
- **f — покрытие ассортиментом**: 1,0, если товаров хватает; 0,5 — один-два товара (ретинол, витамин C, флюид, мужской
  уход); 0 — товаров нет (SPF).

k и f — оценка, а не факт выдачи. Сбор выдачи Яндекса проверит её: где в топ-10 есть специализированные магазины,
k поднимется, где сплошь маркетплейсы — упадёт.
