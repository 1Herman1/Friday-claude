## Самозанятые (НПД)

У плательщиков НПД нет ОКВЭД: DaData по ИНН физлица вернёт пустой список. Не отбраковывать автоматически: помечать статус «самозанятый — проверить вручную» (фото диплома/сертификата косметолога, ссылка на кабинет/соцсети). Статус НПД проверяется по ИНН через сервис ФНС `npd.nalog.ru`. Косметологи на НПД — заметная доля покупателей кабинетных фасовок.

PS_OKVED_PREFIXES=96.02,86.22,86.90.3,86.90.4,86.90.9
