# Задача для Hermes: референс девушки для обложки новости 561

Сайт beautymedgroup.ru, новость «Впервые в России космецевтические бренды
ISSEIMI & GLACEE Skincare от HEBER FARMA (Испания)». Нужна новая обложка с
красивой девушкой; генерирует Claude через Nullume (nano-banana-edit), от тебя —
референс.

## Что найти

2–3 фото-референса: девушка 25–35 лет, ухоженная сияющая кожа, естественный
макияж, крупный или средний план, светлый фон, мягкий дневной свет, премиальная
космецевтика (уход, сыворотка, капля на коже — по желанию). Формат кадра
горизонтальный, 4:3.

## Правила (по новости уже была досудебная претензия за чужое фото)

- Референс задаёт **позу, свет, кадр и настроение**. Лицо на обложке будет
  новым, вымышленным — узнаваемое лицо реального человека не копируем.
- Брать с бесплатных стоков с правом коммерческого использования: Unsplash,
  Pexels. Знаменитостей, моделей из рекламы брендов, кадры из Instagram — нет.
- На референсе не должно быть логотипов и упаковок брендов.
