# Вымышленные AI-иллюстрации — candid v2

Четыре отдельных оригинала, созданных нативным image_gen через авторизованный Codex CLI. Это вымышленные AI-персонажи, НЕ реальные медицинские специалисты и НЕ авторы отзывов. Имена, квалификации, реальные отзывы и рейтинги не приписывались. Не опубликовано; сайт не изменялся. Старый набор сохранён отдельно без изменений.

- `avatar-01.png` — запись в карту, взгляд вниз, стол и дневной свет.
- `avatar-02.png` — обсуждение каталога, взгляд вправо, тёплый интерьер.
- `avatar-03.png` — подготовка средств на подносе, профиль влево, прохладный свет.
- `avatar-04.png` — объяснение на семинаре, взгляд влево, жест и флипчарт.
- `preview-sheet.jpg` — монтаж 2×2 с маркировкой AI01–AI04 только для просмотра; исходники не получены разрезанием коллажа.
- `prompt.txt` — исходные задания четырёх запусков.
- `generation-manifest.json` — фактические нативные tool-вызовы, session/event IDs, пути первичных артефактов, размеры, SHA-256 и визуальная проверка. Base64 событий не копировался.

## Проверка

Все четыре PNG открыты отдельно и визуально проверены: направления взгляда, действия, окружение, возрастная текстура и видимые кисти. Явных лишних/сросшихся пальцев не обнаружено. Байты каждого файла побайтно совпали с декодированным результатом соответствующего completed native event; SHA-256 всех четырёх различаются. Размеры указаны в manifest.

## Ограничения

Это фотореалистичные AI-иллюстрации, а не реальные документальные фотографии. Полностью исключить мелкие синтетические артефакты нельзя. В AI04 флипчарт находится с другой стороны кадра относительно запрошенной; сцена семинара, взгляд и жест соблюдены. Интерьеры остаются довольно аккуратными, но это четыре разные рабочие ситуации. Повторная генерация не потребовалась. Один CLI выдал сообщение об оборванном MCP-транспорте уже после сохранения изображения; итоговый код выхода 0, PNG и нативное происхождение проверены.
