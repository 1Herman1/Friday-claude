# Aequitas — план семантики, этап 1

Дата: 20.10.2026. Регион: Яндекс, `lr=1` (Москва и область). Список запросов —
`queries.txt` (296 запросов, 25 групп). Сбор: частотность Wordstat + топ-10
выдачи через XMLRiver. Это гипотезы, а не факты: направления выбираем по данным.

## Объём и деньги

296 запросов × 2 вида сбора (Wordstat + выдача) = ~592 платных обращения плюс
повторы упавших. Смету по текущему тарифу XMLRiver показать владельцу до запуска;
если не влезает в ~500 ₽, первыми резать группы 23, 25, 13, 14 (низкий приоритет
для юрлиц и сайта-визитки), а не ИИ-группы — их проверка и есть цель.

## Зачем какие группы

| Группы | Зачем |
|---|---|
| 01–03 общие и премиум | Масштаб ниши и кто держит топ: агрегаторы (вероятно Правовед.ру, 9111.ру, Профи.ру), крупные фирмы или частники. Есть ли спрос на «лучший/премиум» |
| 04–08 договоры, долги, арбитраж, корпоративные, банкротство | Ядро для юрлиц (приоритетная аудитория). Ищем направление с хорошим спросом и без засилья агрегаторов |
| 09–18 остальное гражданское право | Широкая сетка, чтобы не выбирать наугад. Часть уйдёт как вторичная практика или контент |
| 19–20 ИИ и цифровые споры | Гипотеза владельца: свободная ниша |
| 21 симптомные | «Приёмное отделение» сайта и основной формат для ИИ-цитирования |
| 22–24 инструменты | Калькуляторы и ноу-хау-сервисы: неудовлетворённый спрос |
| 25 выбор и доверие | Последний шаг перед заявкой; что важно клиенту при выборе |

## Гипотезы для проверки

1. **Юрлица.** Запросы взыскания долгов, арбитража и корпоративных споров
   дают меньше агрегаторов в топе, чем физлицевые (наследство, развод, потребители).
2. **Субсидиарная ответственность и споры участников ООО** — средний спрос,
   высокий чек, топ у профильных фирм, а не у агрегаторов: кандидат в главное
   направление.
3. **ИИ-споры.** Прямой коммерческий спрос близок к нулю; информационные
   («кому принадлежат права на картинку нейросети», «дипфейк что делать»)
   ненулевые, а выдача слабая (СМИ, форумы). Если так — ниша для GEO и
   экспертного контента, а не для коммерческих страниц. Если коммерческий
   спрос есть — это ценнее любой другой находки.
4. **Маркетплейсы.** Блокировки и штрафы селлеров — живой спрос малого бизнеса,
   топ у специализированных юристов-одиночек; проверить как второе нишевое
   направление рядом с ИИ.
5. **Калькуляторы.** «Калькулятор неустойки», «395», «госпошлина» — высокий спрос,
   но топ, вероятно, у КонсультантПлюс, Гаранта и готовых calc-сервисов. Шанс есть там,
   где топ слабый: неустойка по ДДУ, действительная стоимость доли ООО,
   индексация присуждённых сумм, судебные расходы.
6. **Ноу-хау** («оценка шансов выиграть суд», «во сколько обойдётся суд»,
   «сколько длится арбитражный суд») — спрос небольшой, готовых инструментов
   в топе нет. Если выдача отвечает статьями — инструмент заберёт и топ, и ИИ-цитаты.
7. **Выезд к клиенту** — отдельно не собирали: спрос на «адвокат с выездом»
   покажет, стоит ли выносить это в позиционирование.

## Что смотреть в данных на этапе 2

1. **Частотность по группам** — сумма показов на группу, а не по запросам.
2. **Доля агрегаторов и юрсервисов в топ-10** по каждому запросу (как
   в ветклинике): >60% — входа сайту нет, только карточки и площадки.
3. **Тип топа**: коммерческие страницы фирм / статьи / госсайты и
   Консультант. Статьи в топе коммерческого запроса = слабая конкуренция.
4. **Колдунщики и блок ответа Яндекса** (быстрые ответы, Нейро) — где Яндекс
   отвечает сам, там важна цитируемость, а не клик.
5. **Повторяющиеся домены** по всем 296 — карта реальных конкурентов
   в органике (вероятно, не те, что в `competitors.md`: там федеральные фирмы).
6. **Список popular из ответов Wordstat** — бесплатный хвост семантики:
   разобрать целиком и добавить в анализ все фразы, а не только точные совпадения.
7. **Пустые ответы Wordstat.** В ветклинике 97 из 117 вернулись пустыми — тогда
   длинные фразы с «москва» оказались ниже порога учёта. Здесь в каждой группе
   есть короткие «головы»; пустой хвост сверять с popular-списком головы,
   прежде чем объявлять «спроса нет».
8. **Итог этапа 2** — 2–3 основных направления (с упором на юрлиц) + 1 нишевое
   (ИИ или маркетплейсы, если данные подтвердят) + 2–3 инструмента для
   разработки. Решение — за владельцем, на цифрах.

## Ограничения

- Яндекс.Директ (стоимость клика) не собираем — инструмент его не даёт.
- Реклама адвоката — по Кодексу профессиональной этики: в семантике «лучший»
  и «рейтинг» — только для замера спроса, в текстах сайта такие формулировки
  запрещены (сравнение с коллегами).
- Уголовное и административное право исключены по брифу.
