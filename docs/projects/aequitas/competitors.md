# Aequitas — разбор конкурентов

Дата: 18.10.2026. Источник: Firecrawl (markdown + branding + полностраничный снимок
главной), плюс страницы контактов. Снимки — `references/competitors/`
(`pgplaw.png`, `bartolius.png`, `epam.png`). Hex — из branding-извлечения,
сверены со снимками.

Важная оговорка по масштабу: все три — крупные федеральные фирмы (100+ юристов,
рейтинги Chambers/Legal 500). Их сайты продают **репутацию и масштаб**, а не
консультацию. Ни на одном нет формы заявки. Aequitas решает другую задачу
(заявка от юрлица/физлица по гражданскому делу) — копировать их структуру
нельзя, брать можно только тон и приёмы.

## 4. Общий вывод

### Норма рынка (повторение = незаметность)
- Hero-слайдер / баннер с новостью или наградой вместо ценности для клиента.
- Новости, мероприятия, аналитика на главной — сайт как пресс-центр.
- Лента логотипов рейтингов и блок «цифры» (годы, юристы, клиенты).
- «Юридические» цвета: бордо/пурпур/золото-жёлтый на белом или тёмном.
- Ноль пути к заявке: телефон в шапке и «Контакты». Все трое продают масштаб,
  клиент сам знает, куда звонить.
- Карусели, «Подробнее», капс-заголовки секций.

### Пустое место для Aequitas
1. **Сайт, который начинается с вопроса клиента**, а не с фирмы. Ни один из трёх
   не говорит с человеком, у которого спор с подрядчиком, наследство или
   долг контрагента. Путь «моя ситуация → как это решается → заявка» на рынке
   свободен.
2. **Заявка как часть идеи**, а не форма в подвале. Метафора весов просится в
   интерфейс: клиент «кладёт на чашу» свою ситуацию — короткая форма в 3 поля
   (по профилю «Lead magnet + Form» из `design-profiles.md`).
3. **Инструменты как продукт**: калькуляторы (неустойка по 395 ГК, госпошлина,
   срок исковой давности, пени по ДДУ) — их нет ни у кого из трёх, это и SEO,
   и демонстрация точности. Визуальный язык надо заложить сразу, чтобы
   инструменты не выглядели пристройкой.
4. **Адаптив и доступность**: эталон владельца (Бартолиус) не адаптивен и с
   низким контрастом. Сделать «их настроение» на телефоне — уже отличие.
5. **Справедливость, понятая не как Фемида.** Девиз Бартолиуса уже занял
   «справедливость» словом; Фемида с повязкой и весами — клише всего рынка
   юруслуг. Свободно: справедливость как **равновесие, мера, точность** —
   инженерная, а не аллегорическая.

### Три направления концепции (выбор за владельцем)

**A. «Мера» — инженерная точность весов**
- Идея: справедливость = точное измерение. Не статуя, а прибор: тонкие линии
  коромысла, шкалы, деления, риски. Сайт как чертёж/лабораторный журнал;
  калькуляторы органично продолжают тему («отмерим вашу неустойку»).
- Палитра: тёплая бумага (слоновая кость) + графит вместо чёрного, один
  акцент — латунь/приглушённая бронза для делений и активных состояний;
  ошибки/успех — отдельной семантикой.
- Типографика: строгая антиква с острыми засечками для заголовков (новая, не
  Georgia) + моноширинный для цифр, номеров статей, дат; гротеск для текста.
- Моторика: стрелка весов приходит в равновесие при скролле (ease-out, без
  bounce), деления «прорисовываются». Dials: VARIANCE 5, MOTION 5, DENSITY 4.
- Настроение: спокойная уверенность, «у нас всё посчитано».

**B. «Равновесие» — две чаши, асимметрия, приходящая в баланс**
- Идея: композиция каждой секции построена на двух неравных массах
  (крупный текст ↔ пустота, тёмное ↔ светлое), которые выравниваются.
  Hero: две половины экрана «ваша позиция / позиция оппонента»; форма
  заявки — правая чаша. Юрлица и физлица — две чаши навигации.
- Палитра: глубокий тёмно-зелёный или чернильно-синий (не бордо, не пурпур —
  свободно у конкурентов) + тёплый светлый; акцент — холодное серебро/олово.
- Типографика: широкий гротеск крупно (близко по духу к Бартолиусу, но не
  тот же) + классическая книжная антиква для длинного текста.
- Моторика: секции «переваливаются» — горизонтальный сдвиг масс при скролле,
  scroll-driven, с отключением при `prefers-reduced-motion`.
  Dials: VARIANCE 7, MOTION 6, DENSITY 3.
- Настроение: драматургия спора, но с ощущением, что исход взвешен.

**C. «Aequitas» — римское право, камень и надпись**
- Идея: латинское имя как отсылка к римскому праву: эпиграфика, высеченные
  буквы, мрамор/травертин крупным планом (фактура, а не колонны), латинские
  максимы как подзаголовки («Aequitas sequitur legem») с русским переводом.
  Ближе всего к настроению Бартолиуса (классика + современность), но через
  материал и надпись, а не через портрет.
- Палитра: светлый камень (травертин), тёмный базальт для текста, акцент —
  терракота/охра римской штукатурки.
- Типографика: капитель в духе римского квадратного письма для заголовков
  (с кириллицей — проверить по `typography-pairs.md`), сдержанный гротеск
  для текста, моно — для номеров статей ГК.
- Моторика: медленное «проявление» надписей (clip/opacity 400–600мс),
  минимум движения. Dials: VARIANCE 4, MOTION 3, DENSITY 2.
- Настроение: вечность закона, торжественно, но не музейно.

Риски по направлениям: A — легко скатиться в «техно-SaaS», нужна тёплая
фактура; B — самое сложное в вёрстке и адаптиве; C — ближе всего к клише
«античной юрфирмы», держится только на качестве фото камня и шрифта.

## 5. Юридические детали рынка (кратко)

- **Формы заявок и согласия на ПД** — не встретились: форм нет ни на одном
  сайте, сравнить формулировки согласий не с чем. У Aequitas форма будет —
  отдельный чекбокс согласия, ссылка на политику, без предзаполнения
  (проверка `rkn-compliance`).
- **Cookie**: pgplaw — плашка с упоминанием Яндекс.Метрики и ссылками на
  согласие на обработку ПД через cookie (`/cookies/`) и Политику обработки ПД
  (`/personal-data/`), кнопка «Продолжить» (модель «используя сайт —
  соглашаетесь»). Бартолиус — плагин CookieYes с категориями, но экран
  настроек **на английском**, ссылка только на политику cookie, политики
  обработки ПД в футере не видно.
- **Политика ПД**: ЕПАМ — две политики в футере (общая и для данных адвокатов
  и работников) + дисклеймер «материалы не являются юридической консультацией»;
  pgplaw — «Политика обработки персональных данных» и «Правовая информация»
  в футере; Бартолиус — нет.
- **Реквизиты** (ИНН/ОГРН/рег. номер в реестре адвокатов): на главных не
  найдены ни у кого — только адрес, телефоны, почта, © с годами. Для
  Aequitas реквизиты оператора в футере и в политике обязательны.
- Наблюдение: Бартолиус и ЕПАМ — **адвокатские бюро** (реклама адвокатов
  ограничена Кодексом профэтики: без сравнений «лучшие», без гарантий
  результата). Если Aequitas — ООО, а не адвокатское образование, этих
  ограничений меньше, но запрет на гарантии исхода дела и недостоверную
  рекламу (38-ФЗ) действует. Уточнить у владельца форму организации.
