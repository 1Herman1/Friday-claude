# Проект: Aequitas (домен — не выбран)

Специфика проекта. Универсальные правила, агенты и воркфлоу — в `CLAUDE.md` и
`docs/core/`. Здесь — только то, что относится именно к этому проекту.

**Что это.** Сайт юридической фирмы «Aequitas» (лат. «справедливость»):
визитка, запись на консультацию и сбор заявок. Второй этап — бесплатные
онлайн-инструменты для людей, которые ищут решение своей правовой проблемы
в поиске (калькуляторы, конструкторы документов). Они дают поисковый трафик
так же, как калькулятор кубометра доски — сайту стройматериалов.

**Клиент.** Глеб, владелец юрфирмы. Практика: гражданское право, клиенты —
юрлица и физлица. Уголовными делами фирма не занимается — на сайте этого быть
не должно.

**Главная цель проекта — идея в дизайне.** Сайт должен передать мысль автора,
суть услуги и настроение, а не быть «ещё одним сайтом юристов». Конкуренты для
разбора — `competitors.md` (предпочтительны pgplaw.ru и bartolius.ru).

**Название.** Латинское «Aequitas» людям непонятно, нужна русская опора
(«бюро», «группа», «юридическая компания» — решает владелец, см. `brand.md`).

## Правовой контур (для агента `rkn-compliance`)

Универсальные требования — в `docs/core/rkn-compliance.md`. Здесь только факты,
которые нельзя вывести из кода.

**Незаполненное поле агент считает находкой уровня ВАЖНО, а не «проблем нет».**
Прочерк ставится осознанно, с объяснением.

- Оператор ПД: не известен — запросить у Глеба (ООО/ИП, ИНН, ОГРН, адрес)
- Контакт по вопросам ПД: не известен
- Ответственный за организацию обработки: не известен
- Уведомление в РКН: не известно — спросить, подано ли
- Карточка в реестре операторов: не известно
- Хостинг: не выбран (обязательно РФ)
- Физическое расположение БД: не выбрано
- Бэкапы: не выбрано
- Трансграничная передача: не должно быть — шрифты, капча, аналитика только без зарубежных сервисов
- Сервисы, обрабатывающие ПД: не выбраны (куда уходит заявка — почта, CRM, Telegram)
- Категории собираемых ПД: имя, телефон, email, описание ситуации (в описании возможны чувствительные сведения — предупредить в форме)
- Сроки хранения по категориям: не определены
- Способ авторизации: нет (личного кабинета нет)
- Cookie и аналитика: не решено (Яндекс.Метрика — с баннером)
- Интернет-реклама: не известно; реклама юруслуг — общие требования 38-ФЗ, обещания «выиграем дело» недопустимы
- Рекомендательные технологии: нет
- Отраслевые и возрастные ограничения: если в фирме есть адвокаты — ограничения адвокатской этики на рекламу; уточнить статус
- Дата последней проверки комплаенса: не проводилась

## Домены проекта (бизнес-логика)

- Услуги: гражданские споры, сопровождение юрлиц и физлиц. Уголовных дел нет.
- Заявка: кто (юрлицо/физлицо), суть вопроса, контакт, удобный способ связи.
- Инструменты (этап 2): каждый — отдельная страница под поисковый запрос, расчёт в браузере, после результата — мягкий переход к консультации.
