Первые 90 дней

Что происходит по месяцам

Месяц 1

Мы: бесплатный прототип, распаковка, текст без медицины, досье, визитка, карта рекомендателей

Вы: ИП, список своей базы, 2–3 часа интервью, фото

Месяц 2

Мы: набор для партнёров, закрытый Telegram, договоры с юристом

Вы: личные сообщения 10–20 клиентам о переходе на абонемент

Месяц 3

Мы: 10–15 встреч с агентствами, консьержами, клубами; ассистент и учёт

Вы: встречи вместе с нами, пробные сеансы рекомендателям

К концу 6-го месяца: 2–3 семьи на абонементе, 3 активных рекомендателя, выручка от 470 тыс. ₽ в месяц (оценка).

План пути 1

Студия не получает персональные данные клиентов Андрея при составлении списка базы: только сегменты и количество. Встречи с посредниками проводим вместе — его руки и есть аргумент: пробный сеанс рекомендателю.
