Три пути развития

Путь 1

Тихий люкс

3–5 семей платят абонемент на месяц вперёд. Новых приводят те, кому семьи доверяют. Публичности почти нет

Путь 2

Публичный мастер

Имя в Telegram, медиа и интервью. Клиенты ищут вас по имени, цену держит репутация

Путь 3

Метод и мир

Название метода с товарным знаком, ритуал для одного отеля, сезоны на курортах, 1–3 ученика под NDA

Пути не исключают друг друга: вы выбираете основной на первые полгода, остальные можно добавить позже.
