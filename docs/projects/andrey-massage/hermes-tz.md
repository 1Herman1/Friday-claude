## 1. Зачем

Андрею мы предлагаем не один путь, а **три пути развития на выбор**. По
собранному материалу облачная сессия Claude сделает презентацию «Три пути»
для Андрея. От Hermes нужны две вещи:

- **Блок А — исследование**: по каждому пути одинаковый набор фактов, кейсов,
  цифр и шагов, чтобы пути можно было честно сравнить.
- **Блок Б — референсы**: визуальный стиль презентации из Nullume и Pinterest
  (это работает только на Mac).

Итог — «кластер»: набор файлов фиксированной структуры (раздел 7), который
Гермес передаёт Claude.

## 3. Ограничения (не нарушать ни в одном пути)

- Медицинского образования у Андрея нет. Никаких «остеопатий», «лечения»,
  «реабилитации», отзывов «исцелённых».
- Никаких контактов частных лиц, холодных рассылок семьям, массовой рекламы.
- Instagram — без рекламы (запрещена с 01.09.2025).
- Андрей изначально **не хочет раскрывать технологию коллегам**. Путь 3 строится
  только на закрытых форматах: протокол для одного партнёра, наставничество
  1–3 учеников под NDA. Открытые курсы, онлайн-школы, франшизу не предлагать.
- Цифры — только с источником; иначе пометка «оценка».
- Секреты и персональные данные в файлы не писать.

## 4. Три пути развития

Пути не исключают друг друга: каждый — что делаем **в первые 6 месяцев**.
Андрей выбирает основной путь, остальные можно добавить позже.

### Путь 1. «Тихий люкс» — личный мастер нескольких семей
Москва, 3–6 семей на абонементе, клиенты только по рекомендации через
«привратников»: агентства персонала, консьержей домов и посёлков, клубы,
тренеров, частных врачей. Публичности почти нет: закрытый Telegram, визитка,
досье.

### Путь 2. «Публичный мастер» — личный бренд в соцсетях и медиа
Имя Андрея становится известным: Telegram-канал с открытой частью,
Instagram-визитка на английском, VK, YouTube/Rutube, коллаборации, интервью,
публикации в медиа о велнесе. Цель — чтобы его искали по имени, а цена
держалась репутацией. Нужна готовность показывать лицо и голос.

### Путь 3. «Метод и мир» — авторский протокол и сезоны за рубежом
Название метода как бренд (товарный знак). Авторский ритуал для одного отеля
или клуба по лицензии с переаттестацией, сезонные резиденции приглашённого
мастера (Мальдивы, ОАЭ, шале, яхты), закрытое наставничество. Нужны
международный сертификат (ITEC/VTCT/CIDESCO) и английский.

## 5. Блок А — что собрать по каждому пути

Для **каждого из трёх путей** — один и тот же набор, чтобы сравнение было
честным:

| № | Что | Детали |
|---|---|---|
| А1 | Суть в одной фразе | Как объяснить Андрею за 10 секунд |
| А2 | Кейсы | 3–5 реальных кейсов (РФ и мир): кто, что сделал, цифры, ссылка. Для пути 2 — русскоязычные мастера и велнес-специалисты с публичным брендом; для пути 3 — приглашённые мастера курортов, авторы протоколов в отелях (Joanna Czech и аналоги) |
| А3 | Экономика | Доход Андрея через 6 и 12 месяцев (диапазон), его вложения, сколько его часов в месяц уходит не на сеансы |
| А4 | Шаги по месяцам | Месяцы 1–6: что делает студия, что Андрей, что подрядчики |
| А5 | Требования | Документы, сертификаты, язык, публичность, деньги на старт |
| А6 | Риски | 3–5 рисков и как их снижать |
| А7 | Сигналы успеха | 3 измеримых KPI с целевыми значениями к 6 месяцу |
| А8 | Роль H&B и цена | Какие услуги студии нужны в этом пути; рыночная вилка цен со ссылками (опираться на `research/03`) |
| А9 | Кому подходит | При каких ответах Андрея этот путь лучший |

**Общие пробелы**, которые нужно закрыть (ранее не найдено):
- комиссии агентств элитного персонала, консьерж-служб и спа-директоров
  за привод мастера;
- условия программ visiting practitioner на Мальдивах: доля курорта, как
  подать заявку, требования;
- цены B2B-обучения персонала отелей авторскому протоколу и закрытого
  наставничества;
- кейсы продюсирования **офлайн**-специалистов премиум-уровня (массажисты,
  косметологи, тренеры): кто продюсер, этапы, оплата;
- право: лимит НПД на 2026 год; считается ли рекламой пост мастера о своих
  услугах в своём Telegram (ERID); пошлины Роспатента за товарный знак.

**Сравнительная таблица** трёх путей: доход через 6 и 12 месяцев, вложения,
часы Андрея вне сеансов, публичность (нет / средняя / высокая), скорость
первого результата, главный риск, цена услуг H&B.

## 6. Блок Б — референсы для презентации (Nullume, только Mac)

Задача: найти визуальный язык презентации «Три пути» для массажиста
люкс-сегмента. Нужен «тихий люкс», а не спа-салон: спокойный, тактильный,
дорогой, без эзотерики, лотосов, камней, свечей и фиолетового.

### Подготовка (один раз)
```
cd ~/Friday-claude && git pull
export NULLUME_LOCAL_IMPORTERS=1
nullume lib session set pinterest-cookies --cookie "_pinterest_sess=ЗНАЧЕНИЕ"   # если сессия устарела
```

### Сбор (запросы только по-английски: CLIP не понимает кириллицу)
```
for q in \
  "quiet luxury wellness presentation" \
  "luxury spa brand identity minimal" \
  "massage therapist personal brand editorial" \
  "bodywork hands black and white photography" \
  "aman resort spa brand design" \
  "luxury wellness pitch deck" \
  "premium personal service brochure design" \
  "tactile linen stone texture minimal layout" \
  "editorial serif wellness magazine layout" \
  "private concierge brand identity"; do
  nullume lib import pinterest-cookies --query "$q" --limit 30
done
nullume lib search "quiet luxury wellness editorial" --limit 24
```

### Обработка
- `taste-curator` (`.claude/agents/design/taste-curator.md`): кластеризация
  (`nullume lib clusters`), семейства с тегом `andrey-massage`,
  `nullume lib propose`. Для каждого семейства — дескриптор: палитра (HEX),
  типографика (шрифты с кириллицей — сверить с `docs/core/typography-pairs.md`),
  фотостиль, композиция, настроение.
- Отобрать **2–3 семейства-кандидата** и по 5–8 лучших референсов на каждое.
- Экспортировать превью отобранных референсов в
  `docs/projects/andrey-massage/references/img/` (jpg/webp, до 1 600 px по
  длинной стороне, до 300 КБ каждый) — облачная сессия Pinterest не открывает,
  ей нужны сами картинки.
- Просмотр: `nullume lib dashboard --open`.
