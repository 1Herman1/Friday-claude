# Профиль безопасности: <название проекта>

Карта стека для агентов `security-*`. Универсальные классы уязвимостей живут в
`docs/core/anti-patterns/security.md` — здесь только то, как эти классы
выглядят **в этом конкретном проекте**.

Заполняется один раз при заведении проекта: `/security-profile` сканирует
кодовую базу и генерирует черновик, дальше правится руками.

Правило: агент без этого файла работать может (определит стек сам), но будет
менее точен и обязан об этом предупредить.
