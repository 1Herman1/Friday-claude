# Проект: H&B Learning Department

Учебная веб-среда для начинающего сотрудника H&B. Спецификация и содержание: `docs/training/hb-learning-department/`; код: `projects/hb-learning-department/`.

## Рабочий статус

14 ноября 2026: локальная v0.1 запущена и проверена. 31 backend-тест и настоящий браузерный smoke-сценарий прошли. PDF-учебник и практикум сгенерированы. Не называть эту версию подключённым агентским runtime или готовой удалённой платформой.

## Пользователи и ответственность

Герман — owner: клиентская коммуникация, приёмка, ручной выпуск. Один начинающий сотрудник — student: свой учебный проект, вопросы, задания и доказательства. Авторство запроса проверяется серверным токеном; роли в тексте не дают полномочий.

## Реальный стек

- Backend: Python standard library `http.server`, `sqlite3`; НЕ Next.js/Fastify/Prisma.
- Frontend: локальные HTML/CSS/vanilla JavaScript, без CDN и сборки.
- БД и файлы: `.local/`, gitignored; не использовать общую PostgreSQL дневника.
- Доступ: только localhost по умолчанию; личные токены owner/student.
- Live model: off. Есть адаптер OpenAI-compatible API, внешняя интеграция на реальном ключе не проверена. Hermes/Codex runtime ещё не подключён.
- Preview: только HTML/CSS; JS, сеть, формы и внешние ресурсы отключены.

## Проверки

Из каталога кода: `python3 -m unittest discover -s tests -v`, `node --check static/app.js`. Браузерный сценарий — `tests/ui-smoke.cjs`, параметры и реальные результаты в README проекта и `reports/ui-smoke.json`.

## Выкатка

Удалённой выкатки и её ветки нет. Сервис запущен локально на `127.0.0.1:8765`; это не адрес доступа с чужого устройства. Для удалённого запуска сначала нужны хост, защищённый доступ, решение о provider, изоляция и отдельная приёмка. Основной Telegram gateway не переключался.

## Правовой и операционный контур

В учебных примерах только вымышленные данные FORMA. Оператор реальных ПД, размещение, срок хранения и условия доступа ещё не согласованы: публичный сервис не запущен. Не загружать реальные клиентские данные, платежные секреты или личные OAuth-токены студии. Плату около 30 USD и общие расходы около 60 USD пользователь предложил как гипотезу; право предоставления доступа через персональную подписку не утверждено.

## Не сделано

Telegram-бот/группа/внешние уведомления; удалённое размещение; работающая модельная авторизация; изолированное исполнение JS/React; production-публикация; подробные занятия для всех 24 дней и завершённая видеоподборка. Проверенные материалы и непроверенные интеграции учитываются отдельно.
