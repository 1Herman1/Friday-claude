# H&B Learning Department — визуальное направление v0.1

Первое предложенное оформление, не утверждённый фирменный стандарт всей студии.

- Название продукта: H&B Learning Department; учебная роль — Tutor.
- Язык интерфейса и объяснений: русский, технические обозначения с расшифровкой.
- Характер: спокойный рабочий инструмент, ясное разделение урока, диалога, файлов и приёмки.
- Тёмный фон `#101313`, поверхность `#171b1b`, основной текст `#e6ece8`, вторичный `#9daea6`, акцент `#b7d9ac`, границы `#2a3331`.
- Системный шрифт с кириллицей, моноширинный редактор; без внешних шрифтов и CDN.
- Постоянные подсказки честно показывают: локальная версия, live-наставник off, preview только HTML/CSS, production отдельно разрешает владелец.
- Мобильная компоновка проверена в Chromium на 390 px; это не подтверждение всех браузеров и ассистивных технологий.
- PDF: светлая полоса чтения, тёмно-зелёные заголовки, встроенные Unicode-шрифты, оглавление и кликабельные источники.
