## Бизнес

Ветеринарная клиника, упор на **хирургию**, позиционирование — премиум.

Адрес: 4-й Ростовский переулок, 1с1, Москва — район **Хамовники**
(Плющиха / Ростовская набережная, ЦАО).

Почему район важен: общемосковские запросы («ветеринарный хирург Москва»)
заняты сетевыми клиниками и агрегаторами, новому сайту там ловить нечего.
Локальные запросы менее конкурентны, а клиент по ним теплее — ищет рядом с
домом. Район премиальный, что совпадает с позиционированием.

## Инструменты аналитики

**XMLRiver** (`xmlriver.com`) — живая выдача Яндекса и Google, ИИ-ответы,
Wordstat. Аккаунт оплачен, тариф Basic, 25 ₽ за 1000 запросов по Яндексу,
10 потоков. Ключ — **только в секретах GitHub**, никогда в репозитории и
никогда в переписке.

**GEO/AEO рантайм** — в корне этого репозитория.
Даёт органику и ИИ-цитирование. **Частотности и бюджетов Директа не даёт** —
проверено по коду. Эти данные берутся из Wordstat и «Прогноза бюджета»
Яндекс.Директа (бесплатно, нужен аккаунт Директа).

**Сбор данных — через GitHub Actions** (`.github/workflows/geo-collect.yml`),
чтобы ключ не попадал в контекст сессии. Аналитика поверх собранных данных
делается в сессии, ключ для неё не нужен.
