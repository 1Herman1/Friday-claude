# Материалы студента — PDF v1

Редакция 14 ноября 2026.

## Готовые файлы

- `HB-Web-Development-Handbook.pdf` — 39 страниц, 18 глав, 100 терминов, упражнения и разборы, 26 кликабельных первичных источников. Основной авторский текст: 7 948 русских слов по регулярному выражению счётчика сборки, 9 204 слов/токенов с разделением пробелами вместе с английским кодом и списком источников. Это не перевод или копия одной статьи.
- `HB-Student-Workbook-24-Days.pdf` — 26 страниц, задания всех 24 дней и поля для собственных наблюдений и решения владельца. Основание — согласованный `../course.md`.

Сквозные примеры FORMA вымышленные; они не являются работающим внешним API, настоящими платежами или доказательствами выполненного учеником задания. Учебник объясняет основы, а практикум задаёт упражнения; готовность среды исполнения проверяется отдельно.

## Исходники

`handbook.md` — главы 1–9, `continuation.md` — главы 10–18 и словарь. `complete-handbook.md` собирает оба текста и сгенерированный список источников. `citations-ledger.json` задаёт соответствие номеров источникам; `source-verification.json` фиксирует HTTP-проверку 26 адресов без перепубликации полных внешних страниц.

Временные копии источников, длинные выдержки и растры визуального контроля остаются локально и исключены из Git. Не включать их в студенческий комплект.

## Сборка

Нужен Python с reportlab, pypdf и pypdfium2; окружение документов управляется Hermes, основной интерпретатор агента не изменяется. На macOS используется встроенная в систему Arial/Courier New с кириллицей; на Linux сборщик также ищет DejaVu. Не копировать системные файлы шрифтов в репозиторий.

```sh
hermes pm environment documents --extra documents --extra documents-pdf
```

Команда печатает путь к Python окружения. Из этого каталога запустить этим Python:

```sh
python build_handbook.py
python build_workbook.py
python -m unittest test_build_handbook -v
python verify_documents.py
```

В примере `python` означает именно полученный интерпретатор, а не произвольный системный Python. Для генерации списка источников сборщик использует установленный скрипт skill grounded-citations.

## Что проверено

- Обе книги открываются и содержат текст на каждой странице.
- Найдены все 18 глав, словарь со 100 пунктами и все 24 дня практикума.
- В учебнике найдены 26 уникальных внешних PDF link annotations.
- Четыре теста сборщика проходят: стабильные ключи оглавления между проходами, корректное экранирование бренда и обложки, отсутствие повторяющегося предупреждения в первом PDF. В его нижнем колонтитуле оставлены название учебника и номер страницы; второй PDF не изменён.
- Выборочно просмотрены обложка, оглавление, страница с React-кодом, источники и первая страница задания.
- Машинный результат: `verification.json`.

Выборочная визуальная проверка не означает ручное чтение каждой страницы каждым браузером. Видеоподборка к сложным занятиям пока не завершена и не объявляется частью готового PDF-комплекта.
