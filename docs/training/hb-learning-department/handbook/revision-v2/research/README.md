## Происхождение

Каталог `evidence/` — локальный gitignored-кэш полученных страниц и полных описаний: он не включается в Git и студенческий комплект. В репозитории остаются кураторские карточки, реестр и инструкция повторной проверки, а не перепечатки внешних материалов.

- `citation-ledger.json`: локальный реестр цитирования, не изменяет глобальную память/настройки Hermes.
- `evidence/source-01.txt` … `source-10.txt`: видимый текст подтверждённых публичных страниц; Siteinspire — из свежего браузера, остальные — HTTPS GET.
- `evidence/video-01-metadata.json` … `video-06-metadata.json`: проверенные ID, название, издатель, описание, длительность и языковые списки; oEmbed endpoint и статус. Временные URL субтитров не сохраняются.
- `evidence/retrieval-audit.json`: редирект Godly → Recent, ошибки и неудачные WAF-проверки, альтернативные источники и границы проверки.
- Два файла `evidence/https___*.txt`: текущие официальные страницы GSAP и Spline Academy, связывающие издателя с техническими роликами.

## Воспроизводимая проверка без авторизации

1. Получить локальную дату командой `date`.
2. Открыть официальный URL: сверить конечный URL, title и реальный контент. HTTP 200 с WAF-заголовком и пустой HTTP 202 не засчитываются.
3. При ошибке — проверить официальный альтернативный путь или свежий браузер; сохранить ошибку, не использовать личный профиль и не обходить вход/оплату. Если источник не подтверждается, заменить его, а не выдавать поисковый сниппет за просмотр.
4. Для YouTube сначала найти реальную ссылку, затем проверить oEmbed и standalone `~/.hermes/bin/yt-dlp --skip-download --dump-single-json --no-playlist URL`. Без cookies и скачивания видео.
5. Отдельно прочитать описание; список captions не равен проверенному транскрипту, `live_chat` не является субтитрами.
6. Проверить уникальность/число записей программно и прогнать локальный citation verifier.

Тарифы не изучались исчерпывающе. Необязательный аккаунт на странице не означает, что создание/экспорт/сохранение бесплатны. Полный просмотр и педагогическая оценка роликов остаются за преподавателем.
