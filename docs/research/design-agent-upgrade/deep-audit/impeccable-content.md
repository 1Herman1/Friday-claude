## 3. Базовый execution contract и содержательные правила

`skill/SKILL.src.md:20–33`: context один раз с cwd проекта → нужный playbook и incumbent visual truth → craft-floor непосредственно перед UI edits. Отсутствие DESIGN.md не обнуляет существующую identity. При отказе launcher не бесконечные retries: явно сообщить, прочитать existing PRODUCT/DESIGN и продолжить разрешёнными tools. `:30–32`: brief wins; refinement сохраняет content/behavior/world, redesign заменяет world, но сохраняет product truth; loaded hate/militarist symbols не использовать как декоративный мотив.

`craft-floor.md:5–17`: совместная проверка одного render, а не отдельный screenshot на каждый пункт: 4.5:1 body/placeholder, 3:1 large text; читаемый hierarchy/65–75ch, display max 6rem/tracking ≥−0.04em; spacing по computed values, above-heading > below; hover/loading/disabled/error/empty, focus и реальные working controls. Browser selection/caret/focus/underline/tabular numbers — часть системы, copy — часть дизайна. Motion — один authored focal moment, по умолчанию visible content, не одинаковый fade-rise на всех секциях.

`craft-floor.md:19–50`: distinguishes category defaults from hard bans: generic card/hero-metric/gradient/glass не становятся хорошими от привычности; отдельный **безусловный ban на eyebrow/kicker над заголовком**; не sidebar stripe, glyph/emoji icon set, geometric mask вместо настоящего органического контура. Codex-only добавляет border-or-shadow elevation, card radius 12–16px, запрет sketchy picture-SVG/случайных grids/stripes, factual honesty. Эти Codex priors не попадают в Hermes build. Не переносить все вкусовые запреты как общие WCAG требования.

### Visitor modes — не прежние доменные профили

`SKILL.src.md:35–44`, `operate.md:5–61`, `mode-*.md` полностью:

- **Persuade** — посетитель решает и действует. Концепция может владеть структурой, но категория-specific **working action** в первом экране: поиск маршрута/времени, запись, add-to-cart, а не декоративная ссылка. Offer/proof/CTA читаются в выбранной форме.
- **Experience** — сама работа с первого viewport, chrome отступает. Это не лицензия скрыть навигацию, a11y или управляемость.
- **Operate** — familiarity и скорость задачи; world даёт только type/palette/density/**один signature move**, не заимствует чужую навигацию/controls. Fixed rem scale, одна UI family допустима, semantic states и structural responsive. Ни «терминал-костюм», ни декоративное page-load шоу.
- **Read** — привычный документ/wayfinding, спокойная reading column около 60–75ch и 16px, world принадлежит frame/masthead/rail/code-tables, не выступает за текстом. Docs index остаётся Read, даже если продукт — fashion.

Friday profiles (`design-profiles.md:19–79`) уже отличают ecommerce/dashboard/SaaS и checkout. Это **partial**, не отсутствие контекстного дизайна. Дельта v4: mode задаётся **конкретной поверхностью**, а не продуктом целиком; SaaS landing и SaaS editor получают разные правила. `design-system.md:18–21` сейчас берёт категорийный шаблон до суждения, что может вернуть category default, против которого new-work и направлен.
