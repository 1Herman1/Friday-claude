### 1.1 `crates/core/src/browser/driver.rs:1601–3200`

Это не список запретов по словам, а согласование source findings с тем, что нарисовано:

- `1627–1691`: тёмная корневая поверхность определяется по непрозрачному html/body и luminance <0.1. ### 1.2 `quality.rs:1–1600` и `8001–8274`

Первый диапазон — инфраструктура геометрически честных текстовых измерений, не все ветки quality checker:

- Controls определяются не одним tabindex: focusable box ≤80 UTF-16 знаков может быть control, большая focusable region остаётся content (`77–110`). Поиск abutting fill ограничен 4 уровнями вверх, 6 вниз, 200 посещениями на сторону — это явно ограниченная эвристика.

Край, где clip отрезал >0.5px, — обрезание, не flush padding.
- Счётчик rendered characters обходит actual text nodes, сворачивает whitespace по стилю конкретного узла, исключает combining marks/format characters, уважает pre/pre-wrap/NBSP, atomic inline и BR. Вложенный список не удлиняет собственные строки родительского li (`1080–1321`).
- Хвост `8001–8274` — тестовые намерения именно этой модели: сохранённые отступы/хвосты, Devanagari, hidden child, content-visibility (inline/contents исключения), пробелы вокруг пустых img/input и hard break. ## 3. Что действительно стоит добавить Friday отдельной задачей

Все owners ниже — **предлагаемые**, не реально запущенные исполнители; findings передаются координатору открытыми. Сейчас никаких изменений правил/кода не сделано.

1. **P1 / screenshot evidence contract** — owner automator+qa, target `.codex/scripts/screenshot.mjs` и будущая receipt schema. Actual loaded URL/status, viewport/DPR/reduced-motion, verified click state, DOM/image/font readiness, input/content hashes, stability и explicit unavailable. Acceptance: delayed font/image/redirect/failed click/DOM mutation не выдаются за готовый снимок нужного state; frozen exact pixel crop отдельно от human acceptance. Не требовать весь native Rust stack ради этого delta.
2. **P1 / lexical false-positive boundaries** — owner design-lint maintainer, target `.codex/scripts/design-lint.mjs` и fixtures. Skip comments/literal examples, stateful selected stripe и decorative mock context; отчёт различает measured fact и regex suspicion. Acceptance: positive/negative JSX/CSS/Astro/comment/regex cases, непустой scanned set, rule IDs в structured output. Сейчас main всегда exit0 (`300`) и default scan толькоtsx (`269–272`): не называть его blocking compliance gate без отдельного контракта.
3. **P1 / loaded-media + fonts + selected target** — owner qa-engineer, target будущие browser fixtures и reviewer checklist. Missing primary font, ghost loaded image, broken decode, «Book this room» одинаковые без selected id; screenshot evidence до/после и RU fixtures. Existing visual duty уже есть: новый delta именно воспроизводимый probe, не ещё один абзац «проверять глазами».
4. **P2 / context-aware contrast+spacing adapter** — owner design-reviewer specification + automator implementation. Distinguish glyph band/clip/scroll edge, matte/photo/gradient unknown and parked underline. Acceptance: min target по brand/profile; 4.5 base/7 enhanced явно названы; unknown не проходит; fixture centered zero-padding не false-positive. 5. **P2 / review-tool state regressions** — owner qa-engineer, target существующий/будущий picker/review, только когда такой UI реально будет принят.
