### 1.1 `crates/context/src/serve_question.rs:1601–3200` — решение пользователя как протокол

**Вход/сервер.** Payload читается из файла с lossy UTF-8 либо stdin; невалидный `load_round` завершает кодом 1 (`1608–1625`). Bind только `127.0.0.1`, порт finite/nonnegative приводится к u16; bind error всегда подписан `EADDRINUSE`, даже если причина иная (`1627–1633`). Detached режим создаёт questions directory, локальный ignore и atomic state `{pid,port,url,startedAt,comps?}`; ошибки этих записей здесь игнорируются (`1637–1646`). По умолчанию открывается системный браузер: `open`, `cmd /c start`, `xdg-open`, detached stdio-null (`1651–1653`, `2079–2095`). Это реальный side effect предлагаемого upstream, не действие данного аудита.

**Время жизни.** Watchdog каждые 2 s: до первого heartbeat действует timeout_sec; после него idle_grace + `NEXT_CLAIM_GRACE_MS` относительно mtime next-file/last_claim; выход процесса 2 (`1655–1677`). Heartbeat отвечает 204 и обновляет память, disk lastBeat — не чаще одного раза за >4 s (`1723–1737`). Число idle_grace/claim grace в данном срезе не определено, поэтому не выдумываю.

**Граница HTTP.** Каждый запрос сначала проходит exact Host allowlist localhost/127.0.0.1 с текущим портом; отсутствие/чужой Host →403; для 80 разрешён host без суффикса (`1682–1693`, `1958–1971`). Detached POST обязан иметь query key →401 при несовпадении; присутствующий чужой Origin →403; отсутствие Origin разрешено, это защита от browser-origin запросов, не от локального процесса (`1976–1987`). URL target очищается от табов/CR/LF и C0 по краям; percent form decode, `+`=пробел (`1991–2059`). Body truncation на answer/build-path →413 (`1805–1817`).

**Файлы/изоляция.** `/img/<digits>` обслуживает только индексы объявленных local_images, отклоняет лишний pathname suffix, директории/отсутствие →404; MIME выбирается по суффиксу, fallback JPEG (`1747–1774`). `/sketch/<index>` проверяет принадлежность текущей hand, не просто existence. CSP `default-src none`, network закрыт кроме Google Fonts, `img data/blob`, sandbox без same-origin, `form-action none`, `base-uri none`, no-store/nosniff/no-referrer. Raw view запрещает scripts; skeleton view разрешает inline scripts (`1776–1803`). Это существенно сильнее простого iframe на локальном origin. Skeleton после fonts.ready или 2500 ms заменяет текст <22 px полосами; дисплейный текст остаётся, ready посылается родителю (`2119–2123`).

**Выбор и persistence.** `/build-path` принимает только comp/code; переход к comp создаёт flip-file **до** HTTP ACK, обратный переход не вызывает генерацию (`1819–1838`). `/answer` формирует optionId/steer, reroll register только safer/bolder; followup только detached. Hero/board/comp берутся из chosen card; html включается лишь при свежей hand и когда comp не заменил sketch face (`1843–1886`). Telemetry disabled проверяется до ledger claim, seed digest обязан совпасть; ping отправляется в отдельном thread, confirm/release не должен ломать round (`1895–1908`, `1926–1935`). Answer пишется в questions либо stdout. Reroll/followup держат сервер, обычный ответ после 150 ms и join ping завершает 0 (`1910–1945`).

**Визуальный контракт страницы.** `load_round` требует только непустой options array. Canon card получает id canon; declined уезжают после остальных; HTML URL не загружается как sketch (`2196–2283`). Comp face имеет приоритет перед HTML; code-led отключает его, сохраняя резерв. Inspiration явно подписана «не то, как будет выглядеть ваша страница» (`2301–2308`, `2361–2364`, `2390–2435`). Frame принимает `390x844`, ×, [w,h]; оба размера 200..4000, иначе1440×900 (`2128–2137`). Portrait при h>1.05w. Wireframe только без media/declined: default12×10, до12 регионов, min dimension .5, проценты clamp0..100 (`2453–2483`). Palette до6 swatches, materials до4, raises до6; несколько raises — keyboard-focusable role button и aria-live (`2316–2358`). Выбор canon/declined подписан Play it straight/Adopt anyway, обычный Build this. Comp-first flip имеет отдельный confirm dialog с предупреждением об image-provider работе; это не доказательство стоимости/бюджетного approval Friday (`2550–2557`).

**Тестовый intent в этом срезе.** `2621–2656`: системные шрифты chrome, dark chrome отдельно от media paper, WKWebView flip по computed matrix m11 и opacity, reduced-motion без transition. `2671–2688`: state-file без URL не считается готовым; URL появляется atomic после задержки. `2701–2768`: comp/sketch alias, dedupe, canon order, URL-only и code-led не должны требовать локальный comp. `2772–2844`: stale HTML/comp; HTML допускает одинаковые bytes при новой mtime, comp требует новые bytes, кроме generated receipt. `2848–2926`: restart той же hand сохраняет fingerprint, новый payload/reroll инвалидирует старый slot, heartbeat race не стирает hand. `2930–2966`: детерминированная регенерация с одинаковыми bytes засчитывается только через generated, переписанный prompt sidecar — нет. `2970–2998`: невозможность записать hand блокирует start/update до serve/delivery. `3027–3112`: comp-led direction обязан объявить comps на assigned/pick/competitive/canon, declined исключён; отказ без spawn/state/next. `3140–3200`: surface gate зависит от свежего pending surface roll; unreadable/stale record не gate, direction gate имеет приоритет; concurrency compare при take_roll. Последний тест продолжается за пределом среза, его конец не заявлен прочитанным.

### 1.3 `crates/core/src/browser/visual.rs:3201–4800` — почему contrast может остаться unresolved

**Геометрия картинок.** background-position центр/keywords/%/(px), неизвестное→центр; pair использует первые2 tokens, одно top/bottom — вертикаль (`3216–3252`). Background cover/contain масштабирует intrinsic; explicit px/%/auto, unknown intrinsic→1. Object-fit fill/contain/cover/none/scale-down; source point вне painted rect→None, внутри clamp до intrinsic−1 (`3266–3386`). Raster longest side≤640, source point floor к raster pixel (`3425–3445`). Text points:3×3 либо1 по узкой оси (<28px width/<22px height), inset≤12/8, только viewport (`3389–3419`). Это не полноценный CSS layout engine: calc и многотокенные edge-offset позиции здесь не моделируются.

**Stack и uncertainty.** depth>8 unresolved; elementsFromPoint от кандидата вниз, overlay chrome исключён. Если self отсутствует и ancestor clip исключил point, `text clipped at point`, но pointer-events:none сохраняет walk (`3477–3550`). SVG unreadable останавливает walk, нельзя присвоить белый page background под непрочитанной графикой (`3553–3562`). Media fade — произведение opacity до общего с text ancestor максимум64; alpha исправляется при fade<.999. Неудачный media sample (кроме point outside image) ставит stop (`3650–3694`). Translucent stack композитится снизу вверх (`3569–3574`).

**CSS plan.** Background-clip:text не является surface под glyphs. Zero-size gradient или non-repeating hairline≤3 px не читается как фон текста (`3744–3809`). Gradients: только когда full-box coverage известен, composite всех stops over own opaque fill; потенциальные combinations≤4096, иначе unresolved. Positional translucent range возвращает worst/best; если stops расходятся по verdict — screenshot pixels, не искусственный pass/fail (`3816–3876`). Fixed image attachment →stop unresolved. URL path выбирает first CSS URL/слой size/position; это консервативная упрощённая модель, не generic renderer (`3886–3944`).

Image unavailable →stop, а не фон под фото. При известной placement/no-repeat image обязан покрывать candidate text и собственный box (кроме body/html), slack1px; недостаточно покрытия→unresolved (`3962–4062`). Background repeat извлекается из shorthand; неизвестные units/calc не объявляются известными (`4069–4116`). Single URL translucent pixel композитится с собственной background-color; при>1 image layers этот fold не делается (`4129–4158`). Opaque stop alpha≥.95 (`4163–4173`), не exact1.0.

**Candidate identity и sampled verdict.** Для selector с `#`, который matched несколько элементов, хранится [n,count]; пока count совпадает, выбирается nth; если нет — first. Missing/stale/hidden element, blocking blend/filter/backdrop/opacity-stack/text-shadow/unread-layer/text-outline →unresolved; часть paint invisible to hit-test тоже pixels (`4245–4318`). Text rect<4px либо точки вне viewport не оцениваются (`4320–4337`). Нужны min(3,points_len) readable samples. Ratio median, но если median>3×p10 берётся p10; если p10 fail, median pass — unresolved, не ложное обвинение. Gradient straddle не может дать pass, но достаточные прочитанные fail samples могут дать fail (`4350–4447`). Finding содержит ratio/median/threshold/method, canvas confidence high, analytic medium; decorative и near-bar advisory (`4365–4369`, `4449–4484`). Scroll retry только для exact unresolved `text outside viewport`, не любой error (`4673–4675`).

**Screenshot-diff glyph guard.** Сравниваются screenshot с glyphs и без;>=8 changed pixels;>55% clip changed→box repainted;>25% direction minority→text moved; core≥90% strongest delta, если<8 — fallback75%; большинство off-color→other paint; under-glyph/surround luminance ratio≥2→hidden text still painted. Итог median core; all-pixel median>3×verdict→bimodal unresolved (`4539–4668`). CSS color drift≤.5 от span (`4521–4524`). Filter/backdrop/background-clip заблокированы и в pixel path (`4593–4603`). Это детерминированные safeguards против ложных результатов на видео/светлом пятне/AA/glow, а не доказательство WCAG всей страницы.

Тесты в назначенном хвосте (`4687–4800`) закрепляют blend128, image mapping,9 sample points/640 raster, insufficient samples, gradient range disagreement/veil, uncertain-pass vs definite-fail, advisory4.4 против4.5 и decorative2.3. Тест округления начинается4797, его остальная часть не входит в область.
