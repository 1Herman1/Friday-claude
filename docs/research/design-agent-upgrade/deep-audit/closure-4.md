## Главные выводы для координатора

1. Самый полезный delta Impeccable — не ещё один список запретов, а **модель доказательств**: измеренное / неизвестное, painted / только объявленное, активный selector / пустой match, scoped waiver / глобальный запрет, одна декларация / несколько дублирующих находок. Friday уже имеет основные anti-patterns, но прочитанный `design-lint.mjs` — построчный regex, не equivalent этому движку.
2. Motion capture выдаёт временные кадры, geometry/paint findings, filmstrip и manifest, но прямо не доказывает smoothness и не скраббит JS timers. Это полезное дополнение к Friday screenshot + motion doctrine, а не замена визуальному ревью.
3. Taste содержит содержательные детекторы clipping/collision/real hit-target/asset upscale и полноценные progressive-enhancement assets. Одновременно его rhythm — жёсткий собственный стиль: 1–2 экрана на секцию, весь текст слева, одна пара split-линий, запрет меняющих высоту accordions. Это **conflict**, если превратить его в универсальные Friday gates.
4. Встроенные исключения Taste отдают привилегии собственному kit: `[data-ui]`, `.ui`, `[data-fx]`, `[data-moment]` и т. п. `FAIL`/`PASS` здесь — продуктовая policy, не независимая оценка всех сайтов и не WCAG certification.
5. Installer/account code — активная интеграционная поверхность: downloads, chmod, manifests, symlinks, rule-file sync. `--no-hooks` не означает абсолютный запрет изменения уже существующих stale hooks. Автоматическая установка в Friday из результатов аудита не разрешена.

### 1. `crates/core/src/browser/driver.rs:1–1600` (из 5952)

- **Вход/выход:** `Dom`, `BrowserConfig`, optional JSON design-system → `BrowserFinding` и группы по element handle. Состояние `DesignSeen` держит уже названные fonts/colors/radii; `add_browser_findings` сначала фильтрует scoped ignore, затем дописывает группу (:16–64). `data-impeccable-ignore` читается вверх по ancestors, case-insensitive; пустой атрибут и `*` гасят всё, список — rule IDs.
- **Токены, не только имена:** normalization шрифтов снимает внешнюю кавычку, `+` и whitespace; primary-font parser понимает quoted commas и пропускает generic families/var. JSON-флаги должны быть true и иметь непустые разрешённые значения (:164–274). RGB max-channel tolerance **6**, radius **0.5px**, pill ≥99px при разрешённом pill; transparent/currentcolor/inherit/unresolved var/непарсящиеся значения не обвиняются (:277–359). Для DOM font проверяется только direct text, для цветов — text/background/действительно ненулевые borders/outline, для radii — каждый token; повторное одинаковое значение дедупится (:386–497). Google Fonts source scan ловит лишнюю family даже через URL (:499–567).
- **Живой selector:** переписывается именно pseudo-element host, а не произвольно снимаются `:hover/:focus/:not`; успешный пустой match окончателен, invalid selector возвращает unknown (:601–764). Важная оговорка: selector traversal char vs JS UTF-16 имеет документированное отличие на astral literals.
- **Paint/brand context:** stock violet должен реально красить текст/fill/gradient/border/outline/ненулевую shadow, а не просто существовать в stylesheet (:766–870). Heading palette findings снимаются для hue бренда ±12°: logo/site bar/полоса ≥90% viewport width и ≥20% area; отдельная feature panel не равна бренду, heading о логотипах — не logo (:872–1034). Категорийная цветовая система требует ≥6 hue, separation5°, как минимум половину вне tell violet/cyan; группировка ink по tag/font size/weight, fill по tag/размеру (:1036–1162).
- **Статический текст сверяется с paint:** hidden/waived/nonmatching/overridden rules снимаются, computed bg/mask/shadow подтверждают stripe/glow/halo/grid; для старых captures отсутствие поля часто сохраняет finding, а не выдумывает измерение (:1193–1385). Из HTML исключается script body, linked CSS добавляется в corpus; pulsing dot в верхних900px повышается до error (:1387–1519).
- **Одна причина — один отчёт:** computed/class gradient/bounce/palette дубли снимаются, gradient clipped to text принадлежит gradient-text; при low-contrast <1.25 tiny/undersized снимаются как вторичный эффект (:1522–1600; конец функции дополнительно :1601–1616). Это не разрешение автоматически удалять размерные находки, если contrast только provisional/ignored.

### 2. `extension/walks/consent-rules.js:1681–3280` (из 3788)

Это выполняющий действия bundled AutoConsent, **не пассивный consent audit**.

- Popup walk принимает fixed/sticky/dialog-like видимые элементы, исключает контейнеры; button collector учитывает submit input value, disabled и recursively open shadow roots (:1681–1746).
- CMP base проводит main-world snippets прямо или через message eval; неизвестный snippet/ошибка дают false, log channels configurable. Default main=true/frame=false и URL regex ограничивают запуск. Базовые методы Not Implemented бросают; базовый test=true не равен реально проведённому selftest (:1748–1929).
- DSL запускает array steps sequentially с optional; внутри одного step результаты разных actions собираются через Promise.all AND, `any` short-circuits, `negated` инвертирует, if требует exists/visible и then. Неизвестное правило → warning/false (:1930–2091). Нельзя считать это transactional workflow: уже начатые clicks/styles не откатываются от false.
- Heuristic CMP работает только top frame, запоминает найденные popups и берёт первую; target для reject/tier1/прочего — reject/acknowledge/accept соответственно. `optOut` может таким образом нажать acknowledge/accept по классификации; selftest лишь проверяет исчезновение кнопки через500ms, не запись отказа в consent store (:2092–2166).
- Прочитаны все маршруты **11 динамических CMP** в slice: TrustArc, Cookiebot, SourcePoint, ConsentManager, Evidon, Onetrust, Klaro, Uniconsent, Conversant, TikTok, Admiral (:2168–2930). Есть shortcut reject, API snippets, opening settings, uncheck enabled toggles, save, CCPA manager modes, многоязычные XPath labels, Shadow DOM TikTok. Onetrust ждёт SDK style только когда scripts показывают SDK; close button допускается лишь с reject wording либо notice-only. SourcePoint hasSelfTest=false; Evidon/Admiral тоже; ConsentManager тест доступен лишь с API. Conversant проверяет cookie prefix `cmp-data=0`, TikTok decode+JSON всех boolean=false (без локального catch malformed JSON).
- **Побочные эффекты:** click counters растут на попытку; некоторые CMP нажимают DOM напрямую и обходят счётчик. hide/prehide меняют CSS/opacity, setStyle заменяет cssText, addStyle дописывает. `waitForThenClick` возвращает факт найденного/нажатого элемента, retry может нажать ещё раз, но это не факт сохранённого preference (:2932–3069).
- Selector API поддерживает CSS/XPath и цепочки через первый matched parent/open shadow/same-origin frame; `aria/`, `text/`, `pierce/` здесь возвращают []. MutationObserver одноразовый, timeout60s rejects, оба пути disconnect (:3070–3138). Compact-rule decoder запрещает format>1, фильтрует unsupported step versions, recursively разворачивает if/any; optIn у compact class пустой. Начальный lifecycle loading хранит detected CMP/popup, heuristics, selfTest, clicks/time и посылает init (:3140–3280; продолжение вне scope).

**Friday comparison:** `.codex/CODEX.md:387–406` уже требует ранний/финальный rkn-compliance и read-only правовую роль. AutoConsent не equivalent юридическому compliance: он меняет выбор посетителя и способен скрыть проблему до screenshot. Заимствовать только описание/журнал состояний consent и раздельные сценарии opt-in/out, а запуск — только отдельным разрешённым тестом на fixture.
