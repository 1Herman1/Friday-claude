## Находки для координатора (статические, не воспроизведены)

### C1-01 — ВАЖНО: update может объявить доставку после неуспешного копирования payload

`impeccable/crates/context/src/serve_question.rs:1480–1496`: после успешной записи нового hand вызывается `take_roll`, затем результат `std::fs::copy(..., delivered)` отбрасывается; далее вызывается `touch_now`, печатается `next round delivered`, возвращается 0. Ошибка копирования не связана с итоговым статусом. Это конкретный разрыв между hand provenance/поглощённым roll и фактически доставленным файлом; комментарий обещает сохранение предыдущей provenance при ошибке, но покрывает лишь ошибку `write_hand`, не последующую доставку.

Условие: payload изменился/удалён после чтения или destination перестал быть writable между операциями. Нет утверждения, что такой отказ произошёл у пользователя. Предлагаемый upstream owner: context/serve-question; сначала готовить доставку через временный файл, явно обрабатывать ошибку, согласовать порядок commit hand/next/roll и успешное сообщение. Ожидаемый regression: отказ copy/rename → ненулевой код, нет ложного delivery, не потерян предыдущий доступный round и roll.

### C1-02 — КАЧЕСТВО: timestamp каталога проверяется существенно слабее сообщения валидатора

`impeccable/crates/context/src/catalog.rs:361–364,438–448`: ошибка говорит об ISO `reviewedAt`, но fallback `js_date_parse_ok` принимает любую непустую строку с хотя бы одной ASCII-цифрой; первая ветвь также проверяет только год и позиции дефисов, не календарную корректность. Это не эквивалент `Date.parse` и не строгая ISO-проверка. Например, строка с текстом и цифрой проходит по самому условию кода; это статический вывод, не запуск примера.

Owner: context/catalog. Expected test: набор корректных ISO и невозможных/мусорных дат с явным контрактом совместимости JS; не ослаблять критерий ради старых данных молча. Этот дефект не отменяет отдельный content-hash gate устаревшего review.

### C1-03 — КАЧЕСТВО/надёжность: Taste make/probe не гарантируют cleanup при ошибке запуска Chrome

`taste/skills/taste-skill/assets/scenes/_demo/shoot.mjs:297–314,318–333`: HTTP server уже создан, `await chrome(...)` стоит до `try/finally`. Если Chrome не найден/не поднялся, `srv.close()` не выполняется. Внутри `chrome` после получения debug-порта fetch/WebSocket/attach failures также не обёрнуты единым cleanup; `send` хранит pending Promise без собственного deadline (`201–222`). В shoot есть общий 25-минутный `process.exit(2)` watchdog, но это не доказательство удаления дочернего Chrome. Для make/probe такой общий watchdog отсутствует.

Owner: Taste scene-tool maintainer. Expected test: отсутствующий CHROME_PATH, отказ /json/version, WS close с pending request → ограниченный по времени отказ и закрытые собственные ресурсы, без убийства чужого Chrome. Не переносить как production runner без исправления.

### C1-04 — Ограничения доверия вспомогательных Taste labs, не доказанная remote exploit

- `shoot.mjs:171–180`: раздача файлов проверяет строковый `startsWith(root)`, но не path-separator boundary/realpath и не запрещает symlink; `decodeURIComponent`/stat/read-stream errors не превращены в контролируемую HTTP-ошибку. Это localhost dev-tool, не production perimeter. Не выставлять наружу; при переносе нужен нормализованный containment и явная политика symlinks.
- `shoot.mjs:65–71`: автоматический выбор index бережёт installed skill, однако явный `--out` возвращается до проверки protected INDEX. Комментарий «никогда без --in-skill» не абсолютный guard от намеренного `--out` в тот же файл. Это граница обещания, не утверждение о случайном перезаписывании здесь.
- `assets/diagrams/lab.html:104–108`: экспорт JSON в single-quoted attribute либо application/json script выбирается только по наличию апострофа. Нет полного HTML-safe escaping для `<`, `&`, `</script>`; вывод предназначен для дальнейшего копирования. Это не универсальный безопасный сериализатор недоверенного JSON. Error message также вставляется через innerHTML (`126`). Не применять к внешнему пользовательскому spec без отдельной защиты.

### 1. `crates/context/src/serve_question.rs:1–1600` — decision protocol, provenance и ожидание

**Зависимости/входы.** `jsp`, util/Env/Io, question_page PAGE, common HTTP SerialServer, serde_json, sha2, proc/git helpers; provider, concept_seed, telemetry Ledger, generate_image. CLI verbs schema/wait/stop/update/start; JSON payload, key, cwd, env. Сам blocking HTTP-server handler находится за назначенным диапазоном: константа POST-body 8 MiB прочитана, но её реальное применение в handler этим срезом не подтверждается.

**State и writes (`53–168,451–629,801–1119`).** Проектный `.impeccable/questions` содержит state/answer/flip/next/hand/render-check и per-slot generated markers, каталог сам пишет `.gitignore:*`. Глобальный `~/.impeccable/questions/<key>.root.json` связывает key с исходным cwd; cwd с имеющимся state выигрывает. Roll свежий 1 час; mtime подставляется как `at`; local roll предпочитается tracked legacy. `git ls-files` запускается самим upstream при штатной работе; здесь не запускался. Если runtime уже tracked, печатается одно предупреждение на distinct tracked set, сам git index не меняется. Roll-record writes best-effort, не валят concept-seed.

Hand хранит digest всего payload, уникальный id от digest+наносекунд+PID, SHA-256 уже существовавших comp/sketch и startedAt. Restart с тем же digest сохраняет hand; update всегда создаёт новый id. Markers разнесены по slot+hand tag для параллельных generators; после успешного atomic write hand чистятся только чужие markers. Короткий безопасный id допускает `[a-z0-9_]` до 64 символов, иначе хешируется. Записи JSON — temp beside target + rename. Это защита от частично прочитанного файла, не общая транзакция нескольких файлов (см. C1-01).

**Проверки содержания (`170–449`).** Дирекция/surface page с buildPath требует известный kind у каждого option; assigned и pick не более одного; challenger требует catalogId из свежего dealt roll. Canon kind при наличии должен быть canon. Comp-led full hand = value comp + toggle true + минимум 2 options. Направление с canon exit требует comp у всех, включая canon, кроме declined; surface gate определяется pending surface roll, чтобы не спутать comp-round. Отсутствие generation не должно давать toggle. Схема дополнительно задаёт salience parity, демоцию declined, короткие front/back facts, html sketch и wireframe, но prose-schema не следует считать равной полному машинному валидатору.

**Network (`631–783`).** World id plain slug до 120 байт, не с точки; board/hero URL до 500, без пробелов/control/pipe/backtick. Только direction worlds становятся style references. Downloads параллельны, каждый 8 секунд, zero redirects; уже сохранённые webp/png/jpg/jpeg переиспользуются. Fake env выключает запрос. URL разрешён под настроенным card-base либо HTTPS к hostname без userinfo/IP/numeric TLD/local suffix. Это лексический URL gate, не доказательство DNS/IP pinning. Failure оставляет URL вместо файла; удача пишет temp+rename в ignored worlds. API roll context переносится в hand, ledger разрешает seed reference в key; если key не найден, telemetry seed отбрасывается. Наличие этой структуры не означает, что сеть была вызвана в данном аудите.

**Staleness и качество (`1060–1222`).** Comp текущего hand: существует и отличается от pre-fingerprint либо помечен generate-image; comp-round и его recorded option one имеют отдельное исключение. Sketch допускает одинаковую перезапись, если mtime позже startedAt. Существование prompt-sidecar проверяется отдельно; содержимое prompt не валидируется этими helper-функциями. Render-check line записывается once per hand; выдача reminder не доказывает, что агент действительно посмотрел комп.

**Ошибки/exit (`1278–1600`).** Disabled/headless fallback возвращает 2, SDK/CI/SSH/Linux без дисплея распознаются отдельно; force может разрешить serve. Defaults: timeout 900s, idle 600s, port 0. Wait poll 60s; heartbeat <12s считается живым, затем PID probe, EPERM означает alive. Окно доставки/claim 10s предотвращает ложное page-closed; lastBeat >90s даёт exit 4. Server gone — exit 2 с требованием restart, а не default choice. Без ответа после 30 минут с later(hand/server start) — pending exit 5, страница остаётся открытой; обычное ожидание — 3. Answer печатается, удаляется; final закрывает state/hand/markers/root pointer, reroll/followup оставляет таблицу. Stop посылает terminate из state PID и удаляет файлы best-effort. Start пишет hand до spawn, запускает текущий exe detached в исходном cwd, лог append, ждёт URL 8s; spawn error отдельно не возвращается, но отсутствие URL приводит к error+tail лога. Реальная HTTP auth/path-safety за пределами этого среза не оценена.

### 2. `crates/foundation/src/browser/snapshot.rs:1–1600` — сериализованный DOM, не screenshot

Snapshot заменяет live JS Dom в strict-CSP extension: capture `15-snapshot.js` → JSON → offscreen wasm core. Зависимости serde, selector wrapper/selectors, std HashMap/HashSet/RefCell, Dom/Rect. Property lists синхронизируются build-проверкой согласно комментарию; этот аудит build не запускал.

`finish` строит child/sibling/property indexes; отдельные shadow roots не входят в document selector walk. Flat parent учитывает assigned slot → обычный parent → shadow host. Query scope/selectors и closest кешируются; HTML attr lower-case, SVG case-sensitive. TextContent включает CData, direct-text и DomChild CData исключают. Старое отсутствие feature не превращается в отрицание: `anim=false` → None/unknown; media complete absent → None, а не loading; missing metric → NaN; недостающий style → пустая строка плюс unknown_props. Это полезная переносимая модель evidence, но произвольный невалидный snapshot не обещает безопасную валидацию всех ElId — часть методов индексирует `node` напрямую.

Hit tests demand-driven: незнакомые координаты регистрируются, caller отвечает Facts и повторяет deterministic scan; ключи — точные f64 bits. Scroll probes отделены от hit Needs, чтобы consumer, отвечающий только точки, не заявлял знание scroll visibility. `add_facts` сохраняет ответы и сбрасывает pending. Реальные ширины строк собираются из direct rects потомков, исключая renders-no-text, не выдумываются делением общей рамки на line-height (`1188–1215`). IO/сети/файловых writes в adapter нет; внешний live-page probe остаётся ответственностью caller.

Тесты в `1265–1600` фиксируют flat vs document shadow, prettyWrap/fontFaces unknown, text/tree/style roundtrip, placeholder pseudo, bidi/aspect columns, старые animation/containing-block captures, CSS.escape/selector semantics и demand-driven hit/scroll. ### 3. `crates/core/src/browser/visual.rs:1601–3200` — чему доверять при контрасте

Локальное математическое ядро читает Dom, background/text_layers/painted/decorative/element helpers, color contrast/gradient parser, JS-compat numeric/UTF16, regex/serde_json. Async загрузка изображений/Canvas/pixel shots живёт вне среза в browser bundle; здесь только решения и candidate descriptors, без сети/writes.

Sibling candidates сортируются paint-layer descending и reverse document position; climb обходит собственный paint и siblings, opaque card прекращает поиск фото ниже. Hit fallback берёт midline в центре/25%/75%, только viewport; Picture подтверждается всеми отвеченными точками, не одной. `body/html` opaque fill не автоматически доказывает отсутствие sibling paint. Дополнительным чтением constants установлены бюджеты climb 32 уровня, 32 siblings с каждой стороны, 1024 nodes; same-surface RGB Manhattan distance 24. `surface_unread` сопоставляет structural climb с полным text hit-grid; pointer-events-none/SVG/pseudo ancestor — специальные случаи, где stack не всё видит.

Unread chain: максимум 4 слоя, fade/alpha композиция, известные fills/gradient stops против неизвестного диапазона black..white; 5 sample surfaces. Все >=bar → Passes, все <bar → Fails, иначе Unknown. Непонятный порядок/ground/межслойная позиция → Unknown; failing rescore печатает лучшую достижимую поверхность, если старый resolved цвет вне диапазона >24. Это ограниченная модель, не pixel-proof всех произвольных CSS комбинаций (`1888–2299`).

WCAG bar 3 для large/large-bold, иначе 4.5 (`2301–2308`). Text outline: stroke>0 или минимум две противоположные sharp shadow offsets, blur<=2px, offset>=0.5px, alpha>=0.5, цвет достаточно отличен. Font<1px, transparent ink, disabled и unpainted не тратят бюджет; mid-reveal и covered text не оцениваются как resting contrast.

Collector default base=12, routed=0; imageOnly выключает routed. Явно declared mockups пропускаются, labelled screenshots advisory; aria-hidden painted текст допускается только через routed. Routed дедуп приоритизирует разные tag/ink/size/weight/class, повторы заполняют остаток. Blended text echo ищется до 3 уровней, 4 поздних siblings, 40 boxes, края в пределах 4px; translucent alpha<.98 или nonnormal blend → pixels. Crop даёт 2px padding, текстовый excerpt 80 UTF16; outline/opacity/filter/background-clip требуют rendered foreground.

`handed_over_unmeasured` не выдаёт 1.1:1 против страницы за достоверный verdict текста поверх фото: plain-form snippet распознаётся regex, outline/layer-rescore сохраняют advisory; wash-проверка перебирает максимум 4096 комбинаций, при превышении возвращает unmeasured. Analytic gradient: alpha<.95 либо max/min contrast spread>=2 → Unresolved; иначе worst stop. Ключевой delta Friday — explicit unknown/routed/decorative evidence, а не ещё один запрет серого текста.
