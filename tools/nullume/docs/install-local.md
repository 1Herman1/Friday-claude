# Установка Nullume на свой компьютер

Инструкция для человека, который не программист. Каждый шаг — копируешь строку,
вставляешь в чёрное окно, жмёшь Enter, ждёшь. Если строка выдала ошибку —
остановись и покажи её мне, дальше не иди.

---

## Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Node.js версии 22.13 или выше | на нём работает сам инструмент | nodejs.org, кнопка LTS |
| Git | чтобы скачать код и потом отдавать мне результат | git-scm.com |
| Ключ kie.ai | для генерации картинок (для библиотеки вкуса не нужен) | личный кабинет kie.ai |
| ~700 МБ на диске | код, модель распознавания стилей, сами референсы | — |

Ключ kie.ai **в чат мне не присылать**. Он вводится один раз на вашей машине
командой из шага 4 и остаётся только у вас.

---

## Шаг 0. Открыть окно команд

**Windows:** кнопка «Пуск» → напечатать `PowerShell` → открыть «Windows PowerShell».

**Mac:** Cmd+Пробел → напечатать `Терминал` → Enter.

Дальше всё делается в этом окне. Оно запоминает, в какой папке вы находитесь, —
поэтому шаги идут по порядку и «перепрыгивать» нельзя.

---

## Шаг 1. Проверить Node

```
node -v
```

Должно ответить `v22.13.0` или больше (`v23`, `v24` — тоже хорошо).
Если написало «не является командой» или версия меньше — поставьте Node с
nodejs.org (кнопка LTS), закройте окно команд, откройте заново и проверьте снова.

---

## Шаг 2. Скачать код

```
git clone https://github.com/1Herman1/Friday-claude.git
cd Friday-claude/tools/nullume
```

Первая строка скачивает весь наш репозиторий в вашу домашнюю папку, вторая —
заходит внутрь, в каталог самого инструмента.

Спросит логин-пароль от GitHub — введите; если потребует токен вместо пароля,
это Personal Access Token, создаётся в GitHub → Settings → Developer settings →
Personal access tokens.

---

## Шаг 3. Собрать инструмент

```
npm ci
npm run build
```

Первая команда скачивает четыре библиотеки, на которых Nullume работает.
Вторая переводит исходный код в исполняемый. Вместе — пара минут.

Проверка, что живое:

```
node bin/nullume.js --help
```

Должен напечатать список команд. Если напечатал — инструмент установлен.

Чтобы не писать каждый раз `node bin/nullume.js`, можно один раз выполнить:

```
npm link
```

После этого работает просто `nullume --help`. На Mac может потребовать `sudo`
перед `npm link` — это нормально. Если не сработало, ничего страшного: везде
ниже вместо `nullume` пишите `node bin/nullume.js`.

---

## Шаг 4. Ключ kie.ai (только если будете генерировать картинки)

```
nullume setup --key ВАШ_КЛЮЧ
nullume balance
```

Вторая строка должна показать остаток кредитов. Для библиотеки вкуса ключ не
нужен — этот шаг можно пропустить и вернуться позже.

---

## Шаг 5. Завести библиотеку вкуса

```
nullume lib init
```

Создаёт папку `.nullume` в вашей домашней директории и скачивает модель,
которая «смотрит» на картинки и понимает, какие из них похожи по стилю.
Модель весит около 150 МБ, качается один раз, минуту-две.

Где именно всё лежит:

- **Windows:** `C:\Users\<ваше имя>\.nullume`
- **Mac:** `/Users/<ваше имя>/.nullume`

Внутри: `library.db` (база), `originals/` (скачанные референсы),
`previews/` (уменьшенные копии), `config.json` (настройки).
Эта папка — и есть накопленный вкус. Её стоит иногда копировать в облако.

Проверка:

```
nullume lib status
```

---

## Шаг 6. Первые референсы без всякого Pinterest

```
nullume lib sources
nullume lib import unsplash --query "warm minimal skincare still life" --limit 30
nullume lib embed
nullume lib cluster
```

По порядку: посмотреть доступные источники, натащить 30 картинок с Unsplash,
посчитать для них «отпечаток стиля», разложить по семействам.

Затем открыть рабочее место:

```
nullume lib dashboard --open
```

Откроется страница в браузере: вкладки «Референсы», «Собрать», «Семейства»,
«Кластеризация». Там вы смотрите картинки, утверждаете семейства, крутите
регуляторы настроения. Страница живёт только на вашем компьютере — из интернета
её никто не откроет, это сделано намеренно.

Закрыть — Ctrl+C в окне команд (или само закроется через 30 минут простоя).

---

## Шаг 7. Pinterest (по желанию, риск на вас)

Pinterest работает под вашей живой сессией, поэтому включается тремя действиями
сразу — чтобы это нельзя было сделать случайно.

**7.1. Согласиться с риском.** Откройте файл `config.json` в папке `.nullume`
блокнотом и добавьте строку `"acknowledgedRiskyImporters": true` внутрь фигурных
скобок. Либо скажите мне — я напишу вам точный текст файла целиком.

**7.2. Достать cookie.** В браузере, где вы залогинены в Pinterest:
F12 → вкладка Application (Приложение) → Cookies → pinterest.com → найти строку
`_pinterest_sess`, скопировать её значение.

**7.3. Записать и включить.**

Windows (PowerShell):
```
nullume lib session set pinterest-cookies --cookie "_pinterest_sess=ЗНАЧЕНИЕ"
$env:NULLUME_LOCAL_IMPORTERS="1"
nullume lib import pinterest-cookies --query "warm minimal skincare packaging" --limit 40
```

Mac (Терминал):
```
nullume lib session set pinterest-cookies --cookie "_pinterest_sess=ЗНАЧЕНИЕ"
export NULLUME_LOCAL_IMPORTERS=1
nullume lib import pinterest-cookies --query "warm minimal skincare packaging" --limit 40
```

Строка с `NULLUME_LOCAL_IMPORTERS` действует только до закрытия окна — это тоже
намеренно. Cookie живёт несколько недель, потом Pinterest её сбросит и шаг 7.2
придётся повторить.

**Моё возражение, зафиксировано:** частый автоматический сбор с одного аккаунта
Pinterest считает ботом и может его заблокировать. Заводите под это отдельный
аккаунт, не основной. Решение ваше, я его выполняю.

---

## Шаг 8. Отдать результат мне

Когда семейства утверждены в дашборде:

```
nullume lib family list --json > families.json
```

Дальше — либо пришлите мне этот файл в чат, либо положите его в репозиторий и
запушьте. Я подхвачу и буду генерировать по вашему вкусу.

Сами картинки в репозиторий не кладём: их сотни мегабайт, и права на них чужие.
В git едут только описания стилей — палитра, шрифты, настроение, промпт.

---

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `command not found: nullume` | вы не сделали `npm link` — пишите `node bin/nullume.js` вместо `nullume` |
| `command not found: node` / `git` | не установлено или окно команд не перезапущено после установки |
| `API-ключ kie.ai не задан` | шаг 4 |
| `Local-only импортёры требуют...` | не выполнен один из трёх пунктов шага 7 |
| `Библиотека не инициализирована` | шаг 5 |
| любая другая красная надпись | скопируйте её целиком и покажите мне |
