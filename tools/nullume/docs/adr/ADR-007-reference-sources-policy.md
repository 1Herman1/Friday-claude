# ADR-007: Политика источников референсов для библиотеки вкуса (спринт 2 Nullume)

**Дата:** 2026-09-19
**Статус:** Принято

## Контекст

В спринте 2 Nullume добавляется «библиотека вкуса» — коллекция референсов стилей
с автоматической кластеризацией в семейства. Для пополнения нужны источники изображений.

Существующие ADR-002 (Artlist) и ADR-003 (Icon MCP) явно запрещают скрейпинг сайтов,
чьи Terms of Service запрещают автоматический доступ. Это правило остаётся в силе.

Однако Pinterest — золотой стандарт для подбора стилей и вдохновения. API v5 ограничен:
- поиск доступен только по **своим пинам** и **своим доскам** (публичный поиск в закрытой бете, 10 результатов)
- официального способа скрейпить чужие доски нет
- Dribbble API v2 — только свои шоты
- X API — pay-per-use ($0.005 за каждый твит), бесплатного тарифа нет с апреля 2026

**Возражение Джарвиса:** Скрейпинг Pinterest (поиск, вскрытие селекторов) нарушает ToS
и грозит баном аккаунта. Риск неприемлем.

**Решение владельца:** Pinterest необходим любой ценой. Владелец согласен с риском и готов
использовать собственную сессию + cookie на свой риск. Возражение выслушано один раз,
решение принято — фиксируем в ADR.

## Решение

### Два класса импортёров

#### Класс 1: Clean sources (без ограничений)
Импортёры, чьи API и ToS разрешают автоматический доступ:

| Источник | Статус | Особенности |
|---|---|---|
| **Are.na** | v2 анонимный, v3 с токеном | поиск по каналам, публичный API |
| **Unsplash** | открытый API | 50 req/ч, обязательна атрибуция (`download_location`) |
| **Land-book** / **Godly** / **siteinspire** / **Awwwards** | индексы + RSS | свой скриншот или `og:image`, robots.txt, задержка ≥ 2 с |

Эти импортёры везде:
- В CLI (`src/cli/lib import`)
- В MCP (`mcp__nullume__lib_import`)
- В CI/CD автоматические запуски

#### Класс 2: Local-only sources (с гейтом)
Импортёры, чьи API требуют личной авторизации или нарушают ToS:

| Источник | Класс | Обоснование | Использование |
|---|---|---|---|
| **Pinterest (поиск с cookies)** | local-only | ToS запрещает автоматизацию; используем собственную сессию | CLI + гейт |
| **Dribbble** | local-only | v2 API принимает только свои шоты; расширение через скрейп | CLI + гейт |
| **X** | local-only | pay-per-use ($0.005/запрос) и отсутствие бесплатного тарифа | CLI + гейт |

Local-only доступны **только** в CLI (`src/cli/lib import`), **никогда** не в MCP (`src/mcp/tools/*`).

### Гейт `assertLocalOnlyAllowed`

Импортёры local-only работают только при **одновременном выполнении трёх условий**:

```typescript
function assertLocalOnlyAllowed(): void {
  // Условие 1: явное согласие в конфиге
  if (!config.acknowledgedRiskyImporters) {
    throw new Error('Local-only импортёры требуют config.acknowledgedRiskyImporters=true в ~/.nullume/config.json');
  }

  // Условие 2: переменная окружения (двойная проверка)
  if (!process.env.NULLUME_LOCAL_IMPORTERS) {
    throw new Error('Установите env NULLUME_LOCAL_IMPORTERS=1');
  }

  // Условие 3: не в CI/не в изолированной среде
  if (process.env.CI || process.env.GITHUB_ACTIONS) {
    throw new Error('Local-only импортёры не запускаются в CI');
  }

  // При запуске через прокси (сетевая песочница)
  if (process.env.HTTPS_PROXY || process.env.http_proxy) {
    // Можно развернуться, но показать предупреждение
    console.warn('⚠️ Запуск local-only импортёров через прокси может привести к блокировке');
  }
}
```

### Предупреждения и прозрачность

При каждом запуске local-only импортёра показываем предупреждение:

```
⚠️  Используются импортёры с ограничениями:
   - Pinterest (поиск по cookies): риск блокировки аккаунта
   - Dribbble (расширенный скрейп): не поддерживается API
   - X (платный поиск): $0.005 за запрос

Убедитесь, что вы согласны с этими рисками. Риск на вас.
```

### Хранилище учётных данных

- Pinterest cookie-сессия: `~/.nullume/sessions/pinterest.json` (права 0o600)
- Dribbble API token: `~/.nullume/sessions/dribbble.json` (600)
- X платный ключ: `~/.nullume/sessions/x.json` (600)

Все файлы в `.gitignore`, **никогда** не коммитятся.

### Проверка при разработке

Граф импортов проверяется в тестах:

```bash
# Убедиться, что local-only не импортируются в src/mcp/
npm test -- grep "local-only not exported to MCP"
```

Поддерживаем явное правило: если функция импортируется в `src/mcp/`, она не может использовать `assertLocalOnlyAllowed()`.

## Альтернативы

### Отклонено: отказ от Pinterest
- **Причина:** Pinterest уникален для подбора стилей и вдохновения; её нет в конкурентах
- **Цена отказа:** снижается качество библиотеки вкуса

### Принято: платный X API как единственный путь для X
- **Причина:** бесплатный тариф закрыт; платный at least явно зафиксирован в коде и показываем цену
- **Показ цены:** каждый запрос логируем как `X_QUERY_COST: $0.005`

### Рассмотрено: скрейп Pinterest через браузер (Puppeteer)
- **Отклонено:** усложнение, Puppeteer требует Chromium; гейт с cookies проще и прозрачнее

## Последствия

### На агентов

Агенты `security-api-surface` и `security-secrets-scanner` проверяют:
1. Local-only импортёры используются **только** в CLI, не в MCP
2. Граф импортов чистый: нет импорта local-only в `src/mcp/**`
3. Гейт вызывается везде, где используется local-only
4. Тесты покрывают срабатывание гейта на CI и без переменных окружения

### На код

- Новый файл `src/library/importers/gate.ts` с `assertLocalOnlyAllowed()`
- Новые классы в `src/library/importers/{pinterest-local,dribbble,x}.ts`
- Новая переменная в `.env.example`: `NULLUME_LOCAL_IMPORTERS` (по умолчанию не задана)
- Новое поле в `~/.nullume/config.json`: `acknowledgedRiskyImporters` (boolean, false по умолчанию)

### На документацию

- SKILL.md: раздел «Источники данных», перечень чистых и local-only
- README.md: раздел «Риски», фиксация Pinterest и гейты
- ADR-002 и ADR-003 остаются без изменений; исключение из них ограничено этим файлом и только `tools/nullume`

### На владельца

Риск блокировки аккаунта Pinterest — личный риск владельца. Claude (Джарвис) сказал один раз,
решение принято. Дальше — молчим, но гарантируем:
1. Гейт работает (не используется в CI)
2. Печатаем предупреждение (прозрачность)
3. Предоставляем документацию (что делать, если аккаунт заблокирован)

## Решение: исключение из ADR-002 и ADR-003

**Local-only импортёры в `tools/nullume` — исключение из универсального правила.**

- ADR-002 и ADR-003 запрещают скрейпинг везде
- ADR-007 разрешает его **только** в `tools/nullume`, **только** в CLI, **только** локально
- Это исключение документировано и ограничено явно
- Перенос этого кода в другой проект немедленно вызывает ошибку (гейт упадёт)

Правило ADR-002/003 остаётся основным. Исключение — явное, с дорогой ценой и владельца предупредили.

### (в) X: стратегия и учётные данные

**Сигнал X слаб и дорог** — низкое качество контента, отсутствие авторского и лицензионного контекста, плата $0.005 за каждый запрос.

**Решение владельца**: делаем local-only импортёр для X, но с явным осознанием риска.

**Условие неверности (2026-09-21 гипотеза)**: если в первом полном прогоне через дашборд утверждается ≥ 50% кандидатов из X, это означает, что сигнал валиден и стратегия верна. Если < 50%, X будет отключен как неэффективный.

**Хранилище учётных данных для X**:
- Платный API ключ: `~/.nullume/sessions/x.json` (права 0o600)
- Операционные ID GraphQL запросов: `data/x-graphql.json` (заполняет владелец)
- Не коммитятся в git

### (г) Dribbble: только свои шоты

Dribbble API v2 поддерживает только запросы собственных шотов. Расширение через скрейп браузера технически возможно, но не реализовано — придерживаемся API в качестве primary и гейта как secondary при расширении.

**Использование**: local-only, требует токена в `~/.nullume/sessions/dribbble.json`.

### (д) Eagle: локальный API как исключение

Eagle.cool работает локально на `localhost:41595` (HTTP, не HTTPS). Это **единственное исключение из правила https-only**, поскольку:
1. Соединение локальное, не трансграничное
2. Eagle — собственное приложение владельца (desktop app)
3. Палитры и метаданные достаточно ценны для включения

### (е) Один безопасный fetch на пакет

Следствие ревью безопасности (агент `security-api-surface`): все запросы к внешним API в `src/library/importers/http.ts` проходят через единую обёртку `safeFetch()`:
- Таймауты (network 10s, overall 600s)
- Rate limiting (встроенный)
- Retry с экспоненциальной задержкой
- Логирование запросов (без чувствительных данных)
- Кэширование (где применимо)
