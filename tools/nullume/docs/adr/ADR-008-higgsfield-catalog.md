# ADR-008: Каталог пресетов Higgsfield как раздел библиотеки вкуса

**Дата:** 2026-09-30
**Статус:** Принято (решение владельца)

## Контекст

В сессии 30.09 через MCP Higgsfield был выгружен каталог его пресетов:
87 эффектов Viral Hub (33 визуальных фильтра + 54 сценария роликов) и по 12
образцов из Marketing Studio (товарная съёмка, motion). Владелец решил положить
всё это в библиотеку вкуса Nullume отдельным разделом как её основу.

**Возражение Джарвиса** (высказано до работы, один раз):

1. 54 эффекта — ролики с человеком в кадре (клоны, дельфины, рыцари). К стилю
   сайта отношения не имеют и при кластеризации потянут семейства в сторону
   «виральных видео». Уверен.
2. Пресет исполняется только на Higgsfield. В библиотеке он — референс, не
   рецепт: «сделай как Orbit 360» нашими моделями не воспроизводится. Уверен.
3. Превью — маркетинговые материалы Higgsfield. Тянуть их в свою базу без
   лицензии — тот же класс вопроса, что решался в ADR-007 для Pinterest.
   Похоже на проблему; юрист скажет точнее.

**Решение владельца:** класть всё, включая эффекты и превью. Возражение
выслушано, решение принято — фиксируем.

## Решение

- Источник истины — **vendored JSON** `data/higgsfield-catalog.json`
  (id, имя, описание, раздел, группа, ссылки на превью). Библиотека в облаке
  эфемерна, поэтому основой считается файл в репозитории, а не база;
  библиотека пересобирается пятью командами из SKILL.md.
- Импортёр `higgsfield` — clean, без ключа, читает JSON. Превью Higgsfield —
  webp, который Jimp не декодирует; импортёр переписывает URL на
  JPEG-трансформацию CDN (`/cdn-cgi/image/width=1024,format=jpeg/…`),
  проверено живьём.
- Каждый референс: `source: higgsfield`, `author: Higgsfield`, лицензия
  «preview material — reference only», теги `hf-section:<раздел>`,
  `hf-group:<группа>`, `hf:<имя>`. Имя и описание — в `meta`.
- Раздел = четыре семейства по тегу раздела (`family create --tag`):
  `higgsfield-filters`, `higgsfield-effects`, `higgsfield-product-shot`,
  `higgsfield-motion`. Семейства создаются со статусом proposed.
- В генерацию (`--style`) уходит только текст дескриптора. Превью Higgsfield
  как image-input в модели не передаются: стилевая проверка идёт на
  text-to-image пресете.

## Условие пересмотра

Если после кластеризации ≥ половины утверждённых семейств окажутся из
эффектов-роликов, раздел сворачивается до 33 фильтров: эффекты помечаются
discarded, JSON остаётся как справочник.

## Последствия

- Семейства Higgsfield при кластеризации всей библиотеки надо исключать
  (`lib cluster` по умолчанию берёт все эмбеддинги) — иначе п. 1 возражения
  сработает. Пока — руками, через `--family`, если понадобится.
- Лицензионный статус превью не решён; при выходе Nullume за пределы студии
  раздел из npm-пакета исключить или заменить на свои кадры.
