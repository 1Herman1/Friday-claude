# Как дать Claude прямой доступ к Nullume

Облачная сессия Claude Code живёт в контейнере Anthropic и не видит ваш компьютер.
Поэтому генерация шла через GitHub Actions, а библиотека вкуса и Pinterest — через
вас вручную. Ниже два способа это убрать. Их стоит сделать **оба**: они закрывают
разное.

| | Генерация | Библиотека вкуса | Pinterest | Цена |
|---|---|---|---|---|
| **А. Ключ kie в облачную среду** | Claude сам, в облаке | живёт до конца сессии | нет | бесплатно |
| **Б. Claude на вашем Mac** | да | постоянная, с моделью CLIP | да, с вашего адреса | бесплатно |

---

## А. Ключ kie в облачную среду — 2 минуты

После этого облачный Claude вызывает Nullume напрямую: генерация, рецепты, баланс —
без Actions и без вашего участия.

1. Откройте любую сессию Claude Code в браузере или приложении.
2. В заголовке сессии — меню облачной среды → **Edit** (редактировать). Нужна среда,
   в которой идёт работа над репозиторием Friday — обычно **Default**.
3. Раздел **Environment variables / Secrets** → добавить:
   `KIE_API_KEY` = ваш ключ kie.ai.
4. Раздел **Network access** → добавить в разрешённые домены `huggingface.co`
   и `cdn-lfs.huggingface.co`. Оттуда `nullume lib init` один раз скачивает
   модель CLIP (~150 МБ), которая раскладывает референсы по стилям. Дальше
   модель берётся с диска, сеть ей не нужна.
5. Новые сессии увидят ключ сразу.

Ключ **в чат не присылать** — только в настройки среды.

Ограничение: облачный контейнер пересоздаётся, поэтому собранная там библиотека вкуса
пропадает вместе с сессией. Постоянная библиотека — на Mac, способ Б.

---

## Б. Claude на вашем Mac — 10 минут

Репозиторий у вас уже есть: `~/Friday-claude` — это полный клон с правом пуша. Claude,
запущенный в этой папке, видит все файлы и историю и может коммитить так же, как
облачный.

1. Установить Claude Code:

   ```
   npm install -g @anthropic-ai/claude-code
   ```

   Если ругается на права — `sudo npm install -g @anthropic-ai/claude-code` и пароль
   от Mac.

2. Зайти в папку и запустить сессию, доступную из приложения:

   ```
   cd ~/Friday-claude
   claude remote-control
   ```

   Первый раз попросит войти в аккаунт Claude — тем же, что вы используете сейчас.
   После этого сессия появится в приложении Claude Code, и ей можно писать с телефона.

3. Пока окно Терминала открыто, эта сессия видит ваш Nullume: библиотеку в
   `~/.nullume`, модель CLIP, сессию Pinterest, дашборд.

Как делить работу:
- **сессия на Mac** — сбор референсов, Pinterest, дашборд, утверждение стилей;
- **облачные сессии** — код, ревью, агенты, выкатка;
- обмен между ними — через git, как сейчас.

---

## Почему не облачный сервер

Сервер даёт круглосуточную работу без Mac, но не решает Pinterest — ради которого
он и нужен. Запросы с адреса дата-центра Pinterest видит как бота, а cookie, выданная
вашему домашнему адресу, при смене адреса часто сбрасывается. Сервер имеет смысл,
если понадобится работа 24/7 без Pinterest; тогда способ тот же, что Б, только
на сервере.
