# Бренд: Nullume

Бренд-специфика проекта. Универсальные принципы дизайна и anti-references — в
`docs/core/design-principles.md`. Читать оба.

---

## Продукт

- **Что:** CLI-инструмент и MCP-сервер для генерации медиа (изображений, видео, аудио) через kie.ai и управления библиотекой референсов стилей
- **Аудитория:** владелец и агенты Claude Code; разработчики и дизайнеры в будущих версиях
- **Задача интерфейса:** быстрая генерация медиа без лишних кликов; консиль для контроля; MCP для интеграции в агентов
- **Тон:** деловой, без украшений, по-русски, без восклицаний и внутренних id в выводе

## Характер бренда

- **Минималистичный:** функция важнее формы; вывод только нужное, заголовки чёткие
- **Прозрачный:** пользователь видит цену до генерации, прогресс во время, путь результата после
- **Надёжный:** ошибки внятные, советы чёткие, цена честная

## Регуляторы (dials)

**Не применимо.** Nullume — это CLI-инструмент и MCP-сервер, а не веб-сайт. Нет интерфейса,
нет графики, нет типографики по дизайн-принципам (это текст в консоли).

Dials регулируют визуальное ощущение веб-приложения:
- DESIGN_VARIANCE — вариативность элементов
- MOTION_INTENSITY — интенсивность анимаций
- VISUAL_DENSITY — плотность информации на экране

Для CLI все это не актуально. Вместо этого есть собственные правила:

- **Ширина вывода:** 80–100 символов (консоль), длинные блоки обёрнуты
- **Прогресс:** для долгих операций (загрузка, ожидание) показываем `⏳` и таймер
- **Ошибки:** только в stderr, с кодом выхода ≠ 0; успехи в stdout
- **JSON-вывод:** `--json` не добавляет тайтлы и форматирование; чистый JSON, валидный
- **Бизнес-ошибки:** «Баланс недостаточен (нужно 5 кредитов, есть 2)», не просто «403»

## Доменный профиль

**Не E-commerce, не SaaS, не дашборд, не лендинг.** Это инструмент командной строки.

Профиль: **CLI-инструмент** (как ffmpeg, curl, git). Правила других доменов не наши.

---

## Домены проекта, важные для CLI

- **Кредиты kie.ai:** 1 кредит = $0.005; всегда показываем денежный эквивалент
- **Баланс и лимиты:** рассчитываем до генерации, показываем подтверждение > $1
- **Таймауты:** сеть 10 с, ожидание результата 600 с; не показываем пользователю точные числа (эта деталь стека)
- **Файлы:** результаты сохраняются с хешем в имени; путь всегда абсолютный
- **JSON-режим:** для automation; `--json` выводит ровно один JSON-объект, остальное в stderr (логи, прогресс)
