# Воркфлоу: Автоматизация бизнес-процесса

## Алгоритм

### 1. Описание процесса
Ответить на вопросы:
- Что сейчас делается вручную?
- Как часто это повторяется?
- Сколько времени занимает?
- Кто выполняет?
- Какие инструменты используются?

### 2. Триггер
| Тип | Пример |
|-----|--------|
| Расписание | Каждый день в 9:00 |
| Событие | Новый заказ в CRM |
| Вебхук | Оплата прошла |
| Ручной запуск | По кнопке |
| Условие | Остаток товара < 10 |

### 3. Действия
Типовые действия:
- Отправить уведомление (Telegram / email / Slack)
- Записать данные в Google Sheets / БД
- Создать задачу в трекере (Notion / Trello / Jira)
- Отправить HTTP запрос к внешнему API
- Сформировать и отправить документ (PDF / invoice)
- Парсинг данных с сайта

### 4. Реализация

**Простой случай (no-code/low-code):**
- n8n — self-hosted, мощный, бесплатный
- Make (Integromat) — платный, простой
- Zapier — платный, простой

**Кастомный код (пример для стека с очередями):**
```typescript
// BullMQ — очередь задач (требует Redis)
import { Queue, Worker } from 'bullmq'

const queue = new Queue('automation', { connection: redis })

// Добавить задачу
await queue.add('send-report', { userId, period: 'weekly' })

// Обработать задачу
const worker = new Worker('automation', async (job) => {
  if (job.name === 'send-report') {
    await generateAndSendReport(job.data)
  }
})
```

### 5. Мониторинг
- Логировать начало и конец каждого запуска
- Алерт в Telegram при ошибке
- Хранить историю последних 100 запусков
- Dashboard с метриками (успех / ошибка / время выполнения)
