Предполётный чеклист перед коммитом UI. Каждый пункт — да или нет. Если хоть один пункт «нет» — работа не готова, вернуть к доработке.

## Чеклист

- [ ] **Brief inference объявлен** — одной строкой трактовка (тип экрана, аудитория, вайб, V/M/D)?
- [ ] **Регуляторы явно** — DESIGN_VARIANCE, MOTION_INTENSITY, VISUAL_DENSITY заданы конкретными числами (или используются дефолт V=4/M=3/D=5)?
- [ ] **Один акцентный цвет** на всю страницу (не разноцветные кнопки)?
- [ ] **Система скруглений** — радиус консистентен (карточки ≤16px, кнопки ~8px, аватары full)?
- [ ] **Контраст WCAG AA** — текст/кнопки ≥4.5:1 на всех фонах?
- [ ] **CTA читаемо** — текст не переносится на 2+ строк на десктопе?
- [ ] **У полей форм есть label/aria-label** — не полагаемся на placeholder?
- [ ] **Hero влезает в первый экран** — заголовок ≤2 строк на мобильном?
- [ ] **Навигация в одну строку** — высота ≤80px, не прячется (или мобильное меню)?
- [ ] **Списки >5 пунктов** — используют сетку/табы/карусель, не длинный &lt;ul&gt;?
- [ ] **Нет трёх одинаковых карточек-фич подряд** — визуальное разнообразие?
- [ ] **Моторика правильная** — анимации &lt;300мс (модалки/шторки до 500мс), ease-out, только transform/opacity?
- [ ] **prefers-reduced-motion** — анимации движения отключены при его запросе?
- [ ] **Состояния обработаны** — loading / empty / error есть (или явно не нужны)?
- [ ] **Иконки из одной библиотеки** — не микс разных стилей?
- [ ] **Реальные визуалы** — изображения или осмысленные заглушки, не div-фейки?
- [ ] **Цены форматируются** — выводятся как price/100 в рублях, не копейки?
- [ ] **design-lint.mjs чист** — запустить `node .claude/scripts/design-lint.mjs`?

## Правовой блок (публичный сайт российского клиента)

- [ ] **Согласие отдельное** — не склеено с офертой и рекламой, галочка не предустановлена?
- [ ] **Факт согласия сохраняется** — дата, версия текста, цель записаны на бэкенде?
- [ ] **Ссылка на политику** — есть рядом с каждой формой, собирающей телефон или email?
- [ ] **Счётчики после согласия** — аналитика не стартует до него?
- [ ] **Реквизиты владельца** — опубликованы на сайте?
- [ ] **Удаление данных** — есть путь найти, выгрузить и удалить пользователя?
- [ ] **rkn-lint.mjs чист** — запустить `node .claude/scripts/rkn-lint.mjs`?
- [ ] **`rkn-compliance` прогнан в финальном режиме** — скрипт ловит только
      текстуальное; правдивость политики, основание рассылок и статус
      уведомления в РКН проверяются суждением. БЛОКЕР = работа не сдаётся
- [ ] **Правовой контур заполнен** — раздел в `docs/projects/<проект>/project.md` без пустых полей?

## Итог

Если все пункты ✓ — UI готов. Если есть ✗ — вернуть в разработку с указанием невыполненных пунктов.
