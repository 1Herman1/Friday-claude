# bugfix

Почини баг: **$ARGUMENTS**

Следуй воркфлоу `.codex/workflows/bug-fix.md`:

1. Зафиксируй симптом: ожидание vs реальность, шаги воспроизведения, текст ошибки.
2. `debugger` — найди ПРИЧИНУ (`файл:строка`), а не симптом.
3. Проверь нет ли того же бага в других местах (`researcher`).
4. `coder` — минимальный фикс, без попутного рефакторинга.
5. Воспроизведи исходный сценарий — баг должен уйти.
6. Если место критичное (auth/оплата/бонусы) → `code-reviewer`.

Коммит `fix: ...`, пуш на рабочую ветку проекта (см. `docs/projects/<проект>/project.md`).
