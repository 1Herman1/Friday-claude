# summary

Заверши сессию резюме: **$ARGUMENTS**

Не пересказывай весь диалог — только то, что нужно следующей сессии чтобы
продолжить без потери контекста. Ничего не пиши в файлы и не коммить — вывод
только в чат, текстом, чтобы пользователь мог скопировать и вставить в начало
новой сессии.

Формат:

```markdown
# Сессия YYYY-MM-DD — [одна строка сути]

## Сделано
- [Конкретный пункт: что изменено, в каком файле]
- ...

## Не сделано / отложено
- [Что осталось, почему отложено]

## Незапушенное
- [Есть ли незапушенные коммиты — hash и что внутри. Если всё запушено — написать "нет"]

## Решения и договорённости
- [Важный выбор, который нельзя забыть — например «оплату делаем через ЮKassa, не Тинькофф»]

## Следующий шаг
- [Первое конкретное действие для следующей сессии]
```

Правила:
- Только конкретика (файлы, hash коммитов, названия) — без общих фраз вроде
  «поработали над фронтендом».
- Если есть незапушенные изменения — попробовать запушить перед выводом резюме,
  и указать реальный итоговый статус в разделе «Незапушенное».
- Ничего не записывать на диск — только текст ответа в чате.
