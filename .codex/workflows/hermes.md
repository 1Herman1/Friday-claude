# Codex и существующий Hermes

Это инструкция настройки на машине Hermes, не подтверждение её выполнения.

1. Обновить локальный клон рабочей ветки Friday, проверить чистоту дерева.
2. Подготовить инструменты: bash .codex/setup.sh.
3. В Hermes выбрать ChatGPT/Codex Subscription через hermes model и пройти OAuth.
4. Для нативного Codex runtime отдельно выполнить codex login на той же машине.
5. В сессии Hermes: /codex-runtime codex_app_server, затем начать новую сессию.
6. Убедиться, что рабочая директория задачи — корень клона Friday, проект и хуки
   доверены в Codex и загружен .codex/config.toml. Проверить роли, MCP и работу
   с тестовым файлом. Не запускать боевые задания ради проверки подключения.

Обычный провайдер Codex в Hermes и Codex app-server — разные режимы. В режиме
app-server инструменты delegate_task, memory и session_search Hermes могут
быть недоступны; используйте нативных субагентов Codex и файловую память.
Сверяйте поведение с установленной версией Hermes. Основная текущая сессия
Codex не получает доступ к Mac от появления этого файла.

Существующие расписания и archive-задачи Hermes остаются на машине владельца.
Для отдельного архива Codex используйте адаптированный scripts/hermes-archive.py
только после проверки доступов и назначения задачи. Не переключайте старые
cron Claude на новые пути без проверки. Изменения рабочего расписания —
отдельная операция на машине, где это расписание выполняется.
