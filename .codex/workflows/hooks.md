# Хуки Codex

Рабочая конфигурация — .codex/hooks.json. Обработчик — scripts/lifecycle.py.
Это не шаблон Claude settings.json: используются события и JSON-контракт Codex.

| Событие | Автоматическое действие |
|---|---|
| SessionStart | Контекст Codex и исторический контекст Friday, проект, ветка |
| PostToolUse | design-lint для затронутого UI с кешем по содержимому |
| Stop | Проверенные Git-метаданные в игнорируемый .runtime/ |
| PreCompact | Запись технических фактов в sessions/ при наличии изменений |
| SessionEnd | Та же запись, без копирования стенограммы |

Git pull, checkout, npm ci, пуши и деплои выполняются агентами в процессе задачи,
а не безусловным хуком. Штатное доверие к проекту и хукам задаёт сам Codex.
При ошибке хук показывает диагностическое сообщение. Проверка: selftest.py
и test_lifecycle.py. Не используйте архиваторы Claude для стенограммы Codex.
