# feature

Реализуй задачу по .codex/workflows/review-loop.md до соответствия ТЗ.

1. researcher — исследовать существующее поведение и полный набор файлов.
2. planner/architect — критерии готовности, контракт и минимальный план.
3. coder — реализовать согласованный scope, без лишних функций.
4. qa-engineer — необходимые проверки и воспроизведения.
5. review — независимые профильные ревьюеры по полному scope.
6. Исправить каждую подтверждённую находку; повторять тесты и review на
   текущей revision, пока нет открытых дефектов и все критерии ТЗ выполнены.
7. task_gate.py complete, смысловая память Codex, коммит/пуш по правилам.

Внешний блокер объявлять явно. Не путать неизвестный результат с pass.
