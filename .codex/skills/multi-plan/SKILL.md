## Когда использовать

Когда задача большая — не делай всё сам. Раздели на независимые части и запусти агентов параллельно.

## Шаблон разбивки задачи

**Параллельно (независимые части):**
- `Explore` → найти все файлы которые затронет задача
- `architect` → спроектировать как это должно работать

**После получения результатов (последовательно):**
- `coder` → реализовать с полным контекстом от предыдущих агентов

**Параллельно после реализации:**
- `code-reviewer` → качество кода
- `typescript-reviewer` / `react-reviewer` → по типу файлов
- `silent-failure-hunter` → тихие ошибки

## Правила

- Независимые задачи — ВСЕГДА параллельно в одном вызове Agent tool
- Зависимые задачи — строго последовательно (дождаться результата)
- Передавать агенту: пути файлов + что уже известно + что нужно сделать
- Не дублировать работу агента — если он читает файл, не читать его самому
- При запуске субагента — передавать conventions из соответствующего скилла `.codex/skills/`

## Пример для задачи "добавить фичу корзины"

```
Параллельно:
  Explore: "найди все файлы где используется cartApi и CartPage"
  architect: "спроектируй добавление поля notes к заказу"

→ дождаться обоих

Последовательно:
  coder: "добавь поле notes, затронутые файлы: [результат Explore], схема: [результат architect]"

Параллельно:
  react-reviewer: "проверь CartPage.tsx"
  typescript-reviewer: "проверь api.ts и orders/index.ts"
  database-reviewer: "проверь изменения в prisma/schema.prisma"
```


## Критерий завершения Codex

Следуй обязательному циклу .codex/workflows/review-loop.md: все критерии ТЗ,
подтверждённые исправления, повторное независимое ревью текущей revision.
Для информационного запроса без изменений достаточно проверенного ответа;
для реализации/исправления закрывай задачу только после task_gate.py complete.
