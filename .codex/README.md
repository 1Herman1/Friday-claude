# Codex в Friday

Эта папка содержит только инструкции и рабочий контекст Codex.
Инструкции Claude остаются в `CLAUDE.md` и `.claude/`.

## Начало работы

В начале нового чата передай Codex:

> Работаем с 1Herman1/Friday-claude. Сначала прочитай .codex/CODEX.md и следуй ему. Задача: …

`CODEX.md` — основной вход. Эта папка сама по себе не обеспечивает автоматическую
загрузку инструкций для всего репозитория. Корневой `AGENTS.md` намеренно не
создан: владелец попросил держать инструкции Codex в отдельной папке.
Локальный `~/.codex` на компьютере — другое хранилище; файлы авторизации
и пользовательскую конфигурацию оттуда в репозиторий не переносить.

## Содержимое

- `CODEX.md` — правила работы с репозиторием.
- При необходимости `context.md` — краткий актуальный контекст Codex.
- При необходимости `sessions/` — краткие итоги завершённых задач.
- Специализированные инструкции добавлять здесь по мере реальной необходимости.

Общие сведения о продуктах читать в существующей документации, а не
поддерживать их дубли в этой папке. Никакие хуки, серверы или деплои
добавлением этой папки не запускаются.
