# Живая витрина агентов — проверка интеграции

Проверено родителем 16.11.2026 MSK (15.11.2026 UTC). Это read-only наблюдение, **не автономная торговля**.

## Что работает

- Веб существующего дневника: `http://127.0.0.1:3100/agents-monitor`, ссылка «Агенты · Live» в общей навигации. Сервис привязан к loopback, наружу не опубликован.
- Клиент читает `/api/agents-monitor` каждые 5 секунд; сервер только читает whitelisted файлы. Нет чтения `.env`, приватных счетов, отправки заявок или внешнего GET по пользовательскому URL.
- Непрерывный `monitor.py --interval 60`: следующий цикл начинается через 60 секунд ПОСЛЕ завершения предыдущего. Время всего цикла зависит от API/таймаутов, это не обновление бирж каждую секунду.
- `progress.json` обновляется до/после каждого запроса: видны текущая площадка, RUNNING, ошибки, завершение. `latest.json` — последний полный результат, не подменяется частичными полями во время запроса. Возраст данных не равен времени heartbeat.
- Проверен реальный переход Gate → Binance → OKX → новый completed snapshot через HTTP. Trace: `evidence/live-progress-verification.json`, `saw_actual_in_progress=true`, `saw_new_completed_snapshot=true`.
- Источники: BingX, Bitget, Gate, Binance, OKX. Один полностью проверенный цикл `20261115T215531.215568Z`: **3827 observations**, **4530 ticker-only пар**, все HOLD; 856/885/1036/522/528 по площадкам. Raw SHA256 replay совпал. Это записи «инструмент × биржа», не 3827 уникальных монет. У части бирж есть RWA/индексы, классификация crypto-only ещё не сертифицирована.
- Другие циклы реально давали SSL/read timeouts и partial coverage. UI показывает ошибки и UNKNOWN, не скрывает их и не заполняет нулями. Доступность пяти feed в проверенном полном цикле не является SLA.
- Карточка выбранного инструмента, ставка/интервал/следующее начисление, indicative LONG/SHORT и блокирующие причины. Нормализация направления — сначала ставка в час при известных интервалах. Сохранён отдельный RED→GREEN тест различия 1h/8h.
- Отображаются реальные состояния market/funding, standalone quant и risk not wired, отсутствующие news/управляющий/execution. Никаких fake online, PnL или прогресса LLM.
- UI показывает 250 строк выбранного фильтра из всего набора; поиск/venue/extreme funding фильтры работают по всему payload, а не только по первым 250. Пауза экрана не останавливает движок. Старый scanner-snapshot явно SAVED.

- HTTP 200 страницы и API; реальная таблица, выбор инструмента и инспектор проверены браузером. Desktop screenshot и mobile screenshot: `evidence/live-monitor-*.png`.

- Read-only collector запущен как локальный tracked process, не launchd/system service. Сон/выключение Mac останавливает наблюдение. Автозапуск/перезапуск и защищённый remote-доступ не реализованы.

## Что НЕ подключено / не доказано

- CoinGlass: документация проверена, API без оплаченного доступа/ключа не подключён; подписку не покупали.
- Идентичность токена по сети/контракту, liquidity/depth, тарификация аккаунтов, цены исполнения и выхода, future funding cashflows: не сертифицированы. Тикерная пара не исполнимая арбитражная возможность.
- Исторические volume/OI аномалии, полноценный news-agent и управляющий LLM, wiring quant/risk к исполнителю, бумажные two-leg fills и live execution — не реализованы этой работой.
- Это локальная первая витрина. Серверная 24/7 эксплуатация, авторизация, push/stream оптимизация большого payload, общие API rate budgets и политика хранения/ротации raw — отдельные незавершённые задачи. `out/` локальный и исключён из git; не оставлять этот dev collector как бесконтрольный серверный production-daemon.
