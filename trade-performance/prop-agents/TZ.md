# ТЗ: Автономная торговая система ИИ-агентов на пропах (prop-agents) — v2 (черновик)

Статус: черновик. Владелец: Герман.
Источники: ТЗ DeepSeek v1.0, исследование Claude «Open-source основы для мультиагентной LLM-торговли», решения из чата 2026-10-06/07, [`../research/props-and-testbeds.md`](../research/props-and-testbeds.md).

## 1. Цель

Много ИИ-агентов, сгруппированных в кластеры по стратегиям, торгуют на демо, затем на крипто-пропах, где автоматизация разрешена. Система сама ищет улучшения, но не может ослабить риск-лимиты.

## 2. Понятия

- **Кластер** — группа агентов, работающих над одной стратегией. Стратегия → стиль торговли → модель, в совокупности.
- **Агент** — экземпляр: стратегия + модель + параметры + карточка правил + виртуальный/проп счёт.
- **Карточка правил агента** — условия входа, условия отмены, риск на сделку, лимиты, разрешённые инструменты.

## 3. Кластеры (стартовый набор, список будет расширяться)

| Кластер | Суть | Где |
|---------|------|-----|
| MA-cross | Пересечения скользящих средних + фильтр режима рынка | Пропы |
| SMC | Слом структуры (BOS/CHoCH), ордерблоки, FVG, снятие ликвидности | Пропы |
| News & Sentiment | Новостной фон и сентимент | Пропы |
| Pump-short | Шорт пампов >50% | **Не на пропах** (отдельный счёт/демо) |

## 4. Архитектура

1. **Данные** — Python-скрипты (ccxt), свечи, стаканы, новости. Без LLM. Все данные с временем публикации (агент видит только прошлое).
2. **Детекторы сетапов** — код (pandas, `smartmoneyconcepts`, индикаторы). Дёшево, детерминированно.
3. **Мозг агента** — граф ролей по образцу TradingAgents (LangGraph): аналитики → дебаты bull/bear → трейдер → риск → решение. **Дебаты только при сигнале детектора.** Выход — строгая JSON-схема.
4. **Глаза** — агент получает картинку графика и разбирает её vision-моделью; режим B — сам открывает график в браузере.
5. **Шлюз моделей** — OpenRouter/LiteLLM: модель меняется строкой конфига; логируются токены и стоимость.
6. **Риск-слой (код, не промпт)** — размер позиции, плечо, дневной/общий лимит (по equity, как у пропов), обязательный стоп, whitelist инструментов, kill-switch. Лимиты меняет только Герман.
7. **Исполнение** — адаптеры: демо бирж (Hyperliquid testnet, OKX Demo, BloFin demo), Propr API, HyroTrader, терминал SizeProp (браузерная автоматизация, где разрешено правилами).
8. **Арена** — матрица {модель × кластер × площадка}, у каждой ячейки свой счёт, N≥3 повтора, бейзлайны без LLM (buy&hold, простое пересечение MA).
9. **Журнал** — все промпты, ответы, ордера, филлы, комиссии, стоимость API → общая БД → дневник.
10. **Управление** — Telegram (статус, стоп, сигналы, отчёты) + веб-дашборд дневника.

## 5. Самосовершенствование

- Агенты-улучшатели анализируют журнал и предлагают изменения стратегий и скиллов.
- Новая версия торгует **в тени** рядом со старой на той же арене.
- Замена — только если обыграла после комиссий и стоимости API на живых данных.
- Риск-лимиты и карточки допусков на проп — неизменяемы для агентов.

## 6. Правила пропов (учитывать в риск-слое)

Каждый проп — отдельный профиль: цель, дневной лимит (метод расчёта и время сброса), макс. просадка (статическая/трейлинг), плечо, обязательный стоп, мин. дни, запрещённые практики, политика ботов. Профили — в БД, не в промптах.

## 7. LLM

- Основные: **Claude Opus 5.5** (финальное решение, исследователь стратегий) и **Claude Sonnet 5.5** (аналитики, дебаты, vision, разбор сделок).
- Бесплатные модели OpenRouter — черновые прогоны и бейзлайн (подключены, тест 2026-10-07: рабочие Laguna S 2.1, Ling 3.0 Flash, Apodex mini, dots-3).
- Подробно по ролям: [`ARCHITECTURE.md`](ARCHITECTURE.md). Карточка стратегии: [`STRATEGY_CARD_TEMPLATE.md`](STRATEGY_CARD_TEMPLATE.md).
- Ориентир по моделям — TradingArena.ai; решение — по нашей арене.

## 8. Площадки (см. research)

Основные кандидаты: Propr (API, Beta-среда), HyroTrader (свой бот через BloFin/Hyro), SizeProp (терминал). Hash Hedge — только после письменного разрешения.

## 9. Этапы

- **Ф0** — проект, схема БД, подключение OpenRouter, сервер.
- **Ф2** — детекторы MA-cross и SMC, сигналы в Telegram и в лог (без торговли).
- **Ф3** — арена на демо, 4–8 недель.
- **Ф4** — Propr Beta → реальный челлендж с минимальным счётом и kill-switch; HyroTrader; SizeProp-терминал.
- **Ф5** — агенты-улучшатели, теневые версии.
