# Крипто-пропы и тестовые площадки для агентов

Проверено: 2026-10-07. Правила пропов меняются — перед покупкой челленджа перечитывать первоисточник.

## Итог: с кем работаем

| # | Проп | Как торгует агент | Почему | Статус |
|---|------|-------------------|--------|--------|
| 1 | **Propr** (Hyperliquid) | API | Позиционируют себя как «первый проп для ИИ-агентов»: полный REST API, Python/JS SDK, Beta-среда для тестов бота. От $25. Classic 1-Step: цель 10%, дневной лимит 3%, макс. просадка 6% (по обзору Fortunly — сверить) | Основной кандидат |
| 2 | **HyroTrader** | API (свой бот) | Официально: свои боты разрешены — Bybit demo API, BloFin demo API или платформа Hyro. Запрещены чужие стратегии, копи-трейдинг, сигнальные сервисы. Без ограничений по странам, но Bybit-путь требует свой Bybit-аккаунт → для нас BloFin или Hyro | Основной кандидат |
| 3 | **SizeProp** (Hyperliquid) | Терминал (браузер) | Официально: автоматизация через фронтенд разрешена (кликеры, TradingView-алерты), API запрещён. Под режим «агент работает в терминале и смотрит на график». От $19 | Кандидат для режима «глаза + клики» |
| 4 | **Breakout** (Kraken) | Их платформа | Обзоры пишут «боты разрешены», но API-документации нет. Нужен письменный ответ поддержки | Резерв |
| 5 | **Hash Hedge** | — | Terms п. 12.2: боты, скрипты, API, автоматизация запрещены без письменного разрешения. Пишем запрос | Только с разрешением |

## Где тестировать агентов

**Демо-счета с API (бесплатно):** Hyperliquid testnet, OKX Demo Trading, Binance testnet, Bybit Demo, BloFin demo (через HyroTrader).

**Тестовая среда пропа:** Propr Beta — тренировка бота в условиях будущего пропа.

**Арены и бенчмарки моделей:**
- **TradingArena.ai** — актуальные модели (Claude Opus 4.8, GPT-5.5, Gemini 3.1 Pro, Grok 4.3, DeepSeek V4, Qwen3.7 Max), у каждой paper-счёт $10k, один снимок рынка, таймфреймы 1h–1w. Ориентир, какие модели сейчас лучше торгуют.
- **TradeRank Arena** — сезоны с января 2026, 49 моделей.
- **Recall** — соревнования агентов (paper и on-chain), лидерборды.
- **ClawStreet** — соревнование LLM-агентов, paper $100k.
- **CoinRithm** — песочница для агентов, paper 50k.

**Bullpen** (bullpen.fi) — скорее всего тот «bull…»: некастодиальный терминал Hyperliquid + Polymarket + Solana с CLI и готовыми скиллами для Claude Code / Codex. Есть `--dry-run` / `--preview` / `--read-only`, но это реальная торговля, не paper. Статус alpha. Полезен как инструмент исполнения для DEX, не как арена.

Вывод: результаты Alpha Arena 2025 не используем — модели устарели. Ориентир по моделям — TradingArena.ai, но решение принимаем только по своей арене.
