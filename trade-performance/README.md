# Trade Performance

Направление H&B: трейдинг-продукты. Два проекта, общая база данных и общий риск-движок.

| Проект | Что это | ТЗ |
|--------|---------|----|
| [`journal/`](journal) | Дневник трейдера: сделки, статистика, психология, ИИ-разборы. Сначала для Германа, потом SaaS | [`journal/TZ.md`](journal/TZ.md) |
| [`prop-agents/`](prop-agents) | Автономная система ИИ-агентов: кластеры стратегий, арена, торговля на пропах | [`prop-agents/TZ.md`](prop-agents/TZ.md) |
| [`research/`](research) | Исследования: пропы, тестовые площадки, open-source основы | [`research/`](research) |

## Принятые решения (2026-10-07)

1. Дневник сначала только для Германа. Параметры учёта раскрываем по ходу работы и вносим в ТЗ.
2. Агенты торгуют через API нашего продукта, решения принимает LLM. Плюс «глаза»: агент смотрит на график (скриншот → vision-модель или самостоятельный просмотр в браузере).
3. Автоматизация на пропе — только там, где она разрешена правилами, или с письменного разрешения фирмы. Маскировку бота под человека не делаем.
4. У каждого агента — карточка правил: условия входа, риск, лимиты.
5. Дебаты агентов запускаются только при сигнале на вход.
6. Агенты-улучшатели постоянно ищут, как поднять доходность при минимальном риске. Новая версия сначала торгует в тени, заменяет старую только если обыграла на живых данных. Жёсткие лимиты риска меняет только Герман.
7. Стиль Германа за основу агентов не берём (плавающий риск, не копируется). Возможно, вернёмся позже.
8. LLM: Claude Opus 5.5 и Sonnet 5.5; бесплатные модели OpenRouter — для черновых прогонов.
9. Движок переезжает на сервер (Mac не обязан работать 24/7).
10. На каждого агента (кластер стратегии) — свой топик в Telegram. Контекст агента хранится в репо (`prop-agents/clusters/<имя>/`), топик — место обсуждения и правок.
11. (2026-10-09) Оркестратор на старте — Hermes на подписке; LLM будится только при сигнале детектора. Первый детектор — SMC-BTC 5m (`prop-agents/clusters/smc-btc/`).

## Telegram: карта топиков (группа «Трейдинг - крипта», `-1003927097473`)

Принцип: каждый подпроект и кластер — свой топик. Полная карта всех групп — `docs/hermes/topics.json`. Короткие номера (Т1…Т7) — для обращения в чате.
- **Т1 · Разработка автономной системы и агентов** — движок prop-agents: архитектура, риск-слой, исполнение, арена, ТЗ. (thread_id появится после первого сообщения)
- **Т2 · ИИ-агенты и пропы** (thread 5) — агенты на пропах: кластеры, правила пропов, допуск, диагностика и ошибки.
- **Т3 · Тестирование новых идей** (thread 7) — песочница, разные виды трейдинга, терминалы.
- **Т4 · Сигналы памп-дамп** (thread 8) — бот сигналов по пампам/дампам (вне пропов).
- **Т5 · Сигналы смарт-мани** (thread 9) — детектор `prop-agents/clusters/smc-btc/`; сюда приходят сигналы cron «SMC-BTC 5m».
- **Т6 · Разработка дневника трейдинга** (thread 2) — `journal/`.
- **Т7 · Арбитраж** (thread 10) — будущий проект.
