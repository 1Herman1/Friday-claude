# ТЗ: Дневник трейдера (journal) — v2 (черновик)

Статус: черновик, раскрываем по ходу работы. Владелец: Герман.
Источники: ТЗ DeepSeek v1.0 (2026-10-03), исследование Claude по open-source основам, решения из чата 2026-10-06/07.

## 1. Цель

Дневник, который сам собирает сделки, считает статистику, находит ошибки и психологические паттерны и подсказывает, что менять. Сначала для Германа, архитектура — с заделом под SaaS (несколько пользователей).

## 2. Пользователь и стиль торговли (исходные данные)

- **Стиль 1 — BTC, смарт-мани (SMC), 15m.** Анализ на графике MEXC (встроенный TradingView), исполнение на Bybit (сейчас заблокирован).
- **Стиль 2 — шорт пампов на MEXC.** Монеты с ростом >50%; поиск точек интереса для разворота; плечо 10x, стоп = ликвидация; тейки по точкам интереса или 70–80% при сильном скаме.

## 3. Источники данных

| Источник | Способ | Приоритет |
|----------|--------|-----------|
| MEXC (история + текущие сделки) | API, ключ только на чтение | P0 |
| Bybit | API (когда разблокируется) | P2 |
| Сделки агентов (`prop-agents`) | Общая БД | P1 |
| Пропы (Propr, HyroTrader и др.) | API / выгрузка | P2 |
| MetaTrader 5 | Через Windows/Wine-мост на сервере (уточнить брокера) | P3 |
| Ручной ввод | Веб-форма, Telegram | P0 |
| Голос | Голосовое в Telegram → распознавание → структурированная запись | P1 |

## 4. Функции

### MVP (Ф1)
1. **Импорт сделок MEXC** + разбор всей старой истории.
2. **Статистика:** PnL, win rate, profit factor, средний R, equity curve, просадки; разрез по стилю (SMC / пампы), монете, дню недели, часу, длительности.
3. **Карточка сделки:** график со свечами и отметками входа/выхода/стопа/тейка, причина входа, эмоция, скриншот, теги.
4. **Голосовые заметки** после сделки.
5. **Еженедельный ИИ-разбор:** ошибки, психологические паттерны, рекомендации.

### Ф2
6. **Чек-лист перед входом** — базовые правила, список меняется по итогам работы.
7. **Детектор лудки (тильта).** Первые триггеры:
   - вход < 5 мин после убытка;
   - рост лота после убытка;
   - > N сделок за день;
   - серия убытков подряд;
   - торговля ночью / вне своих часов;
   - стоп = ликвидация.
   Доработка функций — по ходу.
8. **Сигналы по монетам** — из результатов тестов `prop-agents` (какие сетапы и монеты показали edge).
9. **Метрика «цена ликвидационного стопа»** — сколько стоят сделки со стопом на ликвидации.

### Ф3
10. Telegram Mini App.
11. Мультипользовательность, биллинг (SaaS).

## 5. Параметры учёта (стартовый список, расширяем)

Сделка: биржа, инструмент, направление, плечо, объём, маржа, вход, выход, стоп (план/факт), тейк(и), ликвидационная цена, комиссии, фандинг, PnL ($, %, R), длительность, стиль, сетап, таймфрейм, источник (я / агент / сигнал), скриншоты.
Психология: эмоция до/после, уверенность 1–10, следование плану (да/нет), нарушенное правило, заметка (текст/голос).
День: стартовый/конечный баланс, PnL, макс. просадка, число сделок, оценка дисциплины.

## 6. Стек

- Веб: Next.js (App Router) + TypeScript + Tailwind + shadcn/ui + TanStack Query.
- Графики: TradingView Lightweight Charts (Apache-2.0) — свечи + отметки сделок.
- БД: PostgreSQL (Supabase), Prisma.
- Импорт и аналитика: Python-воркеры (ccxt) или Node — решим на Ф0.
- ИИ: OpenRouter (старт — бесплатные модели), Claude.
- Telegram: бот через Hermes, Mini App позже.
