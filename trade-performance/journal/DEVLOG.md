# Дневник разработки дневника трейдера

Хронология: что сделано, что решено, что дальше. Новые записи сверху. ТЗ — `TZ.md`, запуск — `RUN.md`.

## 2026-10-21

**Сделано**
- **Синхронизация MEXC стала устойчивой.** 19–20.10 четыре ночных запуска упали на ответе MEXC `513 Invalid request, please try again later`. Теперь на 513 и сетевые ошибки до 5 повторов с паузой, подпись пересобирается на каждой попытке. В чат пишем только если упало 3 запуска подряд.
- **Уведомление о новых сделках.** Когда синхронизация находит сделку, закрытую после прошлого успешного запуска, в топик Т6 приходит строка: монета, сторона, net PnL, отметка ликвидации. Без новых сделок молчит.
- **Подтянуты новые сделки:** шорт JCT 20.10, 14:56–16:51, ликвидация, −$50.16. Лонг BTC с 16.10 открыт. Итого 119 сделок: 118 закрытых, −$773.61, одна открытая.
- **Карточка сделки `/trades/<id>`** (J3, первая часть):
  - свечи MEXC (5м, 15м, 1ч или 4ч, подбирается по длительности) с метками входов, выходов и ликвидаций, линиями входа, выхода и планового стопа;
  - блок фактов: длительность, объём, gross, комиссии, фандинг, net, MFE/MAE по свечам, стоп в % от входа;
  - список исполнений;
  - форма разбора: причина входа, плейбук, теги, эмоции до и после, уверенность 1–10, по плану, плановый стоп, заметки;
  - навигация к предыдущей и следующей сделке, из таблицы сделок в карточку.
  
  Проверено в браузере: сохранение пишет в БД. Тестовые данные убраны мягким удалением через `deleted_at`.
- **Ввод из Telegram** — `intake/tg_note.py`. Джарвис в Т6 сам понимает текст или голосовое и вызывает CLI, в самом CLI LLM нет. Привязка к сделке:
  - `auto`: открытая сделка, иначе закрытая за последние 6 ч, иначе заметка к дню;
  - явно: `#N`, `last`, `day`.
  
  Пишет поля разбора, теги, плейбук. Повтор того же сообщения не создаёт дубль: ключ chat_id + message_id. Проверено на `--dry-run`, БД не изменилась.

**Решено**
- «Универсальный дневник» в словах Германа — этот файл, дневник разработки.
- Тестовые записи не удаляем, а гасим через `deleted_at`: удаление требует подтверждения и тормозит работу.

**Дальше:** см. «Осталось» в `TZ.md` → «Статус разработки».

## 2026-10-21 — Ф2: тильт, сигналы, чек-лист
- `core/tilt.py` — детерминированный детектор (без LLM): перезаход <5 мин после убытка, объём >1.5× после убытка (BTC/ETH и альты раздельно), >5 сделок/день, серия ≥3 убытков, ликвидация. Пишет `trade_rule_violations` (comment `auto: …`) + `risk_events`; снятую вручную auto-галочку повторно не ставит. Алерт в чат — только новые срабатывания за 48 ч. Запуск — из `run_mexc_sync.sh` после каждого sync.
- `core/signals_sync.py` — сигналы smc-btc → `signals` (LIVE = ушли в Т1, иначе BACKTEST, simulated_r), привязка `trades.signal_id`. Детектор пишет `out/setups_live.json`.
- `checklist_runs` (миграция `20261021120000_f2_checklist_runs`) + страница `/checklist`: пункты чек-листа + тильт-фон «сейчас» → вердикт «можно / пауза». Сделка привязывается сама (та же монета/сторона, ≤60 мин). Блок «с чек-листом vs без».
- Дашборд: «с нарушениями / чистые», «цена нарушений» по правилам, «по сигналу».
- Факт на 21.10: чистые сделки 53 шт. **+$831** (WR 75%, PF 8.5); с нарушениями 65 шт. **−$1605**. Ликвидации −$2576, усреднение −$904, объём↑ −$628.

## 2026-10-21 — Ф2: раздел «Сигналы» (SMC + памп-дамп)
- `core/pump_scan.py` — сканер пампов MEXC Futures (публичный API, без ключей и LLM): +50%/24ч и оборот ≥$300k → сигнал `pump-mexc` (шорт). Виртуальная сделка как у Германа: стоп +10% (≈ликвидация 10x), тейк −20% (R=2), исход по часовым свечам за 72 ч + max_drop/max_up. Живой скан — в `run_mexc_sync.sh` (ежечасно, молча). `--backfill 330` — история по монетам из сделок (`--all` — весь рынок, медленно: API режет частоту).
- Привязка шортов к пампу: та же монета, открыт в [−24 ч; +48 ч].
- Веб `/signals`: карточки источников (сигналов, WR, среднее R, медианный откат, «ты взял N сд. и $»), фильтр по источнику и «только взятые мной», ссылки на сделки. Место под чужие каналы.
- Факт на 21.10: пампов по его монетам 96, медианный откат за 72 ч 29%, но вынос +10% раньше −20% в 75% случаев (WR 25%, R −0.26). Его шорты пампов: 51 сделка, −$739, WR 47%. SMC-BTC: 31 сигнал, WR 36%, R +0.09; по ним не входил.
